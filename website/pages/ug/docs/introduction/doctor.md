# Doctor

```sh
everything-rust doctor
everything-rust doctor --json
```

`doctor` تىل ئىجرا مۇھىتلىرى، ۋاكالەتچى تەڭشىكى ۋە MCP مۇلازىمېتىرىنى تەكشۈرىدۇ، ھەمدە ھەر بىر مەسىلىنى تۈزىتىدىغان بۇيرۇقنى بېسىپ چىقىرىدۇ. زۆرۈر بىر نەرسە كەم بولسا، 1 بىلەن چېكىنىدۇ.

بىر قەدەم ئىجرا مۇھىتى، ۋاكالەتچى تەڭشىكى ياكى MCP مۇلازىمېتىرى كەم ياكى كونىراپ كەتكەنلىكى سەۋەبىدىن مەغلۇپ بولسا، ئۇنى ئىجرا قىلىڭ. خىزمەت ئېقىمى ماھارىتىمۇ ۋاكالەتچىلەرگە شۇنداق قىلىشنى ئېيتىدۇ.

## ھەر بىر تىلغا نېمە كېرەك

`record`، `diff` ۋە `bench` ئەسلى نۇسخىنى ئۆزىنىڭ ئىجرا مۇھىتىدا ئىجرا قىلىدۇ: TS ئۈچۈن Node 22.6+ (ئۇ `.ts` مەنبە ھۆججەتلىرىنى بىۋاسىتە ئىجرا قىلىدۇ)، Python ۋە C ئۈچۈن Python 3.9+ (ctypes)، Go 1.21+، Ruby 3+، JDK 17+ (`javac` ۋە `java`). Node دا `profile` ئۈچۈن Node 24+ كېرەك، ئۇ `NODE_OPTIONS` تا `--cpu-prof` قا يول قويىدۇ. C ئۈچۈن يەنە C تەرجىمانى (compiler) كېرەك. wasm كۆۋرۈكلىرىگە يەنە `rustup target add wasm32-unknown-unknown` ۋە ماس كېلىدىغان `wasm-bindgen-cli` كېرەك؛ ئېنىق نەشرىنى `build` ئېيتىپ بېرىدۇ.

## تۆھپىكارلار ئۈچۈن

`cargo run -- doctor` قايسى ئىجرا مۇھىتلىرىڭىز بارلىقىنى، ئۇلارنىڭ نەشرىنى ۋە ھەر بىرىنى ئورنىتىدىغان ياكى يېڭىلايدىغان بۇيرۇقنى كۆرسىتىدۇ. [تۆھپە قوشۇش](/docs/project/contributing) نى كۆرۈڭ.
