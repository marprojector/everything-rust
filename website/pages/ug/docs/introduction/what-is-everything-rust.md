# everything-rust دېگەن نېمە

<p class="lead">پۈتكۈل ئەپىڭىزنى Rust دا بىر قىسىمدىن قايتا يېزىڭ. everything-rust Node.js (TypeScript/JavaScript)، Python، C، Go، Ruby ياكى Java ئەپىڭىزنىڭ بۈگۈن نېمە قىلىدىغانلىقىنى خاتىرىلەيدۇ، ئاندىن Rust دا قايتا يېزىلغان ھەر بىر قىسىمنى كېيىنكىسىگە ئۆتۈشتىن بۇرۇن شۇ خاتىرىگە سېلىشتۇرۇپ تەكشۈرىدۇ، ئەپ ساپ Rust بولغۇچە.</p>

ئۇ CLI، HTTP مۇلازىمېتىرلىرى ۋە كۇتۇپخانىلار ئۈستىدە ئىشلەيدۇ. Rust كودىنى كود ۋاكالەتچىڭىز (Claude Code، Codex، Cursor، Gemini CLI) ياكى سىز يازىسىز. PHP ۋە C# [ئالدىن كۆرۈش](/docs/languages/php) باسقۇچىدا.

## ئۇ نېمە قىلىدۇ، نېمە قىلمايدۇ

everything-rust كودنى تەرجىمە قىلمايدۇ. ئۇ ۋاكالەتچى ئىشەنچلىك پەرەز قىلالمايدىغان نەرسىلەرنى تەمىنلەيدۇ:

- **ۋاقىت قەيەرگە كېتىدۇ**: `profile` ھەقىقىي خىزمەت يۈكىنى ئىجرا قىلىپ، قىزىق فۇنكسىيەلەرنى رەتلەيدۇ؛
- **ئالدى بىلەن نېمىنى، قايسى تەرتىپتە كۆچۈرۈش**: `analyze` بىرلىكلەر، دولقۇنلار، خەتەرلەر ۋە crate لارنى پىلانلايدۇ؛
- **كۆۋرۈك**، شۇنىڭ بىلەن كودنىڭ قالغان قىسمى Rust نى ئۆزگەرمىگەن API سى بىلەن چاقىرىدۇ (`bridge`)؛
- **كۆچۈرمە ماس كېلىشى كېرەك بولغان ئېنىق ھەرىكەت**: `record` ئەسلى نۇسخىنى چېگرا ئەھۋاللاردا ئىجرا قىلىپ، ئۇنىڭ قايتۇرغان ياكى تاشلىغان نەرسىسىنى ساقلايدۇ؛
- **ئۇنى ئېلان قىلىشنىڭ بىخەتەر ئۇسۇلى**: `shadow` ھەر ئىككىسىنى يانمۇيان ئىجرا قىلىدۇ؛
- **كۆچۈرۈشنىڭ قاچان تاماملانغانلىقىنى ئېيتىدىغان دەرۋازا**: `gate`.

ئەسلى نۇسخا ھەقىقەتنىڭ مەنبەسى بولۇپ قالىدۇ. `diff` خاتىرىلەنگەن ھەر بىر ئەھۋالنى Rust تا قايتا قويىدۇ، ھەممىسى ماس كېلىپ `gate` ئۆتمىگۈچە ھېچنېمە ئېلان قىلىنمايدۇ.

## تۆت قەدەم

| قەدەم | نېمە بولىدۇ |
| --- | --- |
| **خاتىرىلەش** | `record` ئەسلى نۇسخىنى ھاسىل قىلىنغان چېگرا ئەھۋاللار، مەنە تۇزاقلىرى ۋە ئۆزىڭىزنىڭ كىرگۈزۈشلىرىدە ئىجرا قىلىپ، ئۇنىڭ قايتۇرغان ياكى تاشلىغان نەرسىسىنى ساقلايدۇ. |
| **كۆچۈرۈش** | `bridge` Rust crate ۋە ئوراپ تۇرغۇچنى ھاسىل قىلىدۇ، شۇڭا چاقىرغۇچىلار ئەسلى API نى ساقلاپ قالىدۇ. Rust كودىنى سىز ياكى ۋاكالەتچىڭىز يازىدۇ. |
| **تەكشۈرۈش** | `diff` خاتىرىلەنگەن ھەر بىر ئەھۋالنى Rust تا قايتا قويىدۇ، ھەممىسى ماس كېلىپ `gate` ئۆتمىگۈچە ھېچنېمە ئېلان قىلىنمايدۇ. |
| **Lift** | قايتا قويۇش زاپاس يولسىز ئۆتسە ۋە ھەر بىر بىرلىك gate دىن ئۆتسە، `app lift` ئۇنى ساپ Rust ئەپىگە ئايلاندۇرىدۇ. ئەسلى نۇسخىغا ھەرگىز تېگىلمەيدۇ. |

## Rust ھەمىشە تېزمۇ؟

ياق، everything-rust مۇ شۇنى دەيدۇ. ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم چاقىرىلىدىغان كىچىك فۇنكسىيە Rust تا كۆپىنچە ئاستا بولىدۇ، چۈنكى ھەر بىر چاقىرىش كۆۋرۈكتىن ئۆتىدۇ؛ V8، JVM ۋە Go بۇنداق فۇنكسىيەلەرنى نانوسېكۇنتلاردا ئىجرا قىلىدۇ. `profile` ئۇنىڭ ئەتراپىدىكى ئايلانمىنى تاپىدۇ، `--batch` پۈتۈن ئايلانمىنى يۆتكەيدۇ، `bench` بولسا ئېلان قىلىشتىن بۇرۇن ھۆكۈم بېرىدۇ. ئۆلچەنگەن سانلار (ئاستىلىرىمۇ بىللە) ئۈچۈن [توپ ۋە قىزىق يوللار](/docs/concepts/batches) نى كۆرۈڭ.

## ئۇ پەقەت خاتىرە قاپلىغان نەرسىنىلا تۇتالايدۇ

ئۆتۈش دېگەنلىك Rust نىڭ خاتىرىلەنگەن ھەر بىر ئەھۋالغا ماس كېلىدىغانلىقىدىن دېرەك بېرىدۇ، ئۇنىڭدىن ئارتۇق ئەمەس. يېشىل gate قا ئىشىنىشتىن بۇرۇن [ئۇ نېمىلەرنى تۇتالمايدۇ](/docs/concepts/limits) نى ئوقۇڭ.

::: warning ئۇنى نۇسخىدا ئىجرا قىلىڭ
`record` ۋە `app record` ئەسلى كودىڭىزنى ئىجرا قىلىدۇ، ھەر بىر فۇنكسىيەنى (ياكى پۈتۈن ئەپنى) نۇرغۇن ھاسىل قىلىنغان كىرگۈزۈشلەردە چاقىرىدۇ، `app record` بولسا ھەر بىر ئەھۋالنى ئىككى قېتىم ئىجرا قىلىدۇ. `diff`، `gate` ۋە `app replay` ئوخشاش ئەھۋاللارنى كۆچۈرمە ياكى ئەسلى نۇسخىدا قايتا ئىجرا قىلىدۇ. ھۆججەت يازىدىغان، ساندان بىلەن ئالاقىلىشىدىغان ياكى تورنى چاقىرىدىغان كود بۇنى ھەر بىر ئەھۋال ئۈچۈن بىر قېتىم قىلىدۇ. ئۇلارنى تۈرنىڭ نۇسخىسىدا، سىناق ساندانى بىلەن، مۇھىتتا ئىشلەپچىقىرىش كىنىشكىلىرى بولمىغان ھالدا ئىجرا قىلىڭ.
:::
