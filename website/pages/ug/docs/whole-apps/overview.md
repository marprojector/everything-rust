# پۈتۈن ئەپنى كۆچۈرۈش

نىشان ئەسلى نۇسخىدەك ئىشلەيدىغان ساپ Rust ئەپى، ئەسلى نۇسخا پايدىلىنىش سۈپىتىدە ساقلىنىدۇ. Rust كودىنى ۋاكالەتچىڭىز يازىدۇ؛ everything-rust خىزمەتنى تەرتىپكە سالىدۇ، ئاساسىنى قۇرىدۇ ۋە ھەر بىر قەدەمنى ئىسپاتلايدۇ. CLI، HTTP مۇلازىمېتىرلىرى ۋە كۇتۇپخانىلار.

```
analyze --whole-app ──> app record ──> app front-door ──> per unit: the loop, then app wire ──> app lift
 shape, every           what the app    Rust owns the       gate passes, so the unit answers in    pure Rust,
 dependency, the        does from the   entry point; the     Rust: replay 100%, fallback rate down proved by
 decisions to make      outside         original answers                                           replay
```

## 1. پىلانلاش

```sh
everything-rust analyze . --whole-app
```

`--whole-app` ئەپنىڭ شەكلى (CLI، مۇلازىمېتىر ياكى كۇتۇپخانا) ۋە كىرىش نۇقتىلىرىنى، ھەر بىر سىرتقى بېقىنىشنى (import قىلىنغان ياكى ئېلان قىلىنغان) ئۇنىڭ Rust crate ى ۋە ماسلىقى بىلەن، كۆچۈرۈش تەرتىپىنى پارچىلار بويىچە (بىر-بىرىنى import قىلىدىغان بىرلىكلەر بىللە يۆتكىلىدۇ)، ۋە تەۋسىيە قىلىنغان جاۋابى بار نومۇرلانغان قارارلارنى قوشىدۇ: ساقلىنىدىغان بىرلىكلەر، توسۇلغان بىرلىكلەر، crate ى يوق ياكى قىسمەن بار بېقىنىشلار.

## 2. پۈتۈن ئەپنى خاتىرىلەڭ، ئاندىن كىرىش نۇقتىسىنى يۆتكەڭ

1. [`app record` ۋە `app replay`](/docs/whole-apps/record-replay) پروگراممىنى سىرتتىن، قارا قۇتا سۈپىتىدە ئىسپاتلايدۇ.
2. [`app front-door`](/docs/whole-apps/front-door) ئەسلى نۇسخىنىڭ ئالدىغا بىر Rust ئىككىلىك ھۆججىتىنى قويىدۇ؛ ھەر بىر بۇيرۇق يەنىلا ئەسلى نۇسخىنى ئىجرا قىلىدۇ.
3. ھەر بىر بىرلىك [ئايلانما](/docs/concepts/the-loop) دىن ئۆتىدۇ، ئاندىن `app wire` ئۇنىڭ بۇيرۇقلىرىنى Rust قا تاپشۇرىدۇ.
4. قايتا قويۇش زاپاس يول نىسبىتى 0 بىلەن ئۆتۈپ، ھەر بىر بىرلىك gate دىن ئۆتكەندە، [`app lift`](/docs/whole-apps/lift) ئەسلى نۇسخىنى چىقىرىۋېتىدۇ.

[مۇلازىمېتىرلار](/docs/whole-apps/servers) ۋە [كۇتۇپخانىلار](/docs/whole-apps/libraries) ئوخشاش بۇيرۇقلارنى ئىشلىتىدۇ.

## ۋاكالەتچى ئۇنى قانداق بېسىپ ئۆتىدۇ

[پۈتۈن ئەپ ماھارىتى](https://github.com/marprojector/everything-rust/blob/main/skills/everything-rust/whole-app.md) ۋاكالەتچىنى ئۇنىڭدىن باشلاپ يېتەكلەيدۇ، ئالدى بىلەن پەقەت سىزلا قىلالايدىغان قارارلاردىن باشلايدۇ:

- **سوراق قىلىش**: ۋاكالەتچى ھەر بىر سوئالنى تەۋسىيە قىلىنغان جاۋابى بىلەن بىرلىكتە نۆۋەت بىلەن سورايدۇ، كۆچۈرۈش تايىنىدىغان ھەر بىر قارار ھەل بولغۇچە، ھەمدە ھەر بىرىنى `rust/DECISIONS.md` غا ADR سۈپىتىدە يازىدۇ، `rust/GLOSSARY.md` بولسا ئەسلى نۇسخىنىڭ ئاتالغۇلىرىنى Rust ناملىرىغا ماسلاشتۇرىدۇ.
- **تەتقىقات**: ئارقا سۇپا ۋاكالەتچىلىرى ھەر بىر بېقىنىشنىڭ ئەسلى مەنبەلىرىنى ئوقۇپ، تاپقان ھەر بىر مەنە تۇزىقى بىلەن `rust/research/<topic>.md` نى يازىدۇ.
- **سۆھبەتلەر ئارا**: `rust/MAP.md` ھەر بىر بىرلىكنى ھالىتى بىلەن كۆرسىتىدۇ؛ بىر سۆھبەت باشلاشتىن بۇرۇن بىر بىرلىكنى ئۆزىگە ئالىدۇ، ھەر بىر تەكشۈرۈش نۇقتىسى كېيىنكى سۆھبەت ئۈچۈن `rust/HANDOFF.md` قالدۇرىدۇ. بىر دولقۇندىكى بىرلىكلەرنى تارماق ۋاكالەتچىلەر پاراللېل كۆچۈرەلەيدۇ.
- **ئالماشتۇرۇش**: ۋاكالەتچى قولىدىن كېلىدىغاننى قىلىپ، `rust/cutover.sh` نى يازىدۇ، بۇ پەقەت سىزلا قىلالايدىغان قەدەملەر (ئورۇنلاشتۇرۇش، DNS، مەخپىي ئاچقۇچلار) ئۈچۈن ئۆز-ئارا تەسىرلىك قوليازما بولۇپ، ھەر بىر قەدەمدە قايتىش يولى بار.

سوراق قىلىش، تەتقىقات ۋە بۇ ئادەتلەر [Matt Pocock نىڭ ماھارەتلىرى](https://github.com/mattpocock/skills) دىن ماسلاشتۇرۇلغان.

## ئۇ Rust نى كونا لايىھەگە باغلاپ قويمامدۇ؟

پەقەت ھەر ئىككىسى يانمۇيان ئىجرا بولۇۋاتقاندىلا. خاتىرىلەر ئەپنىڭ ئىچكى قىسمىنى ئەمەس، چېگرىلىرىدىكى ھەرىكەتنى (CLI نىڭ چىقىرىشى، مۇلازىمېتىرنىڭ جاۋابلىرى، مودۇلنىڭ چىقىرىلغان فۇنكسىيەلىرى) تەكشۈرىدۇ. بىرلىكلەر يەنىلا كۆۋرۈكتىن ئۆتۈۋاتقاندا كونا قۇرۇلمىنى ئەينەن ساقلاڭ؛ `app lift` ئەسلى نۇسخىنى چىقىرىۋەتكەندىن كېيىن، Rust نى ئەركىن قايتا قۇرۇلمىلاڭ، `app replay` يەنىلا ھەرىكەتنى ئىسپاتلايدۇ.

## ھەقىقىي بىر مىسال

[json-server](/docs/real-world/json-server) ھەر بىر قەدەمدىن ئۆتتى: 514 خاتىرىلەنگەن HTTP ئەھۋالى، 99.8% زاپاس يولدىكى ئالدى ئىشىك، ئالدى بىلەن ئوقۇشلار ئۇلاندى (22.6% زاپاس يول)، ئاندىن ھەر بىر يول (0%)، ۋە 514/514 دىن ئۆتىدىغان ساپ Rust ئىككىلىك ھۆججىتىگە lift.
