# خاتىرىلەش ۋە قايتا قويۇش

`record` ۋە `diff` بىر بىرلىكنى ئىسپاتلايدۇ؛ `app record` ۋە `app replay` ئالتە تىلنىڭ ھەر قايسىسىدىكى CLI ۋە مۇلازىمېتىرلار ئۈچۈن ئەپنى ئىسپاتلايدۇ. ئەپ بىر قارا قۇتا.

```sh
everything-rust app record . -- python3 cli.py          # ئەسلى نۇسخىنى ئىجرا قىلىدىغان بۇيرۇق
everything-rust app replay .                            # ئەسلى نۇسخا 100% ئۆتۈشى كېرەك
everything-rust app replay . --build "target/release/mytool"
```

## ئەھۋاللار قەيەردىن كېلىدۇ

`app record` ئەسلى نۇسخىنى تۆۋەندىكىلەردە ئىجرا قىلىدۇ:

- ئەپنىڭ ئۆز ھۆججەتلەشتۈرۈلگەن مىساللىرى: Markdown ۋە shell ھۆججەتلىرىدىكى `$ mytool ...` قۇرلىرى، ئۇلار ئاتىغان ھۆججەتلەر بىلەن؛
- بىر `--inputs` JSONL ھۆججىتى، ھەر بىر قۇردا بىر `{"name", "args", "stdin", "env", "files"}`؛
- شۇ ئەھۋاللاردىن چىقىرىلغان مەنە تۇزاقلىرى: ASCII بولمىغان ۋە emoji قۇرلىرى، مەنپىي بۆلۈش ۋە قالدۇق، تېشىپ كېتىش، چوڭ ۋە كىچىك لەيلىمە سانلار، map تەرتىپى، يوق ھۆججەتلەر.

ھەر بىر ئەھۋال ئىككى قېتىم ئىجرا بولىدۇ؛ ئىككى ئىجرا ئارىسىدا پەرقلىنىدىغان نەرسە `[..]` ئورۇنباسارىغا ئايلىنىدۇ. `--normalize timestamps|uuids|key-order` ياكى `--normalize name=regex` ئەھۋاللار بىلەن بىللە ساقلىنىدىغان نورماللاشتۇرغۇچلارنى قوشىدۇ. `app record` نېمىنىڭ پەرقلەنگەنلىكىنى تۈرى بويىچە دوكلات قىلىدۇ: قىممەتلەر (ھازىر ئورۇنباسارلار)، تەرتىپ (قۇرلار ھەر قانداق تەرتىپتە سېلىشتۇرۇلىدۇ) ۋە قۇرلار (ھەر قانداق نەرسىگە ماس كېلىدىغان `...`). ھەر بىرىگە قاراپ چىقىڭ.

## ئەھۋاللار ئاددىي ھۆججەتلەر

ئەھۋاللار `rust/app-cases/` دىكى [trycmd](https://docs.rs/trycmd) ھۆججەتلىرى:

| ھۆججەت | ئىچىدىكىسى |
| --- | --- |
| `<case>.toml` | argv، مۇھىت، چېكىنىش كودى |
| `<case>.stdin` | ئۆلچەملىك كىرگۈزۈش |
| `<case>.stdout`، `<case>.stderr` | ئەسلى نۇسخا بېسىپ چىقارغان نەرسە |
| `<case>.in/` | كىرگەن ھۆججەتلەر |
| `<case>.out/` | يېزىلغان ھۆججەتلەر |

ئۇلارنى قولدا ئوقۇپ تەھرىرلەڭ؛ كۆچۈرمىنىڭ ئىككىلىك ھۆججىتى بولغاندىن كېيىن، بىر Rust سىنىقى ئۇلارنى `trycmd` بىلەن ئىجرا قىلالايدۇ.

## قايتا قويۇش

- `app replay` ھەر قانداق قۇرۇلمىنى ئەھۋاللارغا قارىتا ئىجرا قىلىدۇ، `passed/total` نى بېسىپ چىقىرىدۇ، مەغلۇپ بولغان ھەر بىر ئەھۋال ئۈچۈن diff بىلەن `rust/app-cases/replay-report.md` نى يازىدۇ، ھەر قانداق ماس كەلمەسلىكتە نۆلدىن پەرقلىق كود بىلەن چېكىنىدۇ.
- [ئالدى ئىشىك](/docs/whole-apps/front-door) قىلغاندەك، `EVERYTHING_RUST_FALLBACK_LOG` ئاتىغان ھۆججەتكە قوشۇپ يازىدىغان قۇرۇلما (ئەسلى نۇسخىغا ھەر بىر زاپاس يول ئۈچۈن بىر قۇر) زاپاس يول نىسبىتىنىمۇ دوكلات قىلدۇرىدۇ.
- `app replay --case <name>` دوكلات بەرگەن نام بىلەن بىر ئەھۋالنى قايتا ئىجرا قىلىدۇ: ھەممىنى قايتا ئىجرا قىلىشتىن بۇرۇن بىر ماس كەلمەسلىكنى تۈزىتىشنىڭ تېز، قايتىلاشقا بولىدىغان ئايلانمىسى.

## CI دا قايتا قويۇش

دوكلاتتا ۋاقىت ياكى ۋاقىتلىق يول يوق: ئوخشاش قۇرۇلمىنى ئىككى قېتىم قايتا قويۇش ئوخشاش ھۆججەتنى يازىدۇ. ئۇنى commit قىلىڭ، ئاندىن CI دا ئىجرا قىلىڭ:

```sh
everything-rust app replay .
git diff --exit-code rust/app-cases/replay-report.md
```

شۇنىڭ بىلەن يېرىم كۆچۈرۈلگەن ئەپ ئۆتىدىغان نەرسىدىكى ھەر قانداق ئۆزگىرىشتە (ياخشىلانسۇن ياكى ناچارلاشسۇن)، دوكلات شۇنىڭغا ماس يېڭىلانمىغۇچە، CI دا مەغلۇپ بولىدۇ.

## سان چىقىرىش

`app record --float-tolerance 1e-9` سانلارنىڭ چوڭراق قىممەتنىڭ شۇ ئۈلۈشى ئىچىدە ماس كېلىشىگە يول قويىدۇ. [لەيلىمە چېكىت يول قويۇشى](/docs/concepts/float-tolerance) نى كۆرۈڭ.
