# ئالدى ئىشىك ۋە ئالاقە

ئالدى بىلەن كىرىش نۇقتىسىنى Rust قا يۆتكەڭ، ئاندىن بۇيرۇقلارنى ئۇنىڭغا بىر قېتىمدا بىر بىرلىكتىن تاپشۇرۇڭ:

```sh
everything-rust app front-door .                            # rust/app: ھەر بىر بۇيرۇق ئەسلى نۇسخىنى ئىجرا قىلىدۇ
everything-rust app wire . textkit --command upper          # textkit-rs gate دىن ئۆتكەندىن كېيىن
# rust/app/src/units/textkit.rs دا يېپىشتۇرغۇچ كودنى يېزىڭ، ئاندىن:
everything-rust app wire . textkit                          # يەنە 100%، زاپاس يول نىسبىتى تۆۋەنرەك
```

## ئالدى ئىشىك

`app front-door` `rust/app` نىڭ ئاساسىنى قۇرىدۇ، ئۇ ئەپنىڭ نامى بىلەن ئاتالغان بىر Rust ئىككىلىك ھۆججىتى: خاتىرىلەنگەن ئەھۋاللاردىكى بۇيرۇق ۋە بەلگىلەر ئۈچۈن بىر clap تەھلىلچىسى، بۇ يەردە ھەر بىر بۇيرۇق ئەسلى نۇسخىنى ئوخشاش argv، stdin ۋە مۇھىت بىلەن ئىجرا قىلىپ، ئۇنىڭ چىقىرىشى ۋە چېكىنىش كودىنى ئۆتكۈزۈۋېتىدۇ. ھەر بىر زاپاس يول سانىلىدۇ، شۇڭا يېڭى ئالدى ئىشىكنى قايتا قويۇش 100% زاپاس يولدا 100% ئۆتۈش بېرىدۇ (ئۇ بۇنى كۆرسىتىش ئۈچۈن قۇرۇپ قايتا قويىدۇ). ئۇ ھەرگىز `rust/app` نى قاپلىمايدۇ: شۇنىڭدىن باشلاپ كود سىزنىڭ.

## بىر بىرلىكنى ئۇلاش

`app wire <repo> <unit> --command <name>`:

1. بىرلىك crate ىدا `gate` نى ئىجرا قىلىدۇ (ئەگەر ئۇ يېڭىلا ئۆتكەن بولسا `--skip-gate`)؛
2. ئۇنى `rust/app` قا كۇتۇپخانا سۈپىتىدە قوشىدۇ؛
3. `src/units/<unit>.rs` نى بىر قېتىم يازىدۇ، سىز ياكى ۋاكالەتچىڭىز تولدۇرىدۇ: پارامېتىرلارنى تەھلىل قىلىش، `<crate>::port` نى چاقىرىش، ئەسلى نۇسخا بېسىپ چىقارغاننى بېسىپ چىقىرىش؛
4. بۇيرۇقلارنى ئۇنىڭغا يۆنىلىشلەيدۇ، ئاندىن قۇرۇپ قايتا قويىدۇ.

يېپىشتۇرغۇچ كودنى يازغاندىن كېيىن ئۇنى قايتا ئىجرا قىلىڭ: 100% ئۆتۈش ۋە تۆۋەنرەك زاپاس يول نىسبىتى. `EVERYTHING_RUST_UNIT_<NAME>=original` ئۇلانغان بىرلىكنى lift قا قەدەر ئەسلى نۇسخىغا قايتۇرىدۇ.

ھېچقانداق بۇيرۇقنى ئاتىمايدىغان argv (پارامېتىرسىز، نامەلۇم بۇيرۇقلار، ئىشلىتىش خاتالىقلىرى) ئۈچۈن ئەپنىڭ ئۆز نامىنى بۇيرۇق سۈپىتىدە ئۇلاڭ (`--command mytool`).

## ھېچنېمە ئەسلى نۇسخىغا قايتا چاقىرمايدۇ

ئالدى ئىشىك ئەسلى نۇسخىنى ئايرىم جەريان سۈپىتىدە ئىجرا قىلىدۇ (ياكى HTTP نى ئۇنىڭغا ئۇلاپ يېتەكلەيدۇ)، كۆۋرۈكلەنگەن بىرلىكلەرنى ئەسلى نۇسخا چاقىرىدۇ، ھەرگىز ئەكسىچە ئەمەس، قايتا چاقىرىش (callback) لار مەنبە تىلدا قالىدۇ.

مۇلازىمېتىرلار بۇيرۇق ئورنىغا يوللارنى ئىشلىتىدۇ: [مۇلازىمېتىرلار](/docs/whole-apps/servers) نى كۆرۈڭ. كۇتۇپخانىلار ئۆزلىرىنىڭ ئاممىۋى API سىنى ئىشلىتىدۇ: [كۇتۇپخانىلار](/docs/whole-apps/libraries) نى كۆرۈڭ.
