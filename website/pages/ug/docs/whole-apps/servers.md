# مۇلازىمېتىرلار

ئوخشاش بۇيرۇقلار HTTP مۇلازىمېتىرلىرىنى ئىسپاتلايدۇ. `--http` بۇيرۇقنىڭ مۇلازىمېتىر قوزغىتىدىغانلىقىنى بىلدۈرىدۇ؛ ئۇ ئېغىزنى
`PORT` تىن ياكى بۇيرۇقتىكى `{port}` تىن ئالىدۇ (ھەمىشە ئوخشاش ئېغىزدا ئاڭلايدىغان مۇلازىمېتىر ئۈچۈن `--port`):

```sh
everything-rust app record . --http -- node server.js
everything-rust app replay .
everything-rust app front-door .                                    # axum: ھەر بىر يول ئۇلاپ يېتەكلىنىدۇ
everything-rust app wire . api --route 'GET /users/{id}' --route '*'
everything-rust app lift .
```

- تەلەپلەر ئەپ ھۆججەتلىرىدىكى `curl` قۇرلىرىدىن (`curl -X POST -d ... http://localhost:8080/x`)،
  `--inputs` (`{"name", "method", "path", "headers", "body"}`) ۋە تۇزاقلاردىن كېلىدۇ: يول بۆلەكلىرى ۋە سۈرۈشتۈرۈش
  قىممەتلىرى CLI پارامېتىرلىرى بىلەن ئوخشاش تۇزاقلارغا ئالماشتۇرۇلىدۇ، گەۋدىلەر تېكىست ۋە JSON تۇزاقلىرىغا، ھەمدە بىر
  نامەلۇم يول. ھەر بىر ئىجرا مۇلازىمېتىرنى يېڭىدىن قوزغىتىپ، تەلەپلەرنى نام تەرتىپى بويىچە ئەۋەتىدۇ، شۇڭا
  تەلەپلەر ئارىسىدىكى ھالەت ساقلىنىدۇ.
- ھالەتنى ھۆججەتلەردە ساقلايدىغان مۇلازىمېتىر ھەر قېتىم قوزغالغاندا يېڭى نۇسخىغا ئېرىشىدۇ: `--fresh db.json` (ھۆججەت
  ياكى قىسقۇچ، قايتىلاشقا بولىدۇ) `http/files/` قا سۈرەتكە ئېلىنىدۇ ۋە ئەسلى نۇسخا، ئالدى ئىشىك ياكى بىر قۇرۇلما
  ھەر قېتىم قوزغالغاندا يېڭى خىزمەت مۇندەرىجىسىگە كۆچۈرۈلىدۇ؛ `--arg db.json` ھەر بىر قوزغىلىشتا بۇيرۇقتىن كېيىن
  بېرىلىدىغان پارامېتىر، شۇڭا Rust ئىككىلىك ھۆججىتى ئەسلى نۇسخىدەك قوزغىتىلىدۇ.
  `--pace 50` ھەر بىر جاۋابتىن كېيىن 50 ms ساقلايدۇ، مۇلازىمېتىر جاۋاب بەرگەندىن كېيىن قىلىدىغان ئىش ئۈچۈن (ئۆزى يېڭىلا يازغاننى
  قايتا يۈكلەيدىغان ھۆججەت كۆزەتكۈچى).
- ئەھۋاللار `rust/app-cases/http/<case>.toml` (تەلەپ، ھالەت كودى ۋە مۇھىم ماۋزۇلار)
  ۋە `<case>.body` (جاۋاب گەۋدىسى، ئىككى ئىجرا پەرقلەنگەن جايلاردا `[..]` بىلەن). Date، server ۋە
  ھەر بىر جاۋابقا خاس باشقا ماۋزۇلار چىقىرىۋېتىلىدۇ؛ كېرەكسىز ھەر قانداق ماۋزۇ قۇرىنى ئۆچۈرۈڭ.
- ئالدى ئىشىك بىر axum مۇلازىمېتىرى بولۇپ، ئۇ ئەسلى نۇسخىنى ئۆزىنىڭ ئېغىزىدا قوزغىتىپ، ھېچقانداق بىرلىك جاۋاب بەرمەيدىغان
  ھەر بىر يولنى ئۇنىڭغا ئۇلاپ يېتەكلەيدۇ. `wire --route` axum يوللىرىنى قوبۇل قىلىدۇ: `METHOD /path/{param}`، ھەر قانداق مېتود ئۈچۈن `/path`،
  قالغان ھەممىسى ئۈچۈن `*`؛ يېپىشتۇرغۇچ كود يول، ئۇنىڭ پارامېتىرلىرى ۋە
  تەلەپنى ئالىدۇ. `lift` ئۇلاپ يېتەكلىگۈچنى چىقىرىۋېتىدۇ؛ ئاندىن HTTP ئەھۋاللىرى CI دا `app replay` بىلەن ئىجرا بولىدۇ.
## ھەقىقىي بىر مىسال

[json-server](/docs/real-world/json-server) غا `--fresh`، `--arg` ۋە `--pace` كېرەك بولدى: ئۇ ھەر بىر يېزىشتا ساندانىنى قايتا يازىدۇ، ئۇنىڭ ھۆججەت كۆزەتكۈچىسى تېزلا كەينىدىن كەلگەن يېزىشنى ئەمەلدىن قالدۇرۇۋېتىشى مۇمكىن.
