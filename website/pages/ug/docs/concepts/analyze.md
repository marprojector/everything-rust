# ئانالىز ۋە تەھلىل

## Profile: يۆتكەشكە ئەرزىيدىغاننى تېپىش

نىشان سۈرئەت بولسا، ھەر قانداق نەرسىنى تاللاشتىن بۇرۇن ئۆلچەڭ:

```sh
everything-rust profile <repo> -- node bench.mjs      # ياكى: python3 bench.py، ruby bench.rb،
                                                    #     java -cp out Main، go test -run X -bench . ./pkg
```

`profile` ھەقىقىي خىزمەت يۈكىنى تىلنىڭ ئانالىزاتورى (node، cProfile، `go test` pprof، JFR، بىر Ruby ئىز قوغلىغۇچى) ئاستىدا ئىجرا قىلىپ، قىزىق فۇنكسىيەلەرنى ئۆز ئىچىگە ئالغان ۋاقىت بويىچە، ئۇلارنىڭ چاقىرغۇچىلىرى ۋە قايسى ئايلانمىلارنى توپلاش كېرەكلىكى بىلەن كۆرسىتىدۇ. Go پەقەت `go test` ئارقىلىقلا ئانالىز قىلىنىدۇ؛ C قوللانمايدۇ.

- ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم چاقىرىلىدىغان كىچىك فۇنكسىيەنى يالغۇز كۆچۈرۈشكە **ئەرزىمەيدۇ**: Rust قا بىر قېتىم چاقىرىش ئۇنىڭ ئىشىدىن قىممەت، JIT لار (V8، JVM، Go) ئۇنى نانوسېكۇنتلاردا ئىجرا قىلىدۇ. ئۇنى چاقىرغۇچىلىرى بىلەن بىللە كۆچۈرۈڭ، ياكى [توپلاڭ](/docs/concepts/batches). تەۋسىيە قۇرى قايسىسى ئىكەنلىكىنى ئېنىق بۇيرۇق بىلەن ئېيتىدۇ.
- ئاللىقاچان تۈزۈلگەن كود (numba `@njit`، Cython، `@jax.jit`) ماشىنا كودى بولۇپ ئىجرا بولىدۇ: Rust كۆچۈرمىسى ئاز سۈرئەت ئالىدۇ. `profile` ئۇنى "Already compiled" ئاستىدا كۆرسىتىدۇ.

## Analyze: كۆچۈرۈشنى پىلانلاش

```sh
everything-rust analyze <repo> -o plan.md        # ئادەملەر ئۈچۈن
everything-rust analyze <repo> --json            # ۋاكالەتچىلەر ئۈچۈن: schema everything-rust/analyze@1
everything-rust analyze <repo> --whole-app       # قوشۇمچە كىرىش نۇقتىلىرى، شەكىل، بېقىنىشلار، قارارلار
```

`analyze` بىرلىكلەرنى، كۆچۈرۈش تەرتىپىنى، `file:line` بىلەن خەتەرلەرنى، ھەر بىر بىرلىكنىڭ كۆۋرۈكىنى، ھەر بىر بېقىنىشنىڭ crate قا قانچىلىك ماس كېلىدىغانلىقىنى، ۋە `start_here` نى (ئەڭ ياخشى تۇنجى كۆچۈرمىلەر) كۆرسىتىدۇ. `--whole-app` ئەپنىڭ شەكلى (CLI، مۇلازىمېتىر ياكى كۇتۇپخانا) ۋە كىرىش نۇقتىلىرىنى، ھەر بىر بېقىنىشنى (import قىلىنغان ياكى ئېلان قىلىنغان) ئۇنىڭ crate ى بىلەن، پارچىلارنى (بىر-بىرىنى import قىلىدىغان بىرلىكلەر بىللە يۆتكىلىدۇ) ۋە تەۋسىيە جاۋابى بار نومۇرلانغان قارارلارنى قوشىدۇ. [پۈتۈن ئەپنى كۆچۈرۈش](/docs/whole-apps/overview) نى كۆرۈڭ.

- بوغچىلار (`package.json`) ۋە مەنبە ھۆججەتلىرى؛ `node_modules`، قۇرۇلما چىقىرىشى، سىناق ماتېرىياللىرى،
  playground لار، قورال تەڭشەكلىرى ئاتلاپ ئۆتۈلىدۇ. Vue/Svelte/Astro `<script>` بۆلەكلىرى import لار ئۈچۈن تەھلىل قىلىنىدۇ.
- **بىرلىكلەر**: مەنبە ھۆججەتلىرىدىن تەركىب تاپقان قىسقۇچ، ياكى بوغچىنىڭ مەنبە يىلتىزىدىكى بىر ھۆججەت.
- **دولقۇنلار**: بىر بىرلىكنىڭ import لىرى ئالدىنقى دولقۇنلاردا كېلىدۇ؛ import ئايلانمىلىرى بىللە كۆچۈرۈلىدۇ.
- **كۆۋرۈك**: بىرلىك ياكى ئۇ import قىلغان ھەر قانداق نەرسىگە Node كېرەك بولسا napi-rs؛ كۆچمە
  كود ئۈچۈن wasm-bindgen؛ UI ۋە تەھرىرلىگۈچ كودى JS تا قالىدۇ.
- **تەييارلىق** (قانچىلىك بىخەتەر) ۋە **ئالدىنلىق** (بىخەتەر ۋە ئەرزىيدىغان: ئايلانمىلار ۋە قۇر ئىشلىرى، سىناقلار، چوڭلۇق).

| خەتەر | ئېغىرلىقى | مىسال |
| --- | --- | --- |
| قۇر ئورۇن ئىلگىرىلەشلىرى | يۇقىرى | `slice`، `indexOf`، `matchAll`، `d` بەلگىسى: UTF-16 ۋە UTF-8 |
| Regex گىرامماتىكىسى | يۇقىرى | lookaround، backreference، `y`: `regex` crate ىدا يوق |
| ھەرىكەتچان regex | يۇقىرى | `new RegExp(userPattern)`: ئىجرا ۋاقتىدىكى JS گىرامماتىكىسى |
| ھەرىكەتچان كود | يۇقىرى | `eval`، `new Function`، ھېسابلانغان `import()` |
| ھەرىكەتچان تىپلاش | ئوتتۇرا | `any`، `'key' in value` |
| تەرتىپلىك توپلاملار | ئوتتۇرا | `Map`، `Set`، `Object.keys`: قىستۇرۇش تەرتىپى |
| Async، generator لار | ئوتتۇرا | promise ۋە generator چېگرىلىرى |
| سىنىپ ۋارىسلىقى، reflection | ئوتتۇرا | `extends`، `Proxy`، `Reflect`، `Symbol` |
| callback شەكىللىك API لار | ئوتتۇرا | فۇنكسىيە تىپلىق پارامېتىر ۋە مېتودلار: سۆزمەن كۆۋرۈكلەر |
| مۇستەسنالار، سانلار، JSON | تۆۋەن | `throw`، bit مەشغۇلاتلىرى، `JSON.stringify` تەرتىپى |
## بېقىنىشلار ئۈچۈن crate لار

`analyze` كود import قىلغان ھەر بىر كۇتۇپخانا ئۈچۈن Rust crate ىنى `good`، `partial` ياكى `none` ماسلىقى بىلەن ئاتايدۇ. جەدۋىلىدە يوق كۇتۇپخانا `unknown` دەپ دوكلات قىلىنىدۇ؛ جەدۋەل ھەرگىز crate پەرەز قىلمايدۇ. بىرنى قوشۇش ئۈچۈن [تۆھپە قوشۇش](/docs/project/contributing#add-a-crate-mapping) نى كۆرۈڭ.
