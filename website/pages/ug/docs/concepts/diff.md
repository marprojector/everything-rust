# پەرق ۋە مەلۇم پەرقلەر

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # چوقۇم N/N بولۇشى كېرەك
everything-rust diff <crate> --json
```

`diff` `cases.jsonl` نى قۇرۇلغان Rust مودۇلىدا، ئەسلى نۇسخىنىڭ چاقىرغۇچىلىرى چاقىرغاندەك چاقىرىپ قايتا قويىدۇ، ھەمدە ماس كەلمەسلىكلەرنى كۆرسىتىدۇ. ماس كەلمەسلىك ھەرىكەت پەرقىدۇر: خاتىرىنى ئەمەس، ھەرگىز كۆچۈرمىنى تۈزىتىڭ.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## مەلۇم پەرقلەر

بەزىدە كۆچۈرمە قەستەن پەرقلىنىدۇ: ئىشلەتكۈچى ئۇنىڭ ئەسلى نۇسخىدىكى بىر خاتالىقنى تۈزىتىشىنى خالايدۇ. ئالدى بىلەن سوراڭ، ئاندىن ھەر بىر ئەھۋال ئۈچۈن `<crate>/known-diffs.jsonl` غا بىر قۇر قوشۇڭ:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

`fn`، `args` ۋە `actual` نى `diff --json` دىن كۆچۈرۈڭ. ئاندىن بۇ ئەھۋال پەقەت شۇ نەتىجە بىلەنلا ئۆتىدۇ، پەرقلەنمەي قالغاندا `gate` مەغلۇپ بولىدۇ، شۇ چاغدا قۇرنى ئۆچۈرۈڭ.

## كونىراپ كەتكەن خاتىرىلەر

`record` ئەسلى بىرلىك ھۆججەتلىرىنىڭ بارماق ئىزىنى `recorded-from.json` دا ساقلايدۇ. ئەسلى نۇسخا كېيىن ئۆزگەرسە، ئەسلى نۇسخىنىڭ ئىلگىرى قىلغىنىغا قارىتا ئۆتۈپ كېتىشنىڭ ئورنىغا، قايتا خاتىرىلىمىگۈچە `diff` ئاگاھلاندۇرىدۇ، `gate` مەغلۇپ بولىدۇ. ئەگەر `gate` خاتىرە كونىراپ كەتتى دېسە، داۋاملىق كۆچۈرۈشتىن بۇرۇن قايتا خاتىرىلەڭ.

## كۆچۈرۈش توختاپ قالغاندا

`diff` قۇرۇلمىلار ئارا ئىلگىرىلەشنى ئىز قوغلايدۇ. ئۇ كۆچۈرۈش توختاپ قالدى دېسە (ئۇنىڭ `trend.stalled` ى: `port.rs` تىكى ئارقا-ئارقىدىن ئۈچ ئۆزگىرىش ھېچقانداق ماس كېلىدىغان ئەھۋال قوشمىدى)، تەھرىرلەشنى توختىتىڭ. قالغان ماس كەلمەسلىكلەرگە پەقەت ئىشلەتكۈچىلا بىلىدىغان قائىدە كېرەك بولۇشى مۇمكىن، ياكى ئۇ فۇنكسىيەلەر ھازىرچە ئەسلى نۇسخىدا قېلىشى مۇمكىن.

## لەيلىمە چېكىت يول قويۇشى

ئەگەر crate `--float-tolerance` بىلەن خاتىرىلەنگەن بولسا، `diff` ئۇنى ئىشلىتىدۇ؛ `diff` تىكى `--float-tolerance` ئۇنى بىر قېتىملىق ئىجرا ئۈچۈن قاپلايدۇ. [لەيلىمە چېكىت يول قويۇشى](/docs/concepts/float-tolerance) نى كۆرۈڭ.
