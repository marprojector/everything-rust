# سىناق ئۆلچىمى

```sh
everything-rust bench <crate>
```

`bench` خاتىرىلەنگەن ئەھۋاللارنى ئەسلى نۇسخا ۋە قۇرۇلغان Rust مودۇلىدا، كۆۋرۈكنى قوشۇپ ۋاقىت ئۆلچەيدۇ، ھەمدە قۇرلار ۋە تەۋسىيەلىك ھۆكۈمنى قايتۇرىدۇ: ئېلان قىلىش، ئاستاراق فۇنكسىيەلەرنى مەنبە تىلدا قالدۇرۇش، ياكى چوڭراق بىرلىكنى كۆچۈرۈش. 1 دىن تۆۋەن تېزلىنىش كۆچۈرمىنىڭ چاقىرغۇچىلىرى چاقىرغاندەك چاقىرىلغاندا ئاستا ئىكەنلىكىنى بىلدۈرىدۇ. `--min-ms` ھەر بىر فۇنكسىيە ۋە تەرەپ ئۈچۈن ئەڭ ئاز ئۆلچەش ۋاقتىنى بەلگىلەيدۇ (سۈكۈتتىكىسى 200).

ھۆكۈمگە ئەمەل قىلىڭ. چاقىرغۇچىلارنى ئاستىلىتىدىغان كۆچۈرمىنى بۇنى ئېيتماي تۇرۇپ ئېلان قىلماڭ.

## كۆچۈرمە نېمە ئۈچۈن ئاستا بولۇشى مۇمكىن

ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم چاقىرىلىدىغان كۆچۈرمە ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم كۆۋرۈك ھەققى تۆلەيدۇ. بۇنى بەلگىلەيدىغىنى:

- **ئىزاھلانغان ئەسلى نۇسخىلار (Python، Ruby)**: Rust قا چاقىرىش تەخمىنەن 100-300 ns، Rust كودى ئىزاھلىغۇچتىن خېلىلا تېز، شۇڭا كىچىك فۇنكسىيەلەرمۇ ئۇتىدۇ.
- **تۈزۈلگەن ئەسلى نۇسخىلار (Go، JIT تىن كېيىنكى Java)**: ئەسلى ياپراق فۇنكسىيە 4-90 ns ئالىدۇ؛ بىر cgo چاقىرىقىنىڭ ئۆزىلا تەخمىنەن 80 ns، قۇر بار JNI چاقىرىقى تېخىمۇ كۆپ. بۇ تىللار پەقەت بىر چاقىرىش نۇرغۇن ئىش قىلغاندىلا پايدا ئالىدۇ: فۇنكسىيەنى چاقىرغۇچىلىرى بىلەن بىللە كۆچۈرۈڭ.
- **C**: ھېچقانداق ئۆتۈش يوق؛ Rust كودى C كودى بىلەن بىۋاسىتە سېلىشتۇرۇلىدۇ.

ھەقىقىي كودتا ھەر چاقىرىشتا ئۆلچەنگىنى ([ئالتە تىل](/docs/real-world/six-languages)):

| تىل | Rust ئەسلىگە نىسبەتەن (`bench`، گېئومېترىيەلىك ئوتتۇرىچە) | ھۆكۈم |
| --- | --- | --- |
| Ruby | **4.4x تېز** (ھەر بىر فۇنكسىيەدە 3.6-7x) | ئېلان قىلىش |
| Python | **1.35x تېز** (كۆپ چاقىرىشلاردا 1.5-1.9x) | ئېلان قىلىش |
| C | 0.87x: ctype 1.1-1.4x تېز، glibc نىڭ ئەلالاشتۇرۇلغان `strtod`، `strspn`، `strcmp` لىرى 0.5-0.7x | ئەلالاشتۇرۇش ياكى ئاستىلىرىنى قالدۇرۇش |
| Java | 0.18x | چوڭراق بىرلىكلەرنى كۆچۈرۈش |
| Go | 0.04x | چوڭراق بىرلىكلەرنى كۆچۈرۈش |

x18n يادروسىدىكى API ئۆزگەرتمەي يۆتكىگىلى بولىدىغان 29 فۇنكسىيەنىڭ ھەممىسى كۆچۈرۈلدى: ھەر بىر gate ئۆتىدۇ، 7,925 خاتىرىلەنگەن ئەھۋال تامامەن ماس كېلىدۇ، ئەمما `bench` كۆچۈرمىلەرنىڭ JS تىن چاقىرىلغاندا TS تىن ئاستا ئىكەنلىكىنى كۆرسەتتى، چۈنكى كۆۋرۈك ئىشتىن قىممەت ([دوكلات](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-core/README.md)). vercel/ms خاتىرىلەنگەن ئەھۋاللىرى ئۈستىدە ھەر چاقىرىشتا 0.56x ئىجرا بولدى ([مىسال تەتقىقاتى](/docs/real-world/vercel-ms)).

## ئۇتىدىغىنى: ئايلانمىنى يۆتكەش

`profile` قىزىق فۇنكسىيەنىڭ ئەتراپىدىكى ئايلانمىنى تاپىدۇ، `--batch` بولسا پۈتۈن ئايلانمىنى بارلىق يادرولاردا Rust قا يۆتكەيدۇ. [توپ ۋە قىزىق يوللار](/docs/concepts/batches) نى كۆرۈڭ.

::: tip تىنچ ماشىنىدا ئۆلچەڭ
`bench` نى تىنچ ماشىنىدا ئىجرا قىلىڭ، ئىككى قېتىم ئىجرا قىلىڭ، ھەمدە ئېلان قىلىنغان ھەر بىر ساننىڭ يېنىغا قاتتىق دېتال ۋە يادرو سانىنى يېزىڭ.
:::
