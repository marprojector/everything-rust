# كۆۋرۈك

```sh
everything-rust bridge <repo> <unit-id>          # <repo>/rust/<name> دىكى crate؛ ھەرگىز قاپلىمايدۇ
everything-rust refresh <crate>                  # port.rs دىكى بىر ئىمزانى ئۆزگەرتكەندىن كېيىن
```

`bridge` باغلىنىشلار (`lib.rs`، شۇنداقلا مەنبە تىل يۈكلەيدىغان ئوراما) ۋە كۆچۈرۈلىدىغان قۇرۇق قېلىپلار (`port.rs`) بار crate قۇرىدۇ. كۆچۈرمىنى پەقەت `src/port.rs` تىلا يازىسىز؛ `src/lib.rs` ۋە ئورامىلار ھاسىل قىلىنىدۇ، `refresh` ئۇلارنى `port.rs` دىكى ئىمزالاردىن قايتا ھاسىل قىلىپ، ھەر قانداق يېڭى توپ سىنىپلىرىنى قوشىدۇ. ئۇ ھەرگىز `port.rs` قا تەگمەيدۇ.

تاللانمىلار:

- `--batch fn:param` نۇرغۇن `param` قىممەتلىرىنى Rust تا ساقلايدىغان سىنىپ قوشىدۇ. [توپلار](/docs/concepts/batches) نى كۆرۈڭ.
- `--as-json T` ئەپ پەقەت سانلىق مەلۇمات بىلەنلا تولدۇرىدىغان تىپ پارامېتىرىنى (`paginate<T>(items: T[])` دىكى `T`) JSON قىممىتى سۈپىتىدە كۆۋرۈكلەيدۇ.
- `--keep "name: reason"` تېخىمۇ كۆپ چىقىرىشلارنى مەنبە تىلدا قالدۇرىدۇ، مەسىلەن `Intl` سانلىق مەلۇماتىغا تايىنىدىغان كود.
- `--kind` پىلان تاللىغان كۆۋرۈكنى قاپلايدۇ (TypeScript ئۈچۈن napi-rs ياكى wasm).

## ھەر بىر تىلنىڭ كۆۋرۈكى

| تىل | كۆۋرۈك |
| --- | --- |
| TypeScript/JavaScript | ھاسىل قىلىنغان ئىككىلىك ئالاقە بىلەن napi-rs ياكى wasm-bindgen؛ سىنىپلار ۋە async مۇ بار |
| Python | PyO3 (abi3)، بىۋاسىتە ئايلاندۇرۇش، تىپلىق مۇستەسنالار |
| C | ئەسلى ئىسىملىرى ۋە باش ھۆججىتى بار `extern "C"` فۇنكسىيەلىرى |
| Go | ئەسلى API سى بار بوغچىدىكى تىپلىق cgo چاقىرىقلىرى ۋە ھاسىل قىلىنغان ئىككىلىك ئالاقە |
| Ruby | ئەسلى مودۇللار ئاستىدىكى magnus كېڭەيتمىسى |
| Java | ئەسلى مېتودلىرى بار ئوراما سىنىپلاردىكى تىپلىق JNI ۋە ھاسىل قىلىنغان ئىككىلىك ئالاقە |

PHP ۋە C# بىرلىكلىرىنى تېخى كۆۋرۈكلىگىلى بولمايدۇ؛ [PHP](/docs/languages/php) ۋە [C#](/docs/languages/csharp) نى كۆرۈڭ.

## bridge نېمىنى قارار قىلىدۇ

- كۆۋرۈكتىن ئۆتەلمەيدىغان چىقىرىشلار سەۋەبى بىلەن مەنبە تىلدا قالىدۇ، سايە
  مودۇلى ئەسلى نۇسخىنى قايتا چىقىرىدۇ. TS ئۈچۈن:
  فۇنكسىيە قوبۇل قىلىدىغان ياكى قايتۇرىدىغان فۇنكسىيەلەر، generator ۋە iterator لار، RegExp، `instanceof` تەكشۈرۈشلىرى،
  generic لار (`--as-json T` ئەپ پەقەت سانلىق مەلۇمات بىلەنلا تولدۇرىدىغان بىرىنى كۆۋرۈكلەيدۇ)، ۋە تىپلىرىدا (import، قايتا چىقىرىش ۋە `extends` ئارقىلىق ئىز قوغلانغان)
  فۇنكسىيە بار قىممەتلەر. `--keep "name: reason"` تېخىمۇ كۆپىنى قالدۇرىدۇ، مەسىلەن `Intl` سانلىق مەلۇماتىغا تايىنىدىغان كود.
- TS تىپلىرى Rust تىپلىرىغا ماسلاشتۇرۇلىدۇ، تىپ تەخەللۇسلىرى import ئارقىلىق ھەل قىلىنىدۇ، پارامېتىر تىپلىرى
  سۈكۈتتىكى قىممەتلەردىن پەرەز قىلىنىدۇ؛ قۇرۇلمىلىق قىممەتلەر ھاسىل قىلىنغان ئىككىلىك ئالاقە بولۇپ ئۆتىدۇ (JSON پەقەت
  ئالاقە مودېللىمايدىغان شەكىللەر ئۈچۈن زاپاس يول).
- JSON `undefined`، NaN، Infinity، -0 ياكى يالغۇز surrogate لارنى ئىپادىلىيەلمەيدۇ: قۇرۇلمىلىق قىممەتلەر
  بەلگىلەرنى ئېلىپ يۈرىدۇ (`{"$undefined": true}`، `{"$num": "NaN"}`، `{"$utf16": [...]}`)، ئۇلارنى ھاسىل قىلىنغان
  `index.cjs` تەرجىمە قىلىدۇ، ياردەمچىلەر crate نىڭ `js.rs` ىدا.

`record` TS مەنبە ھۆججەتلىرىنى ئۆز پېتى ئىجرا قىلىدۇ: Node resolve ئىلمىكى bundler ئۇسلۇبىدىكى import لارغا ئەگىشىدۇ
(`./errors` تىن `./errors.ts` قا)، ئامباردا ئورنىتىلغان بوغچا بولمىسا `--resolve-from` npm بوغچىلىرىنى
تەمىنلەيدۇ، ئۆزگەرتىش كېرەك بولغان TS (enum، پارامېتىر خاسلىقلىرى) 
`--experimental-transform-types` بىلەن قايتا سىنىلىدۇ.
