# توپ ۋە قىزىق يوللار

```sh
everything-rust bridge <repo> <unit> --batch fn:param    # ياكى: everything-rust refresh <crate> --batch fn:param
```

`--batch` `param` قىممەتلىرىنى بىر قېتىم ئېلىپ Rust تا ساقلايدىغان بىر سىنىپ ھاسىل قىلىدۇ: `new FnBatch(items)` (TS، Python، Java)، `Mod::FnBatch.new(items)` (Ruby)، `NewFnBatch(items)` (Go). ھەر بىر سۈرۈشتۈرۈشتە `run(<other args>)` بارلىق نەتىجىلەرنى بىر سانلار گۇرۇپپىسى قىلىپ قايتۇرىدۇ، `rank(<other args>, min)` بولسا ئېلېمېنت ئىندېكسلىرىنى ئەڭ ياخشىسىدىن باشلاپ قايتۇرىدۇ. ئۇ بارلىق يادرولاردا ئىجرا بولىدۇ، خاتالىقلار ئەسلى نۇسخىنىڭكى. C دىن باشقا ھەر بىر تىلدا توپلار بار.

ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم چاقىرىلىدىغان كۆچۈرمە ھەر بىر ئېلېمېنت ئۈچۈن بىر قېتىم كۆۋرۈك ھەققى تۆلەيدۇ ۋە JIT قا يېڭىلىدۇ. ئۇتىدىغىنى
ئايلانمىنى يۆتكەش: `profile` ئۇنى تاپىدۇ، `--batch` بولسا ئېلېمېنتلارنى بىر قېتىم ئېلىپ،
ھەر بىر چاقىرىشتا فۇنكسىيەنى ئۇلارنىڭ ھەممىسى ئۈستىدە بارلىق يادرولاردا ئىجرا قىلىدىغان، تىپلىق سانلار گۇرۇپپىسى نەتىجىسى بېرىدىغان سىنىپ ھاسىل قىلىدۇ.

```sh
everything-rust profile ../x18n -- node --experimental-strip-types $PWD/demo/x18n-search/search.ts .
# -> fuzzyScore: ئىجرانىڭ تۆتتىن بىرى، `matched` تەرىپىدىن ھەر بىر ئاچقۇچ ئۈچۈن چاقىرىلىدۇ: ئۇنى توپلاڭ
everything-rust bridge ../x18n packages/core/src/fuzzy.ts --batch fuzzyScore:text
```

```js
const search = new FuzzyScoreBatch(keys)          // once
const order = search.rank(query, 0)               // per keystroke: indexes, best first
```

`port.rs` دىكى بىر `FuzzyScoreIndex` struct ى سۈكۈتتىكى ئايلانمىنى ئېلېمېنتلارنى بىر قېتىم تەييارلايدىغان
ئايلانما بىلەن ئالماشتۇرىدۇ، ھەمدە ئۆزى رەتلىيەلەيدۇ (`rank`): ئۇ ئاچقۇچلارنى كىچىك ھەرپكە ئايلاندۇرۇپ، ھەر بىرىنى ھەرپ ماسكىسى بىلەن ساقلايدۇ،
ھەر بىر ئاچقۇچتا ھەر بىر ئورتاق ھەرپنىڭ تۇنجى ئورنى جەدۋىلىنى (بىر ھەرپلىك سۈرۈشتۈرۈش بىر
ئىستون) ۋە ئاخىرقى سۈرۈشتۈرۈشنىڭ ماس كەلگەنلىرىنى ساقلايدۇ (`s` تىن كېيىن `se` يازسا، پەقەت `s` ماس كەلگەنلەرلا قايتا باھالىنىدۇ). x18n نىڭ
50,000 ئاچقۇچ ئۈستىدىكى يان تاختا ئىزدىشىدە، ھەرپمۇ ھەرپ يېزىلغاندا، ئوخشاش نەتىجىلەر بىلەن:

| | ھەر سۈرۈشتۈرۈش | TS قا سېلىشتۇرغاندا |
| --- | ---: | ---: |
| TS: `map(fuzzyScore)`، سۈزۈش، رەتلەش | 10 ms | 1x |
| ئىندېكس بىلەن ئوخشاش تارايتىش قىلىدىغان TS | 4.1-5.4 ms | 2x |
| ئوخشاش كۆچۈرمە، ھەر بىر ئاچقۇچ ئۈچۈن چاقىرىلغان | - | 0.2-0.4x |
| `FuzzyScoreBatch`، سۈكۈتتىكى ئىندېكس (4 يادرو) | 5.1 ms | 1.7x |
| `FuzzyScoreIndex` بىلەن `FuzzyScoreBatch` (napi، 4 يادرو) | 0.45-0.56 ms | **18-22x** |
| ئوخشاشنى wasm بىلەن (بىر ئېقىم) | 0.95 ms | **11.5x** |

ئوخشاش تارايتىشنى قىلىدىغان TS قا سېلىشتۇرغاندىمۇ Rust يەنىلا 7-12x تېز (wasm 5x). قايتۇرۇلغان
ئىندېكسلارنى ئاددىي ئايلانما بىلەن ئاچقۇچقا ئايلاندۇرۇڭ: `Array.from(order, i => keys[i])` 20x قىممەت، 0.4 ms كەتتى.

ھەر بىر تىلدا توپلار بار، ئۇلار ھەر چاقىرىشلىق كۆچۈرمىلەر يېڭىلگەن جايلاردىمۇ ئەسلى نۇسخىنى يېڭىدۇ.
4 يادرودا ئوخشاش ئىش، ئوخشاش نەتىجە ۋە خاتالىقلار (سىناق ئۆلچەملىرى ھەر بىر demo قىسقۇچىدا):

| تىل | خىزمەت يۈكى | ئەسلى | ھەر چاقىرىشلىق كۆچۈرمە، ئەسلىگە نىسبەتەن | توپ، ئەسلىگە نىسبەتەن |
| --- | --- | ---: | ---: | ---: |
| TS | x18n ئىزدەش، 50,000 ئاچقۇچ | 10 ms | 0.2-0.4x | **20x** |
| Python | `slugify`، 20,000 قۇر | 98 ms | - | **17x** |
| Ruby | `slugify`، 20,000 قۇر | 110 ms | - | **12.7x** |
| Ruby | `shellescape` (stdlib)، 50,000 ئارىلاش قىممەت | 88 ms | - | **11.8x** |
| Go | `Slugify`، 50,000 قۇر | 49 ms | 0.93x | **4x** |
| Java | `slugify`، 50,000 قۇر | 43 ms | 0.68x | **3x** |

تۈزۈلگەن ئەسلى نۇسخىلار ئازراق پايدا ئالىدۇ: ھەر بىر ئېلېمېنتنىڭ ئىشى ئاللىقاچان تېز، شۇڭا توپ يادرو سانىچىلىك
ئۇتىدۇ. توپ crate لىرى mimalloc بىلەن ئىچكى ساقلىغۇچ ئاجرىتىدۇ: سىستېما ئاجراتقۇچىسى بىلەن Go توپى
بىر ئېقىمدىنمۇ ئاستا ئىدى. Demo: [`demo/x18n-search`](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-search/README.md).
## تېز ئىندېكس يېزىش

- چاقىرغۇچىغا توپنى ھەر بىر سۈرۈشتۈرۈشتە ئەمەس، بىر قېتىم قۇرغۇزۇڭ. قايتۇرۇلغان ئىندېكسلارنى ئاددىي ئايلانما بىلەن ئېلېمېنتلارغا قايتۇرۇڭ.
- ئېلېمېنتلارنى بىر قېتىم تەييارلاش ئۈچۈن (كىچىك ھەرپ، ماسكىلار، ئورۇن جەدۋەللىرى)، `port.rs` دا `new(items)` ۋە `run(<other args>)` بار `pub struct FnIndex` نى ئېنىقلاڭ. ئۇ ئېلېمېنتمۇ ئېلېمېنت فۇنكسىيە بىلەن ئوخشاش نەتىجە بېرىشى كېرەك.
- رەتلەش ئىشنى ئاتلاپ ئۆتەلىسە، ئىندېكسقا ئۆزىنىڭ `rank(<other args>, min)` ىنى بېرىڭ. ئۇ فۇنكسىيە نەتىجىلىرىنى رەتلەشكە ماس كېلىشى كېرەك: نومۇر يۇقىرىدىن تۆۋەنگە، تەڭ بولسا ئېلېمېنت تەرتىپى بويىچە.
- توپ كۆچۈرمىنىڭ ھەر ئېلېمېنتلىق سۈرئىتىنى يادرو سانىغا كۆپەيتىدۇ. تۈزۈلگەن ئەسلى نۇسخىلارغا (Go، Java) قارشى كۆچۈرمىنىڭ ئۆزى تېز بولۇشى كېرەك: ASCII نى Unicode جەدۋەللىرىسىز بىر تەرەپ قىلىڭ، ھەر بىر نەتىجىنى ئالدىن چوڭلۇقى بېكىتىلگەن بىر `String` دا قۇرۇڭ، ئارىلىق نۇسخىلاردىن ساقلىنىڭ.
- Go ۋە Java دا ئىش تۈگىگەندە توپنى يېپىڭ (finalizer لار پەقەت زاپاس يول).
