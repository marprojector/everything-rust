# تىللار

ئالتە تىل پۈتۈن ئايلانمىدىن ئۆتىدۇ: Node.js (TypeScript/JavaScript)، Python، C، Go، Ruby ۋە Java. PHP ۋە C# ئالدىن كۆرۈش باسقۇچىدا: بۈگۈن `analyze` ۋە پۈتۈن ئەپلەر، بىرلىك كۆۋرۈكلىرى كېيىن.

| تىل | بىرلىك | كۆۋرۈك | خاتىرىلەيدىغان ۋە قايتا قويىدىغىنى |
| --- | --- | --- | --- |
| TypeScript/JavaScript | قىسقۇچ ياكى ھۆججەت | ھاسىل قىلىنغان ئىككىلىك ئالاقە بىلەن napi-rs ياكى wasm-bindgen؛ سىنىپلار ۋە async مۇ بار | `.ts` مەنبە ھۆججەتلىرىنى ئىجرا قىلىدىغان Node |
| Python | بوغچا ياكى مودۇل | PyO3 (abi3)، بىۋاسىتە ئايلاندۇرۇش، تىپلىق مۇستەسنالار | ئەسلى نۇسخىنى import قىلىدىغان Python |
| C | `.c` ھۆججىتى | ئەسلى ئىسىملىرى ۋە باش ھۆججىتى بار `extern "C"` فۇنكسىيەلىرى | ئورتاق كۇتۇپخانا قىلىپ تۈزۈلگەن ئەسلى نۇسخا، ctypes ئارقىلىق چاقىرىلىدۇ، ھەر بىر ئەھۋال ئۈچۈن بىر fork |
| Go | بوغچا | ئەسلى API سى بار بوغچىدىكى تىپلىق cgo چاقىرىقلىرى ۋە ھاسىل قىلىنغان ئىككىلىك ئالاقە | ئۆز مودۇلى سۈپىتىدە قۇرۇلغان، ھاسىل قىلىنغان Go قوزغاتقۇچى |
| Ruby | مودۇل فۇنكسىيەلىرىدىن تەركىب تاپقان ھۆججەت ياكى قىسقۇچ | ئەسلى مودۇللار ئاستىدىكى magnus كېڭەيتمىسى | ھاسىل قىلىنغان Ruby قوزغاتقۇچى |
| Java | `public static` مېتودلىرىدىن تەركىب تاپقان بوغچا | ئەسلى مېتودلىرى بار ئوراما سىنىپلاردىكى تىپلىق JNI ۋە ھاسىل قىلىنغان ئىككىلىك ئالاقە | ھاسىل قىلىنغان reflection قوزغاتقۇچى |
| PHP (ئالدىن كۆرۈش) | فۇنكسىيەلەر ۋە `public static` مېتودلىرىدىن تەركىب تاپقان قىسقۇچ | كېيىنكى قەدەم: C ABI ئۈستىدە PHP FFI | بۈگۈن پۈتۈن ئەپلەر: CLI ۋە مۇلازىمېتىرلار (`php -S`) ئۈچۈن `app record`، `app replay` ۋە ئالدى ئىشىك |
| C# (ئالدىن كۆرۈش) | `public static` مېتودلىرىدىن تەركىب تاپقان قىسقۇچ | كېيىنكى قەدەم: C ABI ئۈستىدە P/Invoke | بۈگۈن پۈتۈن ئەپلەر: CLI ۋە ASP.NET مۇلازىمېتىرلىرى (`dotnet <app>.dll`) ئۈچۈن `app record`، `app replay` ۋە ئالدى ئىشىك |

C دىن باشقا ھەر بىر تىلدا يەنە توپ سىنىپلىرى (`--batch`) بار: ئېلېمېنتلار بىر قېتىم ئۆتۈپ،
Rust تا قالىدۇ، ھەر بىر چاقىرىش ئۇلارنىڭ ھەممىسى ئۈستىدە بارلىق يادرولاردا ئىجرا بولىدۇ.

تىل ئامباردىن بايقىلىدۇ (`go.mod`، `pom.xml`، `.csproj` ياكى `.sln`،
`pyproject.toml`، `Gemfile`، `composer.json`، `package.json`، بولمىسا ئەڭ كۆپ ئۇچرايدىغان مەنبە ھۆججەتلىرى)؛
`--lang` ئۇنى قاپلايدۇ. تىپلار مەنبەدىن كېلىدۇ: TS تىپلىرى، Python ئىشارەتلىرى، C، Go، Java ۋە C#
ئىمزالىرى، Ruby YARD بەلگىلىرى، PHP تىپلىرى ۋە phpdoc؛ سان سۈپىتىدە ئىشلىتىلگەن تىپسىز پارامېتىرلار
سان دەپ پەرەز قىلىنىدۇ.

PHP ئالدىن كۆرۈش باسقۇچىدا: `analyze` بىر PHP ئەپىنى پىلانلايدۇ (Composer بوغچىلىرى ۋە PSR-4 ئاپتوماتىك يۈكلەش، بوش سېلىشتۇرۇش ۋە
پۈتۈن ساننىڭ لەيلىمە سانغا تېشىپ كېتىشى قاتارلىق خەتەرلەر، crate لارغا ماسلاشتۇرۇلغان Composer بوغچىلىرى)،
PHP CLI ياكى مۇلازىمېتىرىنى خاتىرىلەپ، قايتا قويۇپ، Rust ئالدى ئىشىكى ئارقىسىغا قويغىلى بولىدۇ. ئۇنىڭ
بىرلىكلىرىنى PHP نىڭ FFI ى ئارقىلىق Rust قا كۆچۈرۈش كېيىنكى قەدەم ([issue #2](https://github.com/marprojector/everything-rust/issues/2)).

C# مۇ ئوخشاش ئالدىن كۆرۈش باسقۇچىدا: `analyze` `.csproj` تۈرلىرىنى ۋە ئۇلارنىڭ NuGet بوغچىلىرىنى
(crate لارغا ماسلاشتۇرۇلغان) ئوقۇيدۇ، `using` كۆرسەتمىلىرىنى قىسقۇچلارغا ھەل قىلىدۇ، ھەمدە C# باشقىچە قىلىدىغان نەرسىلەرنى بەلگىلەيدۇ
(`decimal`، `dynamic`، LINQ نىڭ كېچىكتۈرۈلگەن سۈرۈشتۈرۈشلىرى، `Task`، `lock`، reflection). C# CLI ياكى ASP.NET
مۇلازىمېتىرىنى خاتىرىلەپ، قايتا قويۇپ، Rust ئالدى ئىشىكى ئارقىسىغا قويغىلى بولىدۇ؛ بىرلىكلەرنى P/Invoke ئارقىلىق كۆچۈرۈش
كېيىنكى قەدەم.
