## كۆچۈرمە نېمىنى توغرا قىلىشى كېرەك

- `Integer.parseInt` `Character.digit` ئارقىلىق ھەر قانداق Unicode ئونلۇق رەقەمنى (`١٢`، `２`) قوبۇل قىلىدۇ.
- `Double.toString` (JDK 19+) ئەڭ قىسقا ئونلۇق ساننى بېسىپ چىقىرىدۇ، ئەمما ھەرگىز ئىككى رەقەمدىن ئاز ئەمەس: `4.9E-324`، Rust نىڭ ئەڭ قىسقا شەكلى بولسا `5e-324`.
- `\s` پەقەت ASCII؛ Rust نىڭ `split_whitespace` ى U+00A0 دىمۇ ئايرىيدۇ.
- لەيلىمە چېكىتلىك سانلار بېرىپ-كېلىشتىن ساق چىقىشى كېرەك: `serde_json` نىڭ سۈكۈتتىكى لەيلىمە سان تەھلىلچىسى ھەمىشە توغرا يېقىنلاشتۇرمايدۇ، شۇڭا everything-rust ۋە ئۇ ھاسىل قىلغان ھەر بىر crate ئۇنىڭ `float_roundtrip` ئىقتىدارىنى ئىشلىتىدۇ.

## سۈرئەت

JIT تىن كېيىن ياپراق فۇنكسىيەلەر بىر قانچە نانوسېكۇنت ئالىدۇ، قۇر بار JNI چاقىرىقى بولسا بۇنىڭدىن قىممەت. JDK facade دا `bench` كۆچۈرمىنى ھەر چاقىرىشتا 0.18x دەپ ئۆلچىدى: چوڭراق بىرلىكلەرنى كۆچۈرۈڭ. 4 يادرودا توپ سۈپىتىدە، 50,000 قۇر ئۈستىدىكى `slugify` (Java دا 43 ms) **3x تېز** ئىجرا بولدى (ھەر چاقىرىشلىق كۆچۈرمە: 0.68x).
