# TypeScript/JavaScript

| | |
| --- | --- |
| بىرلىك | بىر قىسقۇچ ياكى ھۆججەت |
| كۆۋرۈك | ھاسىل قىلىنغان ئىككىلىك ئالاقە بىلەن napi-rs ياكى wasm-bindgen؛ سىنىپلار ۋە async مۇ بار |
| خاتىرىلەيدىغان ۋە قايتا قويىدىغىنى | `.ts` مەنبە ھۆججەتلىرىنى ئىجرا قىلىدىغان Node |
| كېرەكلىكى | Node 22.6+ (`profile` ئۈچۈن Node 24+ كېرەك) |
| ھالىتى | دەلىللەنگەن |

## كۆۋرۈك تاللاش

بىرلىك ياكى ئۇ import قىلغان ھەر قانداق نەرسىگە Node كېرەك بولسا، `analyze` napi-rs نى تاللايدۇ؛ كۆچمە كود ئۈچۈن wasm-bindgen نى تاللايدۇ (ئۇ توركۆرگۈلەردىمۇ ئىجرا بولىدۇ)؛ UI ۋە تەھرىرلىگۈچ كودىنى JS تا قالدۇرىدۇ. `bridge --kind napi|wasm` ئۇنى قاپلايدۇ.

كۆۋرۈكتىن ئۆتەلمەيدىغان چىقىرىشلار سەۋەبى بىلەن TS تا قالىدۇ، سايە مودۇلى ئەسلى نۇسخىنى قايتا چىقىرىدۇ: فۇنكسىيە قوبۇل قىلىدىغان ياكى قايتۇرىدىغان فۇنكسىيەلەر، generator ۋە iterator لار، RegExp، `instanceof` تەكشۈرۈشلىرى، generic لار (`--as-json T` ئەپ پەقەت سانلىق مەلۇمات بىلەنلا تولدۇرىدىغان بىرىنى كۆۋرۈكلەيدۇ)، ۋە تىپلىرىدا فۇنكسىيە بار قىممەتلەر. [كۆۋرۈك](/docs/concepts/bridge) نى كۆرۈڭ.

## TS نى ئۆز پېتى خاتىرىلەش

`record` TS مەنبە ھۆججەتلىرىنى بىۋاسىتە ئىجرا قىلىدۇ: Node resolve ئىلمىكى bundler ئۇسلۇبىدىكى import لارغا ئەگىشىدۇ، ئامباردا ئورنىتىلغان بوغچا بولمىسا `--resolve-from` npm بوغچىلىرىنى تەمىنلەيدۇ، ئۆزگەرتىش كېرەك بولغان TS (enum، پارامېتىر خاسلىقلىرى) `--experimental-transform-types` بىلەن قايتا سىنىلىدۇ. `record --from-tests -- npx jest` ئەسلى نۇسخىنىڭ ئۆز سىناق توپلىمى قىلغان ھەر بىر چاقىرىقنى ھەر قانداق ئىجرا قىلغۇچ بىلەن خاتىرىلەيدۇ. TS/JS ئۈچۈن ئەسلى نۇسخىنىڭ قاپلاش دائىرىسى ئۆلچىنىدۇ ([قاپلاش دائىرىسى](/docs/concepts/coverage)).

## كۆچۈرمە نېمىنى توغرا قىلىشى كېرەك

ھەقىقىي كودتىكى خاتىرىلەنگەن ئەھۋاللار تاپقانلىرى:

- `str.length`، `indexOf` ۋە `slice` UTF-16 كود بىرلىكلىرىنى سانايدۇ، شۇڭا بىر emoji ئىككى ئورۇن ئىگىلەيدۇ. ھاسىل قىلىنغان `utf16` ياردەمچىلىرىنى ئىشلىتىڭ.
- `u` بەلگىسىز `/.../i` پەقەت ASCII ھەرپلىرىنىلا قاتلايدۇ، Rust نىڭ `regex` ى بولسا Unicode نى قاتلايدۇ، شۇڭا vercel/ms دا `"1 ſ"` (ئۇزۇن s) ۋە Kelvin بەلگىسى سېكۇنت دەپ تەھلىل قىلىناتتى.
- `Math.round` يېرىمنى يۇقىرىغا يېقىنلاشتۇرىدۇ (`-2.5` بولسا `-2` بېرىدۇ)؛ Rust نىڭ `round` ى نۆلدىن يىراققا ماڭىدۇ. ھاسىل قىلىنغان `js.rs` دا `js::math_round` بار.
- `${n}` بولسا `1e+21`، `5e-324` نى، `-0` ئۈچۈن `0` نى بېسىپ چىقىرىدۇ. `js::number_to_string` بۇنى قايتا ھاسىل قىلىدۇ.
- `String.prototype.trim` Rust نىڭ `char::is_whitespace` ىنى ئەمەس، JS بوشلۇقىنى ئىشلىتىدۇ.

## سۈرئەت

ھەر چاقىرىشتا كۆچۈرمە ھەر قېتىم كۆۋرۈك ھەققىنى تۆلەيدۇ، V8 بولسا كىچىك فۇنكسىيەلەرنى نانوسېكۇنتلاردا ئىجرا قىلىدۇ. vercel/ms خاتىرىلەنگەن ئەھۋاللىرى ئۈستىدە ھەر چاقىرىشتا 0.56x ئىجرا بولدى؛ x18n نىڭ يادرو كۆچۈرمىلىرى JS تىن چاقىرىلغاندا TS تىن ئاستا. توپ سۈپىتىدە ئايلانما Rust قا يۆتكىلىدۇ:

| خىزمەت يۈكى | ئەسلى | everything-rust بىلەن |
| --- | ---: | ---: |
| x18n نىڭ يان تاختا ئىزدىشى، 50,000 ئاچقۇچ (Node) | ھەر سۈرۈشتۈرۈشكە 10 ms | 0.5 ms: 20x تېز |
| ئوخشاش ئىزدەش توركۆرگۈدە (wasm، بىر ئېقىم) | 10 ms | 0.95 ms: 11.5x |
| Fuse.js، 50,000 قۇر | 91.2 ms | 2.8 ms: 32x |
| vercel/ms `parse` x100,000 | 11.8 ms | 0.65 ms: 18x (تاپشۇرۇشنى قوشۇپ ھېسابلىغاندا 3.4x) |
| vercel/ms `format` x100,000 | 2.1 ms | تاپشۇرۇش بىلەن 2.5 ms: 0.8x |

مىساللار: [json-server](/docs/real-world/json-server)، [Fuse.js](/docs/real-world/fuse-js)، [vercel/ms](/docs/real-world/vercel-ms)، [x18n](/docs/real-world/x18n).
