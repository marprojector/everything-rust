`profile` `go test` ئارقىلىق ئىشلەيدۇ: `everything-rust profile <repo> -- go test -run X -bench . ./pkg`. توپلار `NewFnBatch(items)`؛ ئىش تۈگىگەندە ئۇلارنى يېپىڭ.

## كۆچۈرمە نېمىنى توغرا قىلىشى كېرەك

- `path.Clean`: Go نىڭ `lazybuf` ى يېزىش ئىندېكسى كەينىگە يۆتكەلگەندىن كېيىن ئۇ ئورۇندىكى بايتنى ئوقۇيدۇ، ئاخىرقى ساقلانغان بايتنى ئەمەس (9 ئەھۋال، Go نىڭ ئۆز سىناق جەدۋىلىدىن).
- `strings.ToLower` ھەر بىر rune نى ئايرىم كىچىكلىتىدۇ: `ΣΊΣΥΦΟΣ` بولسا `σίσυφοσ` قا ئايلىنىدۇ، Rust نىڭ `to_lowercase` ى بولسا ئاخىرقى sigma قائىدىسىنى قوللىنىدۇ. Go يەنە `İ` نى `i` غا ئايلاندۇرىدۇ، Rust بولسا `i̇` بېرىدۇ.
- Go قۇرلارنى بايت بويىچە كېسىدۇ؛ rune نىڭ ئوتتۇرىسىدىن كېسىلگەن جاي JSON غا ھەر بىر بايت ئۈچۈن بىر U+FFFD بولۇپ يېتىدۇ.

## سۈرئەت

Go ياپراق فۇنكسىيەلەرنى بىر قانچە نانوسېكۇنتتا ئىجرا قىلىدۇ، بىر cgo چاقىرىقىنىڭ ئۆزىلا تەخمىنەن 80 ns. `path` تا `bench` كۆچۈرمىنى ھەر بىر چاقىرىشتا 0.04x دەپ ئۆلچىدى: چوڭراق بىرلىكلەرنى كۆچۈرۈڭ. توپ سۈپىتىدە ئىش بارلىق يادرولاردا Rust قا يۆتكىلىدۇ: 50,000 قۇر ئۈستىدىكى `Slugify` Go دا 49 ms ۋاقىت ئالدى، توپ بولسا **4x تېز** ئىجرا بولدى (ھەر چاقىرىشلىق كۆچۈرمە: 0.93x). توپ crate لىرى mimalloc بىلەن ئىچكى ساقلىغۇچ ئاجرىتىدۇ: سىستېما ئاجراتقۇچىسى بىلەن Go توپى بىر ئېقىمدىنمۇ ئاستا ئىدى.
