# C# (ئالدىن كۆرۈش)

| | |
| --- | --- |
| بىرلىك | `public static` مېتودلىرىدىن تەركىب تاپقان بىر قىسقۇچ |
| كۆۋرۈك | كېيىنكى قەدەم: C ABI ئۈستىدە P/Invoke |
| بۈگۈن | پۈتۈن ئەپلەر: CLI ۋە ASP.NET مۇلازىمېتىرلىرى (`dotnet <app>.dll`) ئۈچۈن `app record`، `app replay` ۋە ئالدى ئىشىك |
| ھالىتى | ئالدىن كۆرۈش: پەقەت `analyze` ۋە پۈتۈن ئەپلەر؛ بىرلىكلەرنى تېخى كۆۋرۈكلىگىلى بولمايدۇ |

`analyze` `.csproj` تۈرلىرىنى ۋە ئۇلارنىڭ NuGet بوغچىلىرىنى (crate لارغا ماسلاشتۇرۇلغان) ئوقۇيدۇ، `using` كۆرسەتمىلىرىنى قىسقۇچلارغا ھەل قىلىدۇ، ھەمدە C# باشقىچە قىلىدىغان نەرسىلەرنى بەلگىلەيدۇ: `decimal`، `dynamic`، LINQ نىڭ كېچىكتۈرۈلگەن سۈرۈشتۈرۈشلىرى، `Task`، `lock`، reflection.

قۇرۇلغان بىر ئەپنى خاتىرىلەش:

```sh
everything-rust app record . -- dotnet out/app.dll
everything-rust app record . --http -- dotnet out/app.dll --urls http://127.0.0.1:{port}
everything-rust app replay .
everything-rust app front-door .
```

بىرلىكلەرنى P/Invoke ئارقىلىق كۆچۈرۈش كېيىنكى قەدەم. ئۇنىڭغىچە `bridge` C# بىرلىكلىرىنى ئېنىق ئۇچۇر بىلەن رەت قىلىدۇ.

CI .NET نى ئورناتمايدۇ، شۇڭا C# سىناقلىرى پەقەت ئۇ ئورنىتىلغان ماشىنىدىلا ئىجرا بولىدۇ. Kotlin ۋە Swift تېخى قوللانمايدۇ؛ ئېھتىياجلىق تىلىڭىز ئۈچۈن issue ئېچىڭ (ياكى بارىغا ئاۋاز بېرىڭ).
