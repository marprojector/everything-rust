# everything-rust нәрсә ул

<p class="lead">Бөтен кушымтагызны Rust телендә өлешләп яңадан языгыз. everything-rust сезнең Node.js (TypeScript/JavaScript), Python, C, Go, Ruby яки Java кушымтагыз бүген нәрсә эшләгәнен язып ала, аннары Rust телендәге яңа версиянең һәр өлешен, алга барганчы, шул язма белән чагыштырып тикшерә, кушымта саф Rust булганчы.</p>

Ул CLI, HTTP серверлар һәм китапханәләр белән эшли. Rust кодын сезнең программалау агенты (Claude Code, Codex, Cursor, Gemini CLI) яки сез үзегез язасыз. PHP һәм C# [preview](/docs/languages/php) рәвешендә.

## Ул нәрсә эшли һәм нәрсә эшләми

everything-rust кодны тәрҗемә итми. Ул агент ышанычлы итеп чамалый алмаган нәрсәләрне бирә:

- **вакыт кая китә**: `profile` чын эш йөкләмәсен җибәрә һәм кайнар функцияләрне рейтинглый;
- **нәрсәне беренче һәм нинди тәртиптә күчерергә**: `analyze` берәмлекләрне, дулкыннарны, куркынычларны һәм crate'ларны планлаштыра;
- **bridge**, калган код Rust'ны API үзгәрмичә чакырсын өчен (`bridge`);
- **порт туры килергә тиешле төгәл тәртип**: `record` оригиналны чик очракларда җибәрә һәм ул нәрсә кайтарганын яки нинди хата ыргытканын саклый;
- **аны чыгаруның куркынычсыз ысулы**: `shadow` икесен янәшә җибәрә;
- **порт кайчан әзер икәнен әйтүче gate**: `gate`.

Оригинал дөреслек чыганагы булып кала. `diff` язып алынган һәр очракны Rust'та кабат уйната, һәм алар барысы да туры килмичә һәм `gate` узмыйча, бернәрсә дә чыгарылмый.

## Дүрт адым

| Адым | Нәрсә була |
| --- | --- |
| **Язып алу** | `record` оригиналны ясалган чик очракларда, семантик тозакларда һәм сезнең үз кертмәләрегездә җибәрә һәм ул нәрсә кайтарганын яки нинди хата ыргытканын саклый. |
| **Күчерү** | `bridge` Rust crate'ын һәм wrapper ясый, шуңа күрә чакыручылар оригинал API'ны саклый. Rust кодын сез яки агентыгыз яза. |
| **Тикшерү** | `diff` язып алынган һәр очракны Rust'та кабат уйната, һәм алар барысы да туры килмичә һәм `gate` узмыйча, бернәрсә дә чыгарылмый. |
| **Lift** | Кабат уйнату fallback'сыз узса һәм һәр берәмлек gate'ны узса, `app lift` аны саф Rust кушымтасына әйләндерә. Оригиналга беркайчан да кагылмый. |

## Rust һәрвакыт тизрәкме?

Юк, һәм everything-rust моны ачык әйтә. Һәр элемент өчен бер тапкыр чакырылган кечкенә функция Rust'та еш кына әкренрәк, чөнки һәр чакыру bridge аша уза; V8, JVM һәм Go андый функцияләрне наносекундларда башкара. `profile` аның тирәсендәге циклны таба, `--batch` бөтен циклны күчерә, ә `bench` чыгарганчы нәтиҗә әйтә. Үлчәнгән саннар, шул исәптән әкреннәре дә, [Batch'лар һәм кайнар юллар](/docs/concepts/batches) битендә.

## Ул язма колачлаганны гына тотып кала ала

Узу Rust язып алынган һәр очракка туры килә дигәнне генә аңлата, артыгын түгел. Яшел gate'ка ышанганчы, [Ул нәрсәне тотып кала алмый](/docs/concepts/limits) битен укыгыз.

::: warning Күчермәдә җибәрегез
`record` һәм `app record` сезнең оригинал кодны җибәрә: һәр функцияне (яки бөтен кушымтаны) күп санлы ясалган кертмәләр белән чакыра, ә `app record` һәр очракны ике тапкыр җибәрә. `diff`, `gate` һәм `app replay` шул ук очракларны портта яки оригиналда тагын җибәрә. Файл язучы, мәгълүмат базасы белән эшләүче яки челтәргә мөрәҗәгать итүче код моны һәр очрак саен бер тапкыр эшли. Аларны проектның күчермәсендә, тест базасы белән һәм мохиттә production сертификатлары булмаганда җибәрегез.
:::
