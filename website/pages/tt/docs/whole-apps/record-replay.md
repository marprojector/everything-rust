# Язып алу һәм кабат уйнату

`record` һәм `diff` бер берәмлекне исбатлый; `app record` һәм `app replay` алты телнең теләсә кайсындагы CLI һәм серверлар өчен кушымтаны исбатлый. Кушымта кара тартма итеп карала.

```sh
everything-rust app record . -- python3 cli.py          # оригиналны җибәрүче команда
everything-rust app replay .                            # оригинал 100% узарга тиеш
everything-rust app replay . --build "target/release/mytool"
```

## Очраклар каян килә

`app record` оригиналны болар белән җибәрә:

- кушымтаның үз документлаштырылган мисаллары: аның Markdown һәм shell файлларындагы `$ mytool ...` юллары, алар атаган файллар белән бергә;
- `--inputs` JSONL файлы, һәр юлда бер `{"name", "args", "stdin", "env", "files"}`;
- шул очраклардан алынган семантик тозаклар: ASCII булмаган һәм эмодзи юллар, тискәре бүлү һәм модуль, ташу, бик зур һәм бик кечкенә float'лар, map тәртибе, булмаган файллар.

Һәр очрак ике тапкыр җибәрелә; ике җибәрү арасында аерылган нәрсә `[..]` wildcard'ка әйләнә. `--normalize timestamps|uuids|key-order` яки `--normalize name=regex` очраклар белән бергә саклана торган нормальләштергечләр өсти. `app record` нәрсә аерылганын төрләре буенча күрсәтә: кыйммәтләр (хәзер wildcard'лар), тәртип (юллар теләсә нинди тәртиптә чагыштырыла) һәм юллар (теләсә нәрсәгә туры килүче `...`). Һәрберсен карагыз.

## Очраклар гади файллар

Очраклар `rust/app-cases/` эчендәге [trycmd](https://docs.rs/trycmd) файллары:

| Файл | Эчтәлеге |
| --- | --- |
| `<case>.toml` | argv, мохит, чыгу коды |
| `<case>.stdin` | стандарт кертү |
| `<case>.stdout`, `<case>.stderr` | оригинал нәрсә бастырган |
| `<case>.in/` | кертелә торган файллар |
| `<case>.out/` | язылган файллар |

Аларны кулдан укыгыз һәм төзәтегез; портның бинар файлы булгач, Rust тесты аларны `trycmd` белән җибәрә ала.

## Кабат уйнату

- `app replay` теләсә нинди build'ны очракларга каршы җибәрә, `passed/total` бастыра, һәр уңышсыз очрак өчен diff белән `rust/app-cases/replay-report.md` яза һәм теләсә нинди туры килмәүдә нульдән башка код белән чыга.
- `EVERYTHING_RUST_FALLBACK_LOG` атаган файлга язып баручы build (оригиналга һәр fallback өчен бер юл), [front door](/docs/whole-apps/front-door) эшләгәнчә, үзенең fallback өлеше турында да хисап ала.
- `app replay --case <name>` бер очракны хисап биргән исем буенча кабат җибәрә: барысын да тагын җибәргәнче туры килмәүне төзәтү өчен тиз, кабатланучан цикл.

## CI'да кабат уйнату

Хисапта вакытлар яки вакытлыча юллар юк: бер үк build'ны ике тапкыр кабат уйнату бер үк файлны яза. Аны commit итегез, аннары CI'да җибәрегез:

```sh
everything-rust app replay .
git diff --exit-code rust/app-cases/replay-report.md
```

Шуннан соң яртылаш күчерелгән кушымта нәрсә узуында теләсә нинди үзгәреш булганда (яхшырак яки начаррак) CI'ны узмый, хисап шуның белән яңартылганчы.

## Сан чыгышы

`app record --float-tolerance 1e-9` саннарга зуррак кыйммәтнең шул өлеше чикләрендә туры килергә мөмкинлек бирә. [Float төгәллеге](/docs/concepts/float-tolerance) битен карагыз.
