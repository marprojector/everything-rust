# Front door һәм wire

Башта керү ноктасын Rust'ка күчерегез, аннары аңа командаларны бер тапкырда бер берәмлек тапшырыгыз:

```sh
everything-rust app front-door .                            # rust/app: һәр команда оригиналны җибәрә
everything-rust app wire . textkit --command upper          # textkit-rs gate'ны узганнан соң
# glue кодын rust/app/src/units/textkit.rs эчендә языгыз, аннары:
everything-rust app wire . textkit                          # тагын 100%, fallback өлеше түбәнрәк
```

## Front door

`app front-door` `rust/app` ясый, кушымта исемен йөртүче Rust бинар файлы: язып алынган очраклардагы командалар һәм флаглар өчен clap парсеры, анда һәр команда оригиналны шул ук argv, stdin һәм мохит белән җибәрә һәм аның чыгышын һәм чыгу кодын үзгәрешсез тапшыра. Һәр fallback санала, шуңа күрә яңа ясалган front door'ны кабат уйнату 100% fallback белән 100% узу бирә (ул моны күрсәтү өчен җыя һәм кабат уйната). Ул `rust/app`'ны беркайчан да өстән язмый: шуннан соң код сезнеке.

## Берәмлекне тоташтыру

`app wire <repo> <unit> --command <name>`:

1. берәмлек crate'ында `gate` җибәрә (ул яңа гына узган булса, `--skip-gate`);
2. аны `rust/app`'ка китапханә итеп өсти;
3. `src/units/<unit>.rs` файлын бер тапкыр яза, аны сез яки агентыгыз тутырсын өчен: аргументларны парсингларга, `<crate>::port`'ны чакырырга, оригинал нәрсә бастырса, шуны бастырырга;
4. командаларны аңа юнәлтә, аннары җыя һәм кабат уйната.

Glue кодын язганнан соң аны тагын җибәрегез: 100% узу һәм түбәнрәк fallback өлеше. `EVERYTHING_RUST_UNIT_<NAME>=original` тоташтырылган берәмлекне lift'ка кадәр оригиналга кире җибәрә.

Бер команданы да атамаган argv өчен (аргументлар юк, билгесез командалар, куллану хаталары) кушымтаның үз исемен команда итеп тоташтырыгыз (`--command mytool`).

## Оригиналга беркем дә кире мөрәҗәгать итми

Front door оригиналны аерым процесс итеп җибәрә (яки HTTP'ны аңа юнәлтә), bridge аша тоташтырылган берәмлекләрне оригинал чакыра, киресенчә беркайчан да түгел, ә callback'лар чыганак телдә кала.

Серверлар командалар урынына маршрутлар куллана: [Серверлар](/docs/whole-apps/servers) битен карагыз. Китапханәләр үзләренең ачык API'ын куллана: [Китапханәләр](/docs/whole-apps/libraries) битен карагыз.
