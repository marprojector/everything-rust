# Серверлар

Шул ук командалар HTTP серверларны исбатлый. `--http` команда сервер җибәрә дигәнне аңлата; ул портын
`PORT`'тан яки командадагы `{port}`'тан ала (һәрвакыт бер үк портны тыңлаучы сервер өчен `--port`):

```sh
everything-rust app record . --http -- node server.js
everything-rust app replay .
everything-rust app front-door .                                    # axum: һәр маршрут проксилана
everything-rust app wire . api --route 'GET /users/{id}' --route '*'
everything-rust app lift .
```

- Сораулар кушымта документациясендәге `curl` юлларыннан (`curl -X POST -d ... http://localhost:8080/x`),
  `--inputs`'тан (`{"name", "method", "path", "headers", "body"}`) һәм тозаклардан килә: юл сегментлары һәм query
  кыйммәтләре CLI аргументлары өчен булган шул ук тозакларга, body'лар текст һәм JSON тозакларына алыштырыла, һәм бер
  билгесез маршрут. Һәр җибәрү серверны яңадан башлый һәм сорауларны исем тәртибендә җибәрә, шуңа күрә сораулар
  арасындагы халәт саклана.
- Халәтен файлларда тотучы сервер һәр җибәрүдә яңа күчермә ала: `--fresh db.json` (файл
  яки папка, кабатларга була) `http/files/` эчендә snapshot итеп саклана һәм оригинал, front door яки build һәр
  җибәрелгәндә яңа эш папкасына күчерелә; `--arg db.json` һәр җибәрү үз командасыннан соң ала торган
  аргумент, шуңа күрә Rust бинар файлы оригинал кебек үк җибәрелә.
  `--pace 50` һәр җаваптан соң 50 ms көтә, сервер җавап биргәннән соң башкара торган эш өчен (файл
  күзәтүчесе үзе яңа гына язганны кабат йөкләгәндә).
- Очраклар `rust/app-cases/http/<case>.toml` (сорау, статус һәм мөһим header'лар)
  һәм `<case>.body` (җавап body'сы, ике җибәрү аерылган урыннарда `[..]` белән). Date, server һәм
  башка һәр җавапка хас header'лар кертелми; сезгә кирәкмәгән теләсә нинди header юлын бетерегез.
- Front door ул оригиналны үзенең аерым портында җибәрүче һәм бер берәмлек тә җавап бирмәгән һәр
  маршрутны проксилаучы axum сервер. `wire --route` axum маршрутларын кабул итә: `METHOD /path/{param}`, теләсә нинди метод өчен `/path`,
  калган һәрнәрсә өчен `*`; glue маршрутны, аның параметрларын һәм сорауны ала.
  `lift` проксины бетерә; аннары HTTP очраклары CI'да `app replay` белән җибәрелә.
## Чын мисал

[json-server](/docs/real-world/json-server) өчен `--fresh`, `--arg` һәм `--pace` кирәк булды: ул һәр язуда мәгълүмат базасын яңадан яза, ә аның файл күзәтүчесе тиз артыннан килгән язуны юкка чыгара ала.
