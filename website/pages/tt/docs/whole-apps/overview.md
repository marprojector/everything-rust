# Бөтен кушымтаны күчерү

Максат оригинал кебек эшләүче саф Rust кушымтасы, оригинал үрнәк булып кала. Rust кодын агентыгыз яза; everything-rust эшне тәртипкә сала, аның нигезен ясый һәм һәр адымны исбатлый. CLI, HTTP серверлар һәм китапханәләр.

```
analyze --whole-app ──> app record ──> app front-door ──> per unit: the loop, then app wire ──> app lift
 shape, every           what the app    Rust owns the       gate passes, so the unit answers in    pure Rust,
 dependency, the        does from the   entry point; the     Rust: replay 100%, fallback rate down proved by
 decisions to make      outside         original answers                                           replay
```

## 1. Планлаштыру

```sh
everything-rust analyze . --whole-app
```

`--whole-app` кушымтаның формасын (CLI, сервер яки китапханә) һәм керү нокталарын, һәр тышкы бәйлелекне (импортланган яки игълан ителгән) аның Rust crate'ы һәм туры килүе белән, күчерү тәртибен өлешләр итеп (бер-берсен импортлаучы берәмлекләр бергә күчә) һәм тәкъдим ителгән җавап белән номерланган карарларны өсти: калдырыла торган берәмлекләр, тоткарланган берәмлекләр, crate'ы булмаган яки өлешчә генә булган бәйлелекләр.

## 2. Бөтен кушымтаны язып алу, аннары керү ноктасын күчерү

1. [`app record` һәм `app replay`](/docs/whole-apps/record-replay) программаны тыштан, кара тартма итеп исбатлый.
2. [`app front-door`](/docs/whole-apps/front-door) оригиналның алдына Rust бинар файлын куя; һәр команда һаман оригиналны җибәрә.
3. Һәр берәмлек [цикл](/docs/concepts/the-loop) аша уза, аннары `app wire` аның командаларын Rust'ка тапшыра.
4. Кабат уйнату 0 fallback өлеше белән узгач һәм һәр берәмлек gate'ны узгач, [`app lift`](/docs/whole-apps/lift) оригиналны бетерә.

[Серверлар](/docs/whole-apps/servers) һәм [китапханәләр](/docs/whole-apps/libraries) шул ук командаларны куллана.

## Агент моны ничек башкара

[Whole-app skill](https://github.com/marprojector/everything-rust/blob/main/skills/everything-rust/whole-app.md) агентны бу юл буйлап алып бара, бары сез генә кабул итә ала торган карарлардан башлап:

- **Сорау алу (grilling)**: агент әйләнешләп сорый, һәр сорау тәкъдим ителгән җавап белән, порт бәйле булган һәр карар хәл ителгәнче, һәм һәрберсен `rust/DECISIONS.md` эчендә ADR итеп яза, ә `rust/GLOSSARY.md` оригиналның терминнарын Rust исемнәренә туры китерә.
- **Тикшеренү**: фон агентлары һәр бәйлелекнең беренчел чыганакларын укый һәм тапкан һәр семантик тозак белән `rust/research/<topic>.md` яза.
- **Сессияләр аша**: `rust/MAP.md` һәр берәмлекне аның халәте белән күрсәтә; сессия эшкә керешкәнче бер берәмлекне үзенә ала, һәм һәр контроль нокта киләсе сессия өчен `rust/HANDOFF.md` калдыра. Бер дулкындагы берәмлекләрне subagent'лар параллель күчерә ала.
- **Күчеш**: агент ул булдыра алганны эшли һәм `rust/cutover.sh` яза, ул бары сез генә башкара ала торган адымнар (deploy, DNS, серләр) өчен интерактив скрипт, һәр адымда кире кайту юлы белән.

Сорау алу, тикшеренү һәм бу практикалар [Matt Pocock'ның skill'ларыннан](https://github.com/mattpocock/skills) җайлаштырылган.

## Бу Rust'ны иске дизайнга бәйләп куймыймы?

Икесе янәшә эшләгәндә генә. Язмалар тәртипне кушымтаның эчке төзелешендә түгел, читләрендә тикшерә (CLI чыгышы, сервер җаваплары, модульнең экспортланган функцияләре). Берәмлекләр һаман bridge аша узганда иске структураны кабатлагыз; `app lift` оригиналны бетергәч, Rust'ны иркен үзгәртеп корыгыз, ә `app replay` барыбер тәртипне исбатлый.

## Чын мисал

[json-server](/docs/real-world/json-server) һәр адымны узды: язып алынган 514 HTTP очрак, 99.8% fallback белән front door, башта уку юллары тоташтырылды (22.6% fallback), аннары һәр маршрут (0%), һәм 514/514 узучы саф Rust бинар файлына lift.
