# Lift

Кабат уйнату 0 fallback өлеше белән узса һәм һәр берәмлек gate'ны узса, аны саф Rust кушымтасына әйләндерегез:

```sh
everything-rust app lift .
```

- `app lift` икесе дә үтәлмичә эшләүдән баш тарта һәм нәрсә комачаулаганын әйтә: һаман fallback'ка китүче очраклар, һаман буш калган glue, gate'ны узмаган берәмлекләр.
- Башта күчермәдә ул fallback юлын һәм сүндергечләрне бетерә, һәр берәмлек crate'ын `rust/app`'ның гади китапханәсенә әйләндерә (`cdylib`, binding'лар яки ясалган wrapper'ларсыз) һәм `rust/app/tests/app_cases.rs` өсти, ул `cargo test` вакытында trycmd белән `rust/app-cases`'ны җибәрә, шуңа күрә CI'га cargo'дан башка бернәрсә дә кирәк түгел.
- Аннары ул lift тикшерү исемлеген җибәрә: һәр берәмлектә һәм `rust/app`'та fmt, clippy `-D warnings` һәм тестлар, `rust/DECISIONS.md`'тә аталган һәр target урнаштырылган урында җыела яки тикшерелә, эш вакытында укыла торган файллар һәм asset папкалары эчкә салынмаган, һәм саф бинар файлда кабат уйнату. Барысы да узгач кына үзгәрешләр кире языла. Оригиналга беркайчан да кагылмый.

## Lift'тан соң

Берәмлекләрдә инде binding'лар юк. json-server'да һәр crate'ның `tests/recorded.rs` файлы аның язып алынган очракларын портта кабат уйната: 514 HTTP очрак янәшәсендә барлык 3,399'ы `cargo test` белән җибәрелә.

Оригинал юкка чыккач, Rust'ны иркен үзгәртеп корыгыз; `app replay` барыбер тәртипне исбатлый.

## Аннары күчеш

Workflow skill агенттан ул булдыра алганны эшләүне һәм `rust/cutover.sh` язуны таләп итә, ул бары сез генә башкара ала торган адымнар (deploy, DNS, серләр) өчен интерактив скрипт, һәр адымда кире кайту юлы белән.
