`profile` `go test` аша эшли: `everything-rust profile <repo> -- go test -run X -bench . ./pkg`. Batch'лар `NewFnBatch(items)`; эш беткәч аларны ябыгыз.

## Порт нәрсәне дөрес эшләргә тиеш

- `path.Clean`: Go'ның `lazybuf`'ы язу индексы артка күчкәннән соң андагы байтны укый, соңгы калдырылган байтны түгел (9 очрак, Go'ның үз тест таблицасыннан).
- `strings.ToLower` һәр rune'ны аерым кечерәйтә: `ΣΊΣΥΦΟΣ` `σίσυφοσ` була, ә Rust'ның `to_lowercase`'ы ахыргы сигма кагыйдәсен куллана. Go шулай ук `İ`'ны `i`'га әйләндерә, ә Rust `i̇` бирә.
- Go юлларны байтлар буенча кисә; rune уртасыннан кисү JSON'га һәр байтка бер U+FFFD булып килеп җитә.

## Тизлек

Go ахыргы функцияләрне берничә наносекундта башкара, ә бер cgo чакыруы гына да якынча 80 ns тора. `path`'та `bench` портны бер чакыруга 0.04x дип үлчәде: зуррак берәмлекләрне күчерегез. Batch итеп, эш барлык ядроларда Rust'ка күчә: 50,000 юлга `Slugify` Go'да 49 ms алды, ә batch **4x тизрәк** эшләде (бер чакыруга порт: 0.93x). Batch crate'лары хәтерне mimalloc белән бүлә: система аллокаторы белән Go batch бер агымнан әкренрәк иде.
