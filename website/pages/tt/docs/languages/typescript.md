# TypeScript/JavaScript

| | |
| --- | --- |
| Берәмлек | папка яки файл |
| Bridge | ясалган бинар wire форматлы napi-rs яки wasm-bindgen; класслар һәм async та керә |
| Кем язып ала һәм кабат уйната | Node, `.ts` чыганакларын җибәреп |
| Кирәк | Node 22.6+ (`profile` өчен Node 24+ кирәк) |
| Халәт | Тикшерелгән |

## Bridge сайлау

`analyze` берәмлеккә яки ул импортлаган нәрсәгә Node кирәк булса, napi-rs, күчмә код өчен wasm-bindgen сайлый (ул браузерларда да эшли), ә UI һәм редактор кодын JS'та калдыра. `bridge --kind napi|wasm` моны алыштыра.

Bridge аша уза алмаган экспортлар, сәбәбе күрсәтелеп, TS'та кала, һәм shadow модуле оригиналны кабат экспортлый: функция кабул итүче яки кайтаручы функцияләр, генераторлар һәм итераторлар, RegExp, `instanceof` тикшерүләре, generic'лар (`--as-json T` кушымта мәгълүмат белән генә тутыра торганын күчерә) һәм типлары функция тотучы кыйммәтләр. [Bridge](/docs/concepts/bridge) битен карагыз.

## TS'ны булганча язып алу

`record` TS чыганакларын турыдан-туры җибәрә: Node resolve hook bundler стилендәге импортларга иярә, `--resolve-from` репозиторийда урнаштырылмаган npm пакетларын бирә, ә үзгәртү таләп иткән TS (enum'нар, parameter properties) `--experimental-transform-types` белән кабат җибәрелә. `record --from-tests -- npx jest` оригиналның үз тест җыелмасы ясаган һәр чакыруны теләсә нинди runner белән язып ала. TS/JS өчен оригиналның колачлавы үлчәнә ([Колачлау](/docs/concepts/coverage)).

## Порт нәрсәне дөрес эшләргә тиеш

Чын кодта язып алынган очраклар ярдәмендә табылды:

- `str.length`, `indexOf` һәм `slice` UTF-16 код берәмлекләрен саный, шуңа күрә эмодзи ике позиция алып тора. Ясалган `utf16` ярдәмчеләрен кулланыгыз.
- `u` флагы булмаган `/.../i` бары ASCII хәрефләрен генә регистрсыз чагыштыра, ә Rust'ның `regex`'ы Unicode'ны да, шуңа күрә vercel/ms'та `"1 ſ"` (озын s) һәм Кельвин билгесе секундлар дип укылыр иде.
- `Math.round` яртыларны өскә түгәрәкли (`-2.5` `-2` бирә); Rust'ның `round`'ы нульдән читкә түгәрәкли. Ясалган `js.rs` эчендә `js::math_round` бар.
- `${n}` `1e+21`, `5e-324` һәм `-0` өчен `0` бастыра. `js::number_to_string` моны кабатлый.
- `String.prototype.trim` Rust'ның `char::is_whitespace`'ын түгел, JS буш урыннарын куллана.

## Тизлек

Бер чакыруга порт һәр тапкыр bridge өчен түли, ә V8 кечкенә функцияләрне наносекундларда башкара. vercel/ms язып алынган очраклары буенча бер чакыруга 0.56x тизлектә эшләде; x18n үзәге портлары JS'тан чакырылганда TS'тан әкренрәк. Batch'лар итеп, цикл Rust'ка күчә:

| Эш йөкләмәсе | Оригинал | everything-rust белән |
| --- | ---: | ---: |
| x18n ян панелендәге эзләү, 50,000 ачкыч (Node) | бер сорауга 10 ms | 0.5 ms: 20x тизрәк |
| Шул ук эзләү браузерда (wasm, бер агым) | 10 ms | 0.95 ms: 11.5x |
| Fuse.js, 50,000 юл | 91.2 ms | 2.8 ms: 32x |
| vercel/ms `parse` x100,000 | 11.8 ms | 0.65 ms: 18x (тапшыруны исәпләгәндә 3.4x) |
| vercel/ms `format` x100,000 | 2.1 ms | тапшыру белән 2.5 ms: 0.8x |

Тикшеренүләр: [json-server](/docs/real-world/json-server), [Fuse.js](/docs/real-world/fuse-js), [vercel/ms](/docs/real-world/vercel-ms), [x18n](/docs/real-world/x18n).
