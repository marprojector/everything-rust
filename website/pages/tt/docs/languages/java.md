Batch'лар `new FnBatch(items)`; эш беткәч аларны ябыгыз. `profile` JFR куллана.

## Порт нәрсәне дөрес эшләргә тиеш

- `Integer.parseInt` `Character.digit` аша теләсә нинди Unicode унарлы цифрны (`١٢`, `２`) кабул итә.
- `Double.toString` (JDK 19+) иң кыска унарлы форманы бастыра, ләкин беркайчан да ике цифрдан ким түгел: `4.9E-324`, ә Rust'ның иң кыска формасы `5e-324`.
- `\s` бары ASCII гына; Rust'ның `split_whitespace`'ы U+00A0'да да бүлә.
- Float'лар әйләнеп кайтуда сакланырга тиеш: `serde_json`'ның килешү буенча float парсеры һәрвакыт дөрес түгәрәкләми, шуңа күрә everything-rust һәм ул ясаган һәр crate аның `float_roundtrip` мөмкинлеген куллана.

## Тизлек

JIT'тан соң ахыргы функцияләр берничә наносекунд ала, ә юллар белән JNI чакыруы моннан кыйммәтрәк. JDK фасадында `bench` портны бер чакыруга 0.18x дип үлчәде: зуррак берәмлекләрне күчерегез. 4 ядрода batch итеп, 50,000 юлга `slugify` (Java'да 43 ms) **3x тизрәк** эшләде (бер чакыруга порт: 0.68x).
