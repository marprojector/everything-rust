# Gate

```sh
everything-rust gate <crate>
```

Әзер дигән сүз `gate` уза дигәнне аңлата. Ул тикшерә:

- `cargo fmt`, `-D warnings` белән clippy һәм cargo тестлары;
- `unsafe` бары `// SAFETY:` аңлатмалары белән генә, һәм бер генә `unimplemented!` тә юк;
- оригинал махсус уңышсызлыкка китергән һәр урын өчен (`throw`, `raise`, `error` нәтиҗәсе) язып алынган уңышсыз очрак. Gate аны атаса, `record --inputs` белән өстәгез;
- оригиналы хата кайтара торган функциядә `unwrap`, `expect` яки `panic!` юк. `Err` кайтарыгыз; оригинал да мөмкин түгел дип санаган халәт өчен `// INFALLIBLE: <why>` аңлатмасы языгыз;
- порт оригинал юлларының иң күбе 3x (өстәвенә импортлар һәм сигнатуралар өчен 50 юл);
- модуль җыела һәм һәр экспорт бар;
- язып алынган һәр очрак туры килә, [билгеле аермалар](/docs/concepts/diff#known-diffs) да исәптә, һәм язма [искергән](/docs/concepts/diff#stale-recordings) түгел;
- TS/JS өчен [колачлау](/docs/concepts/coverage) юлы: очраклар оригиналның күпме өлешен җибәргән.

Һәр уңышсыз тикшерү `fix` йөртә: башта шуны җибәрегез.

## Аннары хисап бирегез һәм көтегез

Gate узгач, workflow skill агенттан нәрсә үзгәргәне (файллар, функцияләр, bridge, batch'лар), gate чыгышы, diff саннары һәм bench саннары, калган тәртип аермалары яки куркынычлар һәм планда нәрсә калганы турында хисап бирүне һәм киләсе берәмлек алдыннан рөхсәт көтүне таләп итә.
