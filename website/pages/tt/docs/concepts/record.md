# Язып алу

```sh
everything-rust record <crate>
everything-rust record <crate> --from-tests -- npx jest      # яки: -- pytest
everything-rust record <crate> --inputs extra.jsonl
```

`record` оригинал функцияләрне җибәрә һәм һәрберсе нәрсә кайтарганын яки нинди хата ыргытканын crate янәшәсендәге `cases.jsonl` эчендә саклый: порт туры килергә тиешле тәртип. Соңрак туры килмәү ул тәртиптәге аерма: язманы түгел, портны төзәтегез.

## Очраклар каян килә

- **Ясалган чик очраклар**: ASCII булмаган текст, эмодзи, `-0`, `NaN`, float көтелгән урында бөтен саннар һәм башкалар (`--count` һәр функциягә күпме икәнен билгели).
- Һәр параметрда **семантик тозаклар**: юл озынлыгы һәм регистр, тамгалы бүлү, ташу чикләре, float бастыру, map һәм сортлау тәртибе.
- Regex кулланган файлдагы һәр функция өчен **regex тозаклары**: төрек нокталы булмаган `ı`, Кельвин билгесе, озын s, гарәп-һинд цифрлары, юл аергычлары, ахыргы сигма, zero-width joiner'лар.
- **Оригиналның үз тестлары**: `--from-tests -- <test command>` тест җыелмасы берәмлекнең экспортланган функцияләренә ясаган һәр чакыруны язып ала (TS/JS теләсә нинди runner белән, Python pytest яки unittest белән). Аннары чыганак код кире торгызыла. vercel/ms'та ул 167 Jest тестыннан 340 чакыру язып алды.
- **Сезнең кертмәләр**: һәр юлда бер `{"fn": name, "args": [...]}` булган `--inputs cases.jsonl`. Чын кертмәләр өстәгез (production'нан үрнәкләр, хата хисаплары); prod'ны боза торган кулланучы кертмәсен генератор сирәк уйлап таба.

Python'да чакыручылар `1`'не `1.0` кебек үк еш бирә, шуңа күрә язып алу һәр дүртенче Python очрагында бөтен кыйммәтле саннарны int итеп бирә.

## cases.jsonl эчендәге билгеләр

JSON `undefined`, NaN, Infinity, -0 яки ялгыз сурогатларны белдерә алмый. Структуралы кыйммәтләр билгеләр йөртә, аларны ясалган `index.cjs` тәрҗемә итә, ярдәмчеләр crate'ның `js.rs` файлында:

| Билге | Мәгънәсе |
| --- | --- |
| `{"$undefined": true}` | JavaScript `undefined` |
| `{"$num": "NaN"}` | JSON саклый алмаган сан (`NaN`, `Infinity`, `-0`) |
| `{"$utf16": [...]}` | ялгыз сурогатлар өчен UTF-16 код берәмлекләре итеп бирелгән юл |

Функция контрактыннан читтәге C кертмәләре оригиналны җимерергә мөмкин. C драйверы һәр очракны fork ителгән бала процессында җибәрә һәм `crash: SIGSEGV` язып ала; `diff` анда портның теләсә нинди тәртибен кабул итә, чөнки C'ныкы билгеләнмәгән.

## Ике җибәрү һәм нәрсә аерыла

`record` оригиналны ике тапкыр җибәрә һәм җибәрүләр арасында нәрсә аерылганын сортлый: үзгәргән кыйммәтләр (вакыт, id) wildcard'ка әйләнә; башка тәртиптәге шул ук юллар (hash map'лар, параллельлек) теләсә нинди тәртиптә чагыштырыла; юллар санының аермасы `...` була, ул теләсә нәрсәгә туры килә. `record` һәр төрне күрсәтә. Һәрберсен карагыз, чөнки hash тәртибе яки параллельлек аермасы нәкъ менә портта чынлап үзгәрә ала торган нәрсә.

## Язма үзенең оригиналын хәтерли

`record` берәмлек файлларының бармак эзен саклый (`recorded-from.json`). Оригинал соңрак үзгәрсә, `diff` кисәтә һәм сез яңадан язып алмыйча `gate` узмый, оригиналның элек нәрсә эшләгәненә карап уза бирми. [Diff](/docs/concepts/diff#stale-recordings) битен карагыз.

## TypeScript үзенчәлекләре

`record` TS чыганакларын булганча җибәрә: Node resolve hook bundler стилендәге импортларга иярә (`./errors` юлын `./errors.ts`'ка), `--resolve-from` репозиторийда урнаштырылмаган npm пакетларын бирә, ә үзгәртү таләп иткән TS (enum'нар, parameter properties) `--experimental-transform-types` белән кабат җибәрелә. Node'та турыдан-туры эшли алмаган TS'ны build чыгышыннан `--module dist/x.mjs` белән яки `--node-arg=--import=tsx` белән язып алып була.

## Сан белән эшләүче код

Float'лары сирәк кенә битка кадәр туры килә торган код өчен `--float-tolerance` белән язып алыгыз. [Float төгәллеге](/docs/concepts/float-tolerance) битен карагыз.
