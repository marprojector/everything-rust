# Цикл

Һәр порт, бер кайнар функциядән алып бөтен кушымтага кадәр, бер үк адымнар аша бер тапкырда бер берәмлек уза. Порт `gate` узгач кына әзер санала.

everything-rust портны ничек тикшерә, аның командалары нәрсәне хәл итә һәм аның чикләре кайда. [README](/) битенә кайту.

## Ничек эшли

```
profile ──> analyze ──> bridge ──> record ──> port.rs ──> diff ──> bench ──> shadow ──> gate
 where the    what to     the Rust   what the    you or      every     faster?    both side   done means
 time goes    port first  crate and  original    your agent  recorded  the        by side in  this passes
                          wrapper    does        write it    case      verdict    production
```

Оригинал дөреслек чыганагы булып кала: `record` аны чик очракларда (һәм сезнең үз кертмәләрегездә) җибәрә һәм
ул нәрсә кайтарганын яки нинди хата ыргытканын саклый; `diff` һәр очракны Rust'та кабат уйната; алар барысы да
туры килмичә һәм `gate` узмыйча, бернәрсә дә чыгарылмый. Чакыручылар бөтен юл буе оригинал API'ны саклый.

Бөтен кушымта да шул ук циклны берәмлекләп уза, бөтен программаны исбатлаучы
рамка эчендә ([Бөтен кушымтаны күчерү](/docs/whole-apps/overview)):


## Цикл

| Адым | Команда | Нәрсә эшли |
| --- | --- | --- |
| 0. Профильләү | `everything-rust profile <repo> -- node bench.mjs` | Чын эш йөкләмәсен телнең профильләүчесе астында җибәрә (node, cProfile, `go test` pprof, JFR, Ruby трейсеры): инклюзив вакыт буенча кайнар функцияләр, аларны чакыручылар һәм кайсы циклларны batch итәргә; Rust аз отыш бирә торган инде компиляцияләнгән кодны (numba, Cython, JAX) билгели |
| 1. Планлаштыру | `everything-rust analyze <repo>` | Берәмлекләр, күчерү тәртибе, `file:line` белән куркынычлар, һәр берәмлек өчен bridge, бәйлелекләрнең crate'ларга туры килүе, иң яхшы беренче портлар; `--whole-app` керү нокталарын һәм форманы, һәр бәйлелекне (импортланган яки игълан ителгән) аның crate'ы белән, өлешләрне (бер-берсен импортлаучы берәмлекләр бергә күчә) һәм тәкъдим ителгән җавап белән номерланган карарларны өсти |
| 2. Bridge | `everything-rust bridge <repo> <unit>` | Binding'лар (`lib.rs`, өстәвенә чыганак тел йөкли торган wrapper) һәм күчерү өчен буш функцияләр (`port.rs`) белән crate; `--batch fn:param` күп `param` кыйммәтләрен Rust'та тотучы класс өсти; `--as-json T` кушымта мәгълүмат белән генә тутыра торган тип параметрын JSON кыйммәтләре итеп күчерә |
| 3. Язып алу | `everything-rust record <crate>` | Оригиналны ясалган чик очракларда (ASCII булмаган текст, эмодзи, `-0`, `NaN`, float көтелгән урында бөтен саннар, ...) һәм һәр параметрдагы һәр семантик тозакта (юл озынлыгы һәм регистр, тамгалы бүлү, ташу чикләре, float бастыру, map һәм сортлау тәртибе) җибәрә һәм `cases.jsonl` саклый; `--from-tests -- npx jest` (яки `-- pytest`) оригиналның үз тест җыелмасы ясаган һәр чакыруны да язып ала; `--float-tolerance 1e-9` сан белән эшләүче код өчен float'ларга шул өлеш чикләрендә туры килергә мөмкинлек бирә |
| 3. Build | `everything-rust build <crate>` | Rust ягын җыя: `.node`, wasm пакеты, Python киңәйтмәсе яки уртак китапханә |
| 3. Diff | `everything-rust diff <crate>` | Язып алынган очракларны Rust'та, оригиналны аның чакыручылары чакырган рәвештә, кабат уйната; туры килмәүләрне күрсәтә |
| 3. Бенчмарк | `everything-rust bench <crate>` | Язып алынган очракларны оригиналда һәм Rust'та, bridge белән бергә, вакытка үлчи |
| 4. Shadow | `everything-rust shadow <crate>` | Икесен дә җибәрүче, оригиналның нәтиҗәсен кайтаручы, туры килмәүләр турында хәбәр итүче алмаштыргыч; `EVERYTHING_RUST_MODE=old\|shadow\|new` |
| 5. Gate | `everything-rust gate <crate>` | fmt, clippy `-D warnings`, тестлар, `unsafe` аудиты, күчерелмәгән бернәрсә дә юк, оригиналның һәр хата юлы өчен язып алынган уңышсыз очрак, оригинал хата кайтарган урында `unwrap`/`expect`/`panic!` юк (`// INFALLIBLE: <why>` дип билгеләнмәсә), build, API, тәртип |
| Агентлар | `everything-rust setup` | MCP серверны (`everything-rust mcp`, һәр адым корал итеп) һәм workflow skill'ны ([`skills/everything-rust/SKILL.md`](https://github.com/marprojector/everything-rust/blob/main/skills/everything-rust/SKILL.md)) программалау агентларыгызда теркәп куя |

## Кайнар юллар: мәгълүматны Rust'та тотыгыз

Һәр элемент өчен бер тапкыр чакырылган порт bridge өчен һәр элементка бер тапкыр түли һәм JIT'тан оттыра. Отыш бирә торганы
циклны күчерү: `profile` аны таба, ә `--batch` элементларны бер тапкыр алып,
һәр чакыруда функцияне аларның барысына барлык ядроларда җибәрүче һәм typed array нәтиҗәләре кайтаручы класс ясый.

```sh
everything-rust profile ../x18n -- node --experimental-strip-types $PWD/demo/x18n-search/search.ts .
# -> fuzzyScore: җибәрүнең чиреге, `matched` аны һәр ачкыч өчен чакыра: batch итегез
everything-rust bridge ../x18n packages/core/src/fuzzy.ts --batch fuzzyScore:text
```

```js
const search = new FuzzyScoreBatch(keys)          // once
const order = search.rank(query, 0)               // per keystroke: indexes, best first
```

`port.rs` эчендәге `FuzzyScoreIndex` структурасы килешү буенча циклны элементларны бер тапкыр әзерләүче
цикл белән алыштыра һәм үзе рейтинглый ала (`rank`): ул ачкычларны кечкенә хәрефләргә күчереп, һәрберсен символ
маскасы белән саклый, һәр ачкычта һәр еш очрый торган символның беренче позициясе таблицасын (бер хәрефле сорау бер
багана) һәм соңгы сорауның туры килүләрен тота (`s`'тан соң `se` язу `s` туры килгәннәрне генә яңадан бәяли). x18n
ян панелендәге 50,000 ачкыч буенча эзләүдә, хәрефләп язганда, нәтиҗәләр бертөрле:

| | Бер сорауга | TS'ка карата |
| --- | ---: | ---: |
| TS: `map(fuzzyScore)`, filter, sort | 10 ms | 1x |
| Индекс белән бер үк тарайту ясаучы TS | 4.1-5.4 ms | 2x |
| Шул ук порт, һәр ачкыч өчен чакырыла | - | 0.2-0.4x |
| `FuzzyScoreBatch`, килешү буенча индекс (4 ядро) | 5.1 ms | 1.7x |
| `FuzzyScoreIndex` белән `FuzzyScoreBatch` (napi, 4 ядро) | 0.45-0.56 ms | **18-22x** |
| Шул ук wasm белән (бер агым) | 0.95 ms | **11.5x** |

Шул ук тарайтуны ясаучы TS белән чагыштырганда да Rust 7-12x тизрәк (wasm 5x). Кайтарылган
индексларны гади цикл белән ачкычларга әйләндерегез: `Array.from(order, i => keys[i])` 20x кыйммәтрәк тора, 0.4 ms.

Һәр тел batch'лар ала, һәм алар бер чакыруга портлар оттырган урында да оригиналдан уздыра.
4 ядрода шул ук эш, нәтиҗәләр һәм хаталар бертөрле (бенчмарклар һәр demo папкасында):

| Тел | Эш йөкләмәсе | Оригинал | Бер чакыруга порт, оригиналга карата | Batch, оригиналга карата |
| --- | --- | ---: | ---: | ---: |
| TS | x18n эзләве, 50,000 ачкыч | 10 ms | 0.2-0.4x | **20x** |
| Python | `slugify`, 20,000 юл | 98 ms | - | **17x** |
| Ruby | `slugify`, 20,000 юл | 110 ms | - | **12.7x** |
| Ruby | `shellescape` (stdlib), 50,000 катнаш кыйммәт | 88 ms | - | **11.8x** |
| Go | `Slugify`, 50,000 юл | 49 ms | 0.93x | **4x** |
| Java | `slugify`, 50,000 юл | 43 ms | 0.68x | **3x** |

Компиляцияләнгән оригиналлар азрак отыш ала: бер элементка эш инде тиз, шуңа күрә batch ядролар саны
кадәр генә отыш бирә. Batch crate'лары хәтерне mimalloc белән бүлә: система аллокаторы белән Go batch
бер агымнан әкренрәк иде. Demo: [`demo/x18n-search`](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-search/README.md).

## `bridge` нәрсәне хәл итә

- Bridge аша уза алмаган экспортлар, сәбәбе күрсәтелеп, чыганак телдә кала, һәм shadow
  модуле оригиналны кабат экспортлый. TS өчен:
  функция кабул итүче яки кайтаручы функцияләр, генераторлар һәм итераторлар, RegExp, `instanceof` тикшерүләре,
  generic'лар (`--as-json T` кушымта мәгълүмат белән генә тутыра торганын күчерә), һәм типлары (импортлар, кабат экспортлар һәм `extends` буенча эзләнеп) функция
  тотучы кыйммәтләр. `--keep "name: reason"` тагын калдыра, мәсәлән, `Intl` мәгълүматларына бәйле код.
- TS типлары Rust типларына туры китерелә, тип псевдонимнары импортлар аша чишелә, ә параметр типлары
  килешү буенча кыйммәтләрдән чыгарыла; структуралы кыйммәтләр ясалган бинар wire аша күчә (JSON бары
  wire модельләштермәгән формалар өчен fallback итеп кына).
- JSON `undefined`, NaN, Infinity, -0 яки ялгыз сурогатларны белдерә алмый: структуралы кыйммәтләр
  билгеләр йөртә (`{"$undefined": true}`, `{"$num": "NaN"}`, `{"$utf16": [...]}`), аларны ясалган
  `index.cjs` тәрҗемә итә, ярдәмчеләр crate'ның `js.rs` файлында.

`record` TS чыганакларын булганча җибәрә: Node resolve hook bundler стилендәге импортларга иярә
(`./errors` юлын `./errors.ts`'ка), `--resolve-from` репозиторийда урнаштырылмаган npm пакетларын
бирә, ә үзгәртү таләп иткән TS (enum'нар, parameter properties)
`--experimental-transform-types` белән кабат җибәрелә.

## `analyze` нәрсәгә карый

- Пакетлар (`package.json`) һәм чыганак файллар; `node_modules`, build чыгышы, fixture'лар,
  playground'лар, корал конфигларын төшереп калдыра. Vue/Svelte/Astro `<script>` блоклары импортлар өчен укыла.
- **Берәмлекләр**: чыганак файллар папкасы яки пакетның чыганак тамырындагы файл.
- **Дулкыннар**: берәмлекнең импортлары алданрак дулкыннарда килә; импорт цикллары бергә күчерелә.
- **Bridge**: берәмлеккә яки ул импортлаган нәрсәгә Node кирәк булса, napi-rs; күчмә код өчен wasm-bindgen;
  UI һәм редактор коды өчен JS'та калдыру.
- **Әзерлек** (никадәр куркынычсыз) һәм **өстенлек** (куркынычсыз һәм лаеклы: цикллар һәм юллар белән эш, тестлар, зурлык).

| Куркыныч | Җитдилек | Мисал |
| --- | --- | --- |
| Юл офсетлары | югары | `slice`, `indexOf`, `matchAll`, `d` флагы: UTF-16 һәм UTF-8 |
| Regex синтаксисы | югары | lookaround, кире сылтамалар, `y`: `regex` crate'ында юк |
| Динамик regex | югары | `new RegExp(userPattern)`: эш вакытында JS синтаксисы |
| Динамик код | югары | `eval`, `new Function`, исәпләнгән `import()` |
| Динамик типлаштыру | урта | `any`, `'key' in value` |
| Тәртипле коллекцияләр | урта | `Map`, `Set`, `Object.keys`: өстәү тәртибе |
| Async, генераторлар | урта | promise һәм генератор чикләре |
| Класс варислыгы, reflection | урта | `extends`, `Proxy`, `Reflect`, `Symbol` |
| Callback формасындагы API'лар | урта | функция типлы параметрлар һәм методлар: сөйләшүчән bridge'лар |
| Исключениеләр, саннар, JSON | түбән | `throw`, бит операцияләре, `JSON.stringify` тәртибе |

## Ул нәрсәне тотып кала алмый

Узу Rust язып алынган һәр очракка туры килә дигәнне генә аңлата, артыгын түгел. Яңадан язуларны еш кына
язмадан читтә яткан нәрсә бозып куя, шуңа күрә чикләрнең кайда икәнен белегез:

- **Беркем дә язып алмаган кертмәләр.** Ясалган очраклар, тозаклар, оригиналның тест җыелмасы
  (`record --from-tests`) һәм сезнең үз `--inputs` файлыгыз түшәм булып тора. Чын кертмәләр өстәгез (production'нан
  үрнәкләр, хата хисаплары); prod'ны боза торган кулланучы кертмәсен генератор сирәк уйлап таба.
- **Алга киткән оригинал.** `record` берәмлек файлларының бармак эзен саклый
  (`recorded-from.json`); оригинал соңрак үзгәрсә, `diff` кисәтә һәм сез яңадан язып алмыйча
  `gate` узмый, оригиналның элек нәрсә эшләгәненә карап уза бирми.
- **Regex'лар.** `regex` crate'ында lookaround һәм кире сылтамалар юк, һәм хәтта компиляцияләнгән
  үрнәк тә ASCII булмаган текстта `\w`, `\b`, `\d` һәм регистрга карамаган эзләүне JS, Python яки Java'дан
  башкача эшкәртергә мөмкин. `fancy-regex` куллану яки үрнәкне яңадан язу язып алынган һәр
  очракны узарга һәм шулай да төрек нокталы булмаган `ı` яки zero-width joiner'да аерылырга мөмкин. `record`
  regex кулланган файлдагы һәр функциягә regex тозакларын өсти (шулар, Кельвин билгесе, озын s, гарәп-һинд цифрлары, юл аергычлары, ахыргы сигма),
  ләкин чын үрнәкләрегезне чын текстта fuzz белән дә тикшерегез.
- **Җибәрүләр арасында нәрсә үзгәрә.** `record` оригиналны ике тапкыр җибәрә һәм нәрсә аерылганын сортлый:
  үзгәргән кыйммәтләр (вакыт, id) wildcard'ка әйләнә; башка тәртиптәге шул ук юллар (hash map'лар,
  параллельлек) теләсә нинди тәртиптә чагыштырыла, шуңа күрә порт барыбер нәкъ шул юлларны чыгарырга тиеш;
  юллар санының аермасы `...` була, ул теләсә нәрсәгә туры килә. `record` һәр төрне күрсәтә:
  һәрберсен карагыз, чөнки hash тәртибе яки параллельлек аермасы нәкъ менә портта чынлап үзгәрә
  ала торган нәрсә.
- **Float'лар.** Санны текстка форматлау телләр арасында аерыла (`1e21`, `-0`, цифрлар саны).
  Тозаклар бу кыйммәтләрне үз эченә ала, һәм алар төгәл туры килергә тиеш; `--float-tolerance` бары
  түгәрәкләүне генә гафу итә, форматлауны беркайчан да түгел.
- **Чыгышта булмаган нәрсә.** Вакыт, хәтер, йөкләнеш астындагы параллельлек һәм stdout, stderr, чыгу кодлары,
  язылган файллар һәм HTTP җаваплардан башка ян эффектлар (челтәр чакырулары, мәгълүмат базалары,
  сигналлар) чагыштырылмый.
- **Башка платформалар.** Язма аны җибәргән машинадагы тәртипне генә исбатлый. Нәтиҗәләре
  тип зурлыкларына, байт тәртибенә яки компиляторга бәйле C коды максат платформада башкача эшли ала; шуңа күрә `analyze`
  җиһаз белән эшләүче C кодын C'та калдыра.
## Һәр адым

| Адым | Команда | Нәрсә эшли |
| --- | --- | --- |
| 0. Профильләү | `everything-rust profile <repo> -- node bench.mjs` | Чын эш йөкләмәсен телнең профильләүчесе астында җибәрә (node, cProfile, `go test` pprof, JFR, Ruby трейсеры): инклюзив вакыт буенча кайнар функцияләр, аларны чакыручылар һәм кайсы циклларны batch итәргә; Rust аз отыш бирә торган инде компиляцияләнгән кодны (numba, Cython, JAX) билгели |
| 1. Планлаштыру | `everything-rust analyze <repo>` | Берәмлекләр, күчерү тәртибе, `file:line` белән куркынычлар, һәр берәмлек өчен bridge, бәйлелекләрнең crate'ларга туры килүе, иң яхшы беренче портлар; `--whole-app` керү нокталарын һәм форманы, һәр бәйлелекне (импортланган яки игълан ителгән) аның crate'ы белән, өлешләрне (бер-берсен импортлаучы берәмлекләр бергә күчә) һәм тәкъдим ителгән җавап белән номерланган карарларны өсти |
| 2. Bridge | `everything-rust bridge <repo> <unit>` | Binding'лар (`lib.rs`, өстәвенә чыганак тел йөкли торган wrapper) һәм күчерү өчен буш функцияләр (`port.rs`) белән crate; `--batch fn:param` күп `param` кыйммәтләрен Rust'та тотучы класс өсти; `--as-json T` кушымта мәгълүмат белән генә тутыра торган тип параметрын JSON кыйммәтләре итеп күчерә |
| 3. Язып алу | `everything-rust record <crate>` | Оригиналны ясалган чик очракларда (ASCII булмаган текст, эмодзи, `-0`, `NaN`, float көтелгән урында бөтен саннар, ...) һәм һәр параметрдагы һәр семантик тозакта (юл озынлыгы һәм регистр, тамгалы бүлү, ташу чикләре, float бастыру, map һәм сортлау тәртибе) җибәрә һәм `cases.jsonl` саклый; `--from-tests -- npx jest` (яки `-- pytest`) оригиналның үз тест җыелмасы ясаган һәр чакыруны да язып ала; `--float-tolerance 1e-9` сан белән эшләүче код өчен float'ларга шул өлеш чикләрендә туры килергә мөмкинлек бирә |
| 3. Build | `everything-rust build <crate>` | Rust ягын җыя: `.node`, wasm пакеты, Python киңәйтмәсе яки уртак китапханә |
| 3. Diff | `everything-rust diff <crate>` | Язып алынган очракларны Rust'та, оригиналны аның чакыручылары чакырган рәвештә, кабат уйната; туры килмәүләрне күрсәтә |
| 3. Бенчмарк | `everything-rust bench <crate>` | Язып алынган очракларны оригиналда һәм Rust'та, bridge белән бергә, вакытка үлчи |
| 4. Shadow | `everything-rust shadow <crate>` | Икесен дә җибәрүче, оригиналның нәтиҗәсен кайтаручы, туры килмәүләр турында хәбәр итүче алмаштыргыч; `EVERYTHING_RUST_MODE=old\|shadow\|new` |
| 5. Gate | `everything-rust gate <crate>` | fmt, clippy `-D warnings`, тестлар, `unsafe` аудиты, күчерелмәгән бернәрсә дә юк, оригиналның һәр хата юлы өчен язып алынган уңышсыз очрак, оригинал хата кайтарган урында `unwrap`/`expect`/`panic!` юк (`// INFALLIBLE: <why>` дип билгеләнмәсә), build, API, тәртип |
| Агентлар | `everything-rust setup` | MCP серверны (`everything-rust mcp`, һәр адым корал итеп) һәм workflow skill'ны ([`skills/everything-rust/SKILL.md`](https://github.com/marprojector/everything-rust/blob/main/skills/everything-rust/SKILL.md)) программалау агентларыгызда теркәп куя |
