# Batch'лар һәм кайнар юллар

```sh
everything-rust bridge <repo> <unit> --batch fn:param    # яки: everything-rust refresh <crate> --batch fn:param
```

`--batch` `param` кыйммәтләрен бер тапкыр алып, аларны Rust'та тотучы класс ясый: `new FnBatch(items)` (TS, Python, Java), `Mod::FnBatch.new(items)` (Ruby), `NewFnBatch(items)` (Go). Һәр сорауга `run(<other args>)` һәр нәтиҗәне бер массив итеп кайтара, ә `rank(<other args>, min)` элемент индексларын, иң яхшысыннан башлап, кайтара. Ул барлык ядроларда эшли, һәм хаталар оригиналныкы. C'тан кала һәр тел batch'лар ала.

Һәр элемент өчен бер тапкыр чакырылган порт bridge өчен һәр элементка бер тапкыр түли һәм JIT'тан оттыра. Отыш бирә торганы
циклны күчерү: `profile` аны таба, ә `--batch` элементларны бер тапкыр алып,
һәр чакыруда функцияне аларның барысына барлык ядроларда җибәрүче һәм typed array нәтиҗәләре кайтаручы класс ясый.

```sh
everything-rust profile ../x18n -- node --experimental-strip-types $PWD/demo/x18n-search/search.ts .
# -> fuzzyScore: җибәрүнең чиреге, `matched` аны һәр ачкыч өчен чакыра: batch итегез
everything-rust bridge ../x18n packages/core/src/fuzzy.ts --batch fuzzyScore:text
```

```js
const search = new FuzzyScoreBatch(keys)          // once
const order = search.rank(query, 0)               // per keystroke: indexes, best first
```

`port.rs` эчендәге `FuzzyScoreIndex` структурасы килешү буенча циклны элементларны бер тапкыр әзерләүче
цикл белән алыштыра һәм үзе рейтинглый ала (`rank`): ул ачкычларны кечкенә хәрефләргә күчереп, һәрберсен символ
маскасы белән саклый, һәр ачкычта һәр еш очрый торган символның беренче позициясе таблицасын (бер хәрефле сорау бер
багана) һәм соңгы сорауның туры килүләрен тота (`s`'тан соң `se` язу `s` туры килгәннәрне генә яңадан бәяли). x18n
ян панелендәге 50,000 ачкыч буенча эзләүдә, хәрефләп язганда, нәтиҗәләр бертөрле:

| | Бер сорауга | TS'ка карата |
| --- | ---: | ---: |
| TS: `map(fuzzyScore)`, filter, sort | 10 ms | 1x |
| Индекс белән бер үк тарайту ясаучы TS | 4.1-5.4 ms | 2x |
| Шул ук порт, һәр ачкыч өчен чакырыла | - | 0.2-0.4x |
| `FuzzyScoreBatch`, килешү буенча индекс (4 ядро) | 5.1 ms | 1.7x |
| `FuzzyScoreIndex` белән `FuzzyScoreBatch` (napi, 4 ядро) | 0.45-0.56 ms | **18-22x** |
| Шул ук wasm белән (бер агым) | 0.95 ms | **11.5x** |

Шул ук тарайтуны ясаучы TS белән чагыштырганда да Rust 7-12x тизрәк (wasm 5x). Кайтарылган
индексларны гади цикл белән ачкычларга әйләндерегез: `Array.from(order, i => keys[i])` 20x кыйммәтрәк тора, 0.4 ms.

Һәр тел batch'лар ала, һәм алар бер чакыруга портлар оттырган урында да оригиналдан уздыра.
4 ядрода шул ук эш, нәтиҗәләр һәм хаталар бертөрле (бенчмарклар һәр demo папкасында):

| Тел | Эш йөкләмәсе | Оригинал | Бер чакыруга порт, оригиналга карата | Batch, оригиналга карата |
| --- | --- | ---: | ---: | ---: |
| TS | x18n эзләве, 50,000 ачкыч | 10 ms | 0.2-0.4x | **20x** |
| Python | `slugify`, 20,000 юл | 98 ms | - | **17x** |
| Ruby | `slugify`, 20,000 юл | 110 ms | - | **12.7x** |
| Ruby | `shellescape` (stdlib), 50,000 катнаш кыйммәт | 88 ms | - | **11.8x** |
| Go | `Slugify`, 50,000 юл | 49 ms | 0.93x | **4x** |
| Java | `slugify`, 50,000 юл | 43 ms | 0.68x | **3x** |

Компиляцияләнгән оригиналлар азрак отыш ала: бер элементка эш инде тиз, шуңа күрә batch ядролар саны
кадәр генә отыш бирә. Batch crate'лары хәтерне mimalloc белән бүлә: система аллокаторы белән Go batch
бер агымнан әкренрәк иде. Demo: [`demo/x18n-search`](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-search/README.md).
## Тиз индекс язу

- Чакыручы batch'ны һәр сорауга түгел, бер тапкыр төзесен. Кайтарылган индексларны элементларга гади цикл белән кире әйләндерегез.
- Элементларны бер тапкыр әзерләү өчен (кечкенә хәрефләр, маскалар, позиция таблицалары) `port.rs` эчендә `new(items)` һәм `run(<other args>)` белән `pub struct FnIndex` билгеләгез. Ул элемент саен функция белән бер үк нәтиҗә бирергә тиеш.
- Рейтинглау эшне калдырып китә алса, индекска үзенең `rank(<other args>, min)` методын бирегез. Ул функция нәтиҗәләрен рейтинглауга туры килергә тиеш: бәя зурдан кечкенәгә, тигезләрдә элементлар тәртибе.
- Batch портның бер элементка тизлеген ядролар санына тапкырлый. Компиляцияләнгән оригиналларга (Go, Java) каршы портның үзе тиз булырга тиеш: ASCII'ны Unicode таблицаларыннан башка эшкәртегез, һәр нәтиҗәне алдан зурлыгы билгеләнгән бер `String` эчендә төзегез, арадаш күчермәләрдән качыгыз.
- Go һәм Java'да эш беткәч batch'ны ябыгыз (finalizer'лар бары fallback кына).
