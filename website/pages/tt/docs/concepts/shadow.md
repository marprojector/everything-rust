# Shadow

```sh
everything-rust shadow <crate>
```

`shadow` оригинал API'лы алмаштыргыч ясый: TS яки Python модуле, Go пакеты, Ruby файлы, Java класслары яки C файлы. Аны кушымта оригиналны йөкләгән урында йөкләгез. Ул икесен дә җибәрә, оригиналның нәтиҗәсен кайтара һәм production'да ышаныч туплаганда Rust туры килмәүләре турында хәбәр итә.

| `EVERYTHING_RUST_MODE` | Тәртип |
| --- | --- |
| `shadow` (килешү буенча) | икесен дә җибәрә, оригиналның нәтиҗәсен кайтара, туры килмәүләр турында хәбәр итә |
| `new` | Rust'ка күчә |
| `old` | Rust'ны сүндерә |

Ачык API үзгәрми. Чакыручылар шул ук функцияләрне яки алар урынына shadow модулен импортлый.
