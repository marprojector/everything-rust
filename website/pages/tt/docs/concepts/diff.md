# Diff һәм билгеле аермалар

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # N/N булырга тиеш
everything-rust diff <crate> --json
```

`diff` `cases.jsonl` файлын җыелган Rust модулендә, оригиналны аның чакыручылары чакырган рәвештә, кабат уйната һәм туры килмәүләрне күрсәтә. Туры килмәү ул тәртиптәге аерма: язманы түгел, портны төзәтегез.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## Билгеле аермалар

Кайвакыт порт теләп аерылырга тиеш: кулланучы аның оригиналдагы хатаны төзәтүен тели. Башта сорагыз, аннары `<crate>/known-diffs.jsonl` файлына һәр очрак өчен бер юл өстәгез:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

`fn`, `args` һәм `actual` кыйммәтләрен `diff --json` чыгышыннан күчереп алыгыз. Шуннан соң ул очрак нәкъ шул нәтиҗә белән генә уза, ә аерма юкка чыкса, `gate` узмый, ул чакта юлны бетерегез.

## Искергән язмалар

`record` оригинал берәмлек файлларының бармак эзен `recorded-from.json` эчендә саклый. Оригинал соңрак үзгәрсә, `diff` кисәтә һәм сез яңадан язып алмыйча `gate` узмый, оригиналның элек нәрсә эшләгәненә карап уза бирми. `gate` язма искергән дисә, күчерүне дәвам иткәнче яңадан язып алыгыз.

## Порт тукталып калганда

`diff` build'лар буенча алгарышны күзәтә. Ул порт тукталып калды дисә (аның `trend.stalled`: `port.rs` файлындагы рәттән өч үзгәреш бер генә туры килгән очрак та өстәмәде), төзәтүне туктатыгыз. Калган туры килмәүләргә бары кулланучы гына белә торган кагыйдә кирәк булырга мөмкин, яки ул функцияләр әлегә оригиналда калырга мөмкин.

## Float төгәллеге

Crate `--float-tolerance` белән язып алынган булса, `diff` аны куллана; `diff` командасындагы `--float-tolerance` аны бер җибәрү өчен алыштыра. [Float төгәллеге](/docs/concepts/float-tolerance) битен карагыз.
