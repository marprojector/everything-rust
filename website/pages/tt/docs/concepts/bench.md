# Бенчмарк

```sh
everything-rust bench <crate>
```

`bench` язып алынган очракларны оригиналда һәм җыелган Rust модулендә, bridge белән бергә, вакытка үлчи һәм рәтләрне, шулай ук киңәшле нәтиҗә кайтара: чыгарырга, әкренрәк функцияләрне чыганак телдә калдырырга яки зуррак берәмлекне күчерергә. 1'дән кечкенә тизләнү порт аны чакыручылар чакырган рәвештә әкренрәк дигәнне аңлата. `--min-ms` һәр функция һәм һәр як өчен минималь үлчәү вакытын билгели (килешү буенча 200).

Нәтиҗәгә иярегез. Чакыручыларны әкренәйтә торган портны моны әйтмичә чыгармагыз.

## Порт ни өчен әкренрәк булырга мөмкин

Һәр элемент өчен бер тапкыр чакырылган порт bridge өчен һәр элементка бер тапкыр түли. Нәрсә хәл итә:

- **Интерпретацияләнә торган оригиналлар (Python, Ruby)**: Rust'ка чакыру якынча 100-300 ns тора, ә Rust коды интерпретатордан күпкә тизрәк, шуңа күрә кечкенә функцияләр дә отыш бирә.
- **Компиляцияләнгән оригиналлар (Go, JIT'тан соң Java)**: оригинал ахыргы функция 4-90 ns ала; бер cgo чакыруы гына да якынча 80 ns тора, юллар белән JNI чакыруы тагын да күбрәк. Бу телләр бер чакыру күп эш башкарганда гына отыш ала: функцияне аны чакыручылар белән бергә күчерегез.
- **C**: чик кичү юк; Rust коды C коды белән турыдан-туры чагыштырыла.

Чын кодта бер чакыруга үлчәнгән ([алты тел](/docs/real-world/six-languages)):

| Тел | Rust оригиналга карата (`bench`, геометрик урта) | Нәтиҗә |
| --- | --- | --- |
| Ruby | **4.4x тизрәк** (функция буенча 3.6-7x) | чыгарырга |
| Python | **1.35x тизрәк** (күпчелек чакыруларда 1.5-1.9x) | чыгарырга |
| C | 0.87x: ctype 1.1-1.4x тизрәк, glibc'ның көйләнгән `strtod`, `strspn`, `strcmp` функцияләре 0.5-0.7x | оптимальләштерергә яки әкренрәкләрне калдырырга |
| Java | 0.18x | зуррак берәмлекләрне күчерергә |
| Go | 0.04x | зуррак берәмлекләрне күчерергә |

x18n үзәгенең API үзгәртмичә күчә ала торган 29 функциясенең барысы да күчерелде: һәр gate уза һәм язып алынган 7,925 очрак төгәл туры килә, ә `bench` портларның JS'тан чакырылганда TS'тан әкренрәк икәнен күрсәтте, чөнки bridge эшнең үзеннән кыйммәтрәк ([хисап](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-core/README.md)). vercel/ms язып алынган очраклары буенча бер чакыруга 0.56x тизлектә эшләде ([тикшеренү](/docs/real-world/vercel-ms)).

## Нәрсә отыш бирә: циклны күчерү

`profile` кайнар функция тирәсендәге циклны таба, ә `--batch` бөтен циклны Rust'ка, барлык ядроларга күчерә. [Batch'лар һәм кайнар юллар](/docs/concepts/batches) битен карагыз.

::: tip Тыныч машинада үлчәгез
`bench` командасын тыныч машинада, ике тапкыр җибәрегез, һәм бастырылган һәр сан янында җиһазны һәм ядролар санын күрсәтегез.
:::
