# Bridge

```sh
everything-rust bridge <repo> <unit-id>          # crate <repo>/rust/<name> эчендә; беркайчан да өстән язмый
everything-rust refresh <crate>                  # port.rs эчендә сигнатураны үзгәрткәннән соң
```

`bridge` binding'лар (`lib.rs`, өстәвенә чыганак тел йөкли торган wrapper) һәм күчерү өчен буш функцияләр (`port.rs`) белән crate ясый. Портны сез `src/port.rs` эчендә генә язасыз; `src/lib.rs` һәм wrapper'лар ясалган файллар, һәм `refresh` аларны `port.rs` эчендәге сигнатуралардан яңадан ясый, яңа batch классларын да өсти. Ул `port.rs` файлына беркайчан да кагылмый.

Параметрлар:

- `--batch fn:param` күп `param` кыйммәтләрен Rust'та тотучы класс өсти. [Batch'лар](/docs/concepts/batches) битен карагыз.
- `--as-json T` кушымта мәгълүмат белән генә тутыра торган тип параметрын (`paginate<T>(items: T[])` эчендәге `T`) JSON кыйммәтләре итеп күчерә.
- `--keep "name: reason"` чыганак телдә тагын экспортлар калдыра, мәсәлән, `Intl` мәгълүматларына бәйле код.
- `--kind` план сайлаган bridge'ны алыштыра (TypeScript өчен napi-rs яки wasm).

## Телләр буенча bridge

| Тел | Bridge |
| --- | --- |
| TypeScript/JavaScript | ясалган бинар wire форматлы napi-rs яки wasm-bindgen; класслар һәм async та керә |
| Python | PyO3 (abi3), туры үзгәртү, типлы исключениеләр |
| C | оригинал исемле `extern "C"` функцияләр һәм header |
| Go | типлы cgo чакырулары һәм ясалган бинар wire формат, оригинал API'лы пакетта |
| Ruby | оригинал модульләр астында magnus киңәйтмәсе |
| Java | типлы JNI һәм ясалган бинар wire формат, оригинал методлы wrapper класслар эчендә |

PHP һәм C# берәмлекләре өчен bridge әлегә юк; [PHP](/docs/languages/php) һәм [C#](/docs/languages/csharp) битләрен карагыз.

## bridge нәрсәне хәл итә

- Bridge аша уза алмаган экспортлар, сәбәбе күрсәтелеп, чыганак телдә кала, һәм shadow
  модуле оригиналны кабат экспортлый. TS өчен:
  функция кабул итүче яки кайтаручы функцияләр, генераторлар һәм итераторлар, RegExp, `instanceof` тикшерүләре,
  generic'лар (`--as-json T` кушымта мәгълүмат белән генә тутыра торганын күчерә), һәм типлары (импортлар, кабат экспортлар һәм `extends` буенча эзләнеп) функция
  тотучы кыйммәтләр. `--keep "name: reason"` тагын калдыра, мәсәлән, `Intl` мәгълүматларына бәйле код.
- TS типлары Rust типларына туры китерелә, тип псевдонимнары импортлар аша чишелә, ә параметр типлары
  килешү буенча кыйммәтләрдән чыгарыла; структуралы кыйммәтләр ясалган бинар wire аша күчә (JSON бары
  wire модельләштермәгән формалар өчен fallback итеп кына).
- JSON `undefined`, NaN, Infinity, -0 яки ялгыз сурогатларны белдерә алмый: структуралы кыйммәтләр
  билгеләр йөртә (`{"$undefined": true}`, `{"$num": "NaN"}`, `{"$utf16": [...]}`), аларны ясалган
  `index.cjs` тәрҗемә итә, ярдәмчеләр crate'ның `js.rs` файлында.

`record` TS чыганакларын булганча җибәрә: Node resolve hook bundler стилендәге импортларга иярә
(`./errors` юлын `./errors.ts`'ка), `--resolve-from` репозиторийда урнаштырылмаган npm пакетларын
бирә, ә үзгәртү таләп иткән TS (enum'нар, parameter properties)
`--experimental-transform-types` белән кабат җибәрелә.
