# Профильләү һәм анализ

## Профильләү: күчерергә лаеклы нәрсәне табу

Максат тизлек булса, берәр нәрсә сайлаганчы үлчәгез:

```sh
everything-rust profile <repo> -- node bench.mjs      # яки: python3 bench.py, ruby bench.rb,
                                                    #      java -cp out Main, go test -run X -bench . ./pkg
```

`profile` чын эш йөкләмәсен телнең профильләүчесе астында җибәрә (node, cProfile, `go test` pprof, JFR, Ruby трейсеры) һәм кайнар функцияләрне инклюзив вакыт буенча, аларны чакыручыларны һәм кайсы циклларны batch итәргә кирәклеген күрсәтә. Go бары `go test` аша гына профильләнә; C өчен ярдәм юк.

- Һәр элемент өчен бер тапкыр чакырылган кечкенә функцияне аерым күчерергә **лаеклы түгел**: Rust'ка бер чакыру аның эшеннән кыйммәтрәк тора, ә JIT'лар (V8, JVM, Go) аны наносекундларда башкара. Аны чакыручылары белән бергә күчерегез яки [batch итегез](/docs/concepts/batches). Киңәш юлы кайсысын икәнен төгәл команда белән әйтә.
- Инде компиляцияләнгән код (numba `@njit`, Cython, `@jax.jit`) машина коды булып эшли: Rust порты тизлектә аз отыш бирә. `profile` аны "Already compiled" астында күрсәтә.

## Анализ: портны планлаштыру

```sh
everything-rust analyze <repo> -o plan.md        # кешеләр өчен
everything-rust analyze <repo> --json            # агентлар өчен: everything-rust/analyze@1 схемасы
everything-rust analyze <repo> --whole-app       # өстәвенә керү нокталары, форма, бәйлелекләр, карарлар
```

`analyze` берәмлекләрне, күчерү тәртибен, `file:line` белән куркынычларны, һәр берәмлек өчен bridge'ны, һәр бәйлелекнең crate'ка күпме туры килүен һәм `start_here` күрсәтә: иң яхшы беренче портлар. `--whole-app` кушымтаның формасын (CLI, сервер яки китапханә) һәм керү нокталарын, һәр бәйлелекне (импортланган яки игълан ителгән) аның crate'ы белән, өлешләрне (бер-берсен импортлаучы берәмлекләр бергә күчә) һәм тәкъдим ителгән җавап белән номерланган карарларны өсти. [Бөтен кушымтаны күчерү](/docs/whole-apps/overview) битен карагыз.

- Пакетлар (`package.json`) һәм чыганак файллар; `node_modules`, build чыгышы, fixture'лар,
  playground'лар, корал конфигларын төшереп калдыра. Vue/Svelte/Astro `<script>` блоклары импортлар өчен укыла.
- **Берәмлекләр**: чыганак файллар папкасы яки пакетның чыганак тамырындагы файл.
- **Дулкыннар**: берәмлекнең импортлары алданрак дулкыннарда килә; импорт цикллары бергә күчерелә.
- **Bridge**: берәмлеккә яки ул импортлаган нәрсәгә Node кирәк булса, napi-rs; күчмә код өчен wasm-bindgen;
  UI һәм редактор коды өчен JS'та калдыру.
- **Әзерлек** (никадәр куркынычсыз) һәм **өстенлек** (куркынычсыз һәм лаеклы: цикллар һәм юллар белән эш, тестлар, зурлык).

| Куркыныч | Җитдилек | Мисал |
| --- | --- | --- |
| Юл офсетлары | югары | `slice`, `indexOf`, `matchAll`, `d` флагы: UTF-16 һәм UTF-8 |
| Regex синтаксисы | югары | lookaround, кире сылтамалар, `y`: `regex` crate'ында юк |
| Динамик regex | югары | `new RegExp(userPattern)`: эш вакытында JS синтаксисы |
| Динамик код | югары | `eval`, `new Function`, исәпләнгән `import()` |
| Динамик типлаштыру | урта | `any`, `'key' in value` |
| Тәртипле коллекцияләр | урта | `Map`, `Set`, `Object.keys`: өстәү тәртибе |
| Async, генераторлар | урта | promise һәм генератор чикләре |
| Класс варислыгы, reflection | урта | `extends`, `Proxy`, `Reflect`, `Symbol` |
| Callback формасындагы API'лар | урта | функция типлы параметрлар һәм методлар: сөйләшүчән bridge'лар |
| Исключениеләр, саннар, JSON | түбән | `throw`, бит операцияләре, `JSON.stringify` тәртибе |
## Бәйлелекләр өчен crate'лар

`analyze` код импортлаган һәр китапханә өчен Rust crate'ын `good`, `partial` яки `none` туры килү дәрәҗәсе белән атый. Таблицада булмаган китапханә `unknown` дип күрсәтелә; таблица беркайчан да crate'ны чамалап әйтми. Яңасын өстәү өчен [Катнашу](/docs/project/contributing#add-a-crate-mapping) битен карагыз.
