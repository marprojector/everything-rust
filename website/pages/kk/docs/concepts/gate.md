# Gate

```sh
everything-rust gate <crate>
```

Дайын дегеніміз `gate`-тің өтуі. Ол мыналарды тексереді:

- `cargo fmt`, `-D warnings` бар clippy және cargo тесттері;
- `unsafe` тек `// SAFETY:` түсініктемелерімен, және ешбір `unimplemented!` жоқ;
- түпнұсқа әдейі құлайтын әр орын үшін (`throw`, `raise`, `error` нәтижесі) жазылған сәтсіз кейс. Gate оны атаса, `record --inputs` арқылы біреуін қосыңыз;
- түпнұсқасы қате қайтаратын функцияда `unwrap`, `expect` немесе `panic!` жоқ. `Err` қайтарыңыз; түпнұсқа да мүмкін емес деп санайтын күй үшін `// INFALLIBLE: <why>` түсініктемесі;
- порт түпнұсқа жолдарынан ең көбі 3x (импорттар мен сигнатуралар үшін тағы 50 жол);
- модуль құрастырылады, және әр экспорт бар;
- әр жазылған кейс сәйкес келеді, [known diffs](/docs/concepts/diff#known-diffs) қоса алғанда, және жазба [ескірмеген](/docs/concepts/diff#stale-recordings);
- TS/JS үшін [қамту](/docs/concepts/coverage) жолы: кейстер түпнұсқаның қаншасын іске қосқаны.

Әр құлаған тексерудің `fix` өрісі бар: алдымен соны іске қосыңыз.

## Содан кейін хабарлап, күтіңіз

Gate өткенде workflow skill агентке мыналарды хабарлауды тапсырады: не өзгерді (файлдар, функциялар, bridge, batch-тар), gate шығысы, diff сандары мен bench сандары, қалған мінез-құлық айырмашылықтары немесе тәуекелдер, және жоспарда не қалды; содан кейін келесі бірлікке дейін рұқсатты күтеді.
