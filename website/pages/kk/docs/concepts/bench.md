# Bench

```sh
everything-rust bench <crate>
```

`bench` жазылған кейстерді түпнұсқада және құрастырылған Rust модулінде, bridge-ті қоса алғанда, уақытпен өлшейді және жолдар мен кеңесі бар вердиктті қайтарады: шығару, баяуырақ функцияларды бастапқы тілде қалдыру немесе үлкенірек бірлікті порттау. 1-ден төмен жылдамдық өсімі порттың шақырушылары шақыратындай түрде баяуырақ екенін білдіреді. `--min-ms` әр функция мен әр жақ үшін ең аз өлшенетін уақытты белгілейді (әдепкі 200).

Вердиктті ұстаныңыз. Шақырушыларды баяулататын портты бұл туралы айтпай шығармаңыз.

## Неге порт баяуырақ болуы мүмкін

Әр элемент үшін бір рет шақырылатын порт bridge үшін әр элементке бір рет төлейді. Мұны не шешеді:

- **Интерпретацияланатын түпнұсқалар (Python, Ruby)**: Rust-қа шақыру шамамен 100-300 ns тұрады, ал Rust коды интерпретатордан әлдеқайда жылдам, сондықтан кішкентай функциялар да ұтады.
- **Компиляцияланатын түпнұсқалар (Go, JIT-тен кейінгі Java)**: түпнұсқа шеткі функция 4-90 ns алады; бір cgo шақыруының өзі шамамен 80 ns тұрады, жолдары бар JNI шақыруы одан көп. Бұл тілдер бір шақыру көп жұмыс істегенде ғана ұтады: функцияны оның шақырушыларымен бірге порттаңыз.
- **C**: шекарадан өту жоқ; Rust коды C кодымен тікелей салыстырылады.

Нақты кодта бір шақыруға өлшенген ([алты тіл](/docs/real-world/six-languages)):

| Тіл | Rust түпнұсқамен салыстырғанда (`bench`, геометриялық орта) | Вердикт |
| --- | --- | --- |
| Ruby | **4.4x жылдамырақ** (функция бойынша 3.6-7x) | шығару |
| Python | **1.35x жылдамырақ** (шақырулардың көбінде 1.5-1.9x) | шығару |
| C | 0.87x: ctype 1.1-1.4x жылдамырақ, glibc-тің баптап оңтайландырылған `strtod`, `strspn`, `strcmp` функциялары 0.5-0.7x | оңтайландыру немесе баяуларын қалдыру |
| Java | 0.18x | үлкенірек бірліктерді порттау |
| Go | 0.04x | үлкенірек бірліктерді порттау |

x18n ядросының API-ді өзгертпей көшіруге болатын барлық 29 функциясы портталды: әр gate өтеді және 7,925 жазылған кейс дәл сәйкес келеді, ал `bench` порттардың JS-тен шақырылғанда TS-тен баяуырақ екенін көрсетті, өйткені bridge жұмыстың өзінен қымбатқа түседі ([есеп](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-core/README.md)). vercel/ms өзінің жазылған кейстерінде бір шақыруға 0.56x жұмыс істеді ([тәжірибе](/docs/real-world/vercel-ms)).

## Не ұтады: циклды көшіру

`profile` ыстық функцияның айналасындағы циклды табады, ал `--batch` бүкіл циклды барлық ядроларда Rust-қа көшіреді. [Batch-тар және hot path-тар](/docs/concepts/batches) бетін қараңыз.

::: tip Тыныш машинада өлшеңіз
`bench` командасын тыныш машинада іске қосыңыз, оны екі рет іске қосыңыз және жарияланған әр санның қасында жабдық пен ядролар санын атаңыз.
:::
