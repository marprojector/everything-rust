# Жазып алу

```sh
everything-rust record <crate>
everything-rust record <crate> --from-tests -- npx jest      # немесе: -- pytest
everything-rust record <crate> --inputs extra.jsonl
```

`record` түпнұсқа функцияларды іске қосып, әрқайсысының не қайтаратынын немесе не лақтыратынын crate-тің қасындағы `cases.jsonl` файлына сақтайды: порт сәйкес келуге тиіс мінез-құлық. Кейінгі сәйкессіздік мінез-құлық айырмашылығы: жазбаны емес, портты түзетіңіз.

## Кейстер қайдан алынады

- **Генерацияланған шеткі кейстер**: ASCII емес таңбалар, эмодзи, `-0`, `NaN`, float күтілетін жердегі int-тер және басқалар (`--count` әр функцияға қаншасы керектігін белгілейді).
- Әр параметрдегі **семантикалық тұзақтар**: жол ұзындығы мен регистрі, таңбалы бөлу, толып кету шекаралары, float-тарды басып шығару, map және сұрыптау реті.
- Регекс қолданатын файлдағы әр функцияға **регекс тұзақтары**: түрік тіліндегі нүктесіз `ı`, Кельвин белгісі, ұзын s, араб-үнді цифрлары, жол бөлгіштер, соңғы сигма, zero-width joiner-лер.
- **Түпнұсқаның өз тесттері**: `--from-tests -- <test command>` тест жиынтығы бірліктің экспортталған функцияларына жасайтын әр шақыруды жазып алады (TS/JS кез келген runner-мен, Python pytest немесе unittest-пен). Кейін бастапқы код қалпына келтіріледі. vercel/ms-те ол 167 Jest тестінен 340 шақыруды жазып алды.
- **Сіздің кірістеріңіз**: әр жолда бір `{"fn": name, "args": [...]}` бар `--inputs cases.jsonl`. Нақты кірістерді қосыңыз (production үлгілері, қате туралы хабарламалар); prod-ты бұзатын пайдаланушы кірісі генератордың ойына сирек келеді.

Python шақырушылары `1` мәнін `1.0` сияқты жиі береді, сондықтан жазып алу әр төртінші Python кейсінде бүтін сандарды int ретінде береді.

## cases.jsonl ішіндегі белгілер

JSON `undefined`, NaN, Infinity, -0 немесе жалғыз суррогаттарды бере алмайды. Құрылымды мәндер генерацияланған `index.cjs` аударатын белгілерді тасымалдайды, көмекшілері crate-тің `js.rs` файлында:

| Белгі | Мағынасы |
| --- | --- |
| `{"$undefined": true}` | JavaScript `undefined` |
| `{"$num": "NaN"}` | JSON сақтай алмайтын сан (`NaN`, `Infinity`, `-0`) |
| `{"$utf16": [...]}` | жалғыз суррогаттар үшін UTF-16 код бірліктері ретінде берілген жол |

Функция келісімшартынан тыс C кірістері түпнұсқаны құлатуы мүмкін. C драйвері әр кейсті fork жасалған еншілес процесте іске қосып, `crash: SIGSEGV` жазып алады; `diff` ол жерде порттың кез келген мінез-құлқын қабылдайды, өйткені C-дың мінез-құлқы анықталмаған.

## Екі іске қосу және не ерекшеленеді

`record` түпнұсқаны екі рет іске қосып, іске қосулар арасында нені ерекшеленгенін сұрыптайды: өзгерген мәндер (уақыттар, id-лер) wildcard-қа айналады; басқа ретпен келген сол жолдар (hash map-тар, параллельдік) кез келген ретпен салыстырылады; жолдардың басқа саны `...` болады, ол кез келген нәрсеге сәйкес келеді. `record` әр түрін тізімдейді. Әрқайсысын қараңыз, өйткені hash-рет немесе параллельдік айырмашылығы дәл портта шынымен өзгеруі мүмкін нәрсе.

## Жазба өз түпнұсқасын есте сақтайды

`record` бірлік файлдарының саусақ ізін сақтайды (`recorded-from.json`). Кейін түпнұсқа өзгерсе, `diff` ескертеді, ал `gate` түпнұсқаның бұрын не істейтініне қарсы өтудің орнына, қайта жазып алмайынша құлайды. [Diff](/docs/concepts/diff#stale-recordings) бетін қараңыз.

## TypeScript ерекшеліктері

`record` TS бастапқы файлдарын сол күйінде іске қосады: Node resolve hook-ы bundler стиліндегі импорттарды қадағалайды (`./errors` бастап `./errors.ts` дейін), репозиторийде ештеңе орнатылмаған болса `--resolve-from` npm пакеттерін береді, ал түрлендіруді қажет ететін TS (enum-дар, parameter properties) `--experimental-transform-types` арқылы қайта іске қосылады. Node-та тікелей іске қосыла алмайтын TS-ті құрастырылған шығыстан `--module dist/x.mjs` арқылы немесе `--node-arg=--import=tsx` арқылы жазып алуға болады.

## Сандық код

Float-тары биттік деңгейде сирек сәйкес келетін код үшін `--float-tolerance` арқылы жазып алыңыз. [Float рұқсат ауытқуы](/docs/concepts/float-tolerance) бетін қараңыз.
