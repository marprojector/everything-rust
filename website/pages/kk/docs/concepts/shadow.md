# Shadow

```sh
everything-rust shadow <crate>
```

`shadow` түпнұсқаның API-і бар алмастырғышты генерациялайды: TS немесе Python модулі, Go пакеті, Ruby файлы, Java кластары немесе C файлы. Оны қолданба түпнұсқаны жүктеген жерде жүктеңіз. Ол екеуін де іске қосады, түпнұсқаның нәтижесін қайтарады және production-да сенімділік жинап жатқаныңызда Rust сәйкессіздіктерін хабарлайды.

| `EVERYTHING_RUST_MODE` | Мінез-құлқы |
| --- | --- |
| `shadow` (әдепкі) | екеуін де іске қосады, түпнұсқаның нәтижесін қайтарады, сәйкессіздіктерді хабарлайды |
| `new` | Rust-қа ауысады |
| `old` | Rust-ты өшіреді |

Ашық API өзгермейді. Шақырушылар сол функцияларды немесе олардың орнына shadow модулін импорттайды.
