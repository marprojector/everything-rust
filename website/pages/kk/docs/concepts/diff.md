# Diff және known diffs

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # N/N болуы керек
everything-rust diff <crate> --json
```

`diff` `cases.jsonl` файлын құрастырылған Rust модуліне қарсы, түпнұсқаның шақырушылары шақыратындай етіп қайта ойнатады және сәйкессіздіктерді тізімдейді. Сәйкессіздік мінез-құлық айырмашылығы: жазбаны емес, портты түзетіңіз.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## Known diffs

Кейде порт әдейі ерекшеленуі керек: пайдаланушы оның түпнұсқадағы қатені түзетуін қалайды. Алдымен сұраңыз, содан кейін әр кейс үшін `<crate>/known-diffs.jsonl` файлына бір жол қосыңыз:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

`fn`, `args` және `actual` мәндерін `diff --json` ішінен көшіріңіз. Сонда ол кейс тек дәл сол нәтижемен өтеді, ал ол енді ерекшеленбей қалғанда `gate` құлайды, сондықтан сол кезде жолды алып тастаңыз.

## Ескірген жазбалар

`record` түпнұсқа бірлік файлдарының саусақ ізін `recorded-from.json` ішіне сақтайды. Кейін түпнұсқа өзгерсе, `diff` ескертеді, ал `gate` түпнұсқаның бұрын не істейтініне қарсы өтудің орнына, қайта жазып алмайынша құлайды. Егер `gate` жазба ескірген десе, порттауды жалғастырмас бұрын қайта жазып алыңыз.

## Порт тоқтап қалғанда

`diff` build-тер бойынша прогресті қадағалайды. Ол порт тоқтап қалды десе (оның `trend.stalled` өрісі: `port.rs` файлындағы қатарынан үш өзгеріс бірде-бір сәйкес кейс қоспады), өңдеуді тоқтатыңыз. Қалған сәйкессіздіктерге тек пайдаланушы білетін ереже керек болуы мүмкін, немесе ол функциялар әзірге түпнұсқада қалуы мүмкін.

## Float рұқсат ауытқуы

Егер crate `--float-tolerance` арқылы жазып алынған болса, `diff` соны қолданады; `diff` командасындағы `--float-tolerance` оны бір іске қосу үшін ауыстырады. [Float рұқсат ауытқуы](/docs/concepts/float-tolerance) бетін қараңыз.
