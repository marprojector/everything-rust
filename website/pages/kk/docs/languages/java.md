# Java

| | |
| --- | --- |
| Бірлік | `public static` әдістерінен тұратын пакет |
| Bridge | типтелген JNI және генерацияланған бинарлық wire, түпнұсқа әдістері бар wrapper кластарында |
| Жазып алатын және қайта ойнататын | генерацияланған reflection драйвері |
| Қажет | JDK 17+ (`javac` және `java`) |
| Күйі | Facade артындағы JDK 21-де тексерілген: 4,492/4,492 (226-сы exception лақтырады), gate өтеді |

Batch-тар `new FnBatch(items)` арқылы жасалады; жұмыс біткенде оларды жабыңыз. `profile` JFR қолданады.

## Порт нені дұрыс істеуі керек

- `Integer.parseInt` `Character.digit` арқылы кез келген Unicode ондық цифрын (`١٢`, `２`) қабылдайды.
- `Double.toString` (JDK 19+) ең қысқа ондық санды басып шығарады, бірақ ешқашан екі цифрдан аз емес: `4.9E-324`, ал Rust-тың ең қысқа түрі `5e-324`.
- `\s` тек ASCII үшін; Rust-тың `split_whitespace` функциясы U+00A0 бойынша да бөледі.
- Float-тар толық айналымнан өзгеріссіз өтуі керек: `serde_json`-ның әдепкі float парсері әрқашан дұрыс дөңгелектемейді, сондықтан everything-rust және ол генерациялайтын әр crate оның `float_roundtrip` мүмкіндігін қолданады.

## Жылдамдық

JIT-тен кейін шеткі функциялар бірнеше наносекунд алады, ал жолдары бар JNI шақыруы одан қымбатқа түседі. JDK facade-та `bench` порттың бір шақыруға 0.18x екенін өлшеді: үлкенірек бірліктерді порттаңыз. 4 ядродағы batch ретінде 50,000 жол бойынша `slugify` (Java-да 43 ms) **3x жылдамырақ** жұмыс істеді (бір шақырулық порт: 0.68x).
