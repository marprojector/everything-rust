`profile` `go test` арқылы жұмыс істейді: `everything-rust profile <repo> -- go test -run X -bench . ./pkg`. Batch-тар `NewFnBatch(items)` арқылы жасалады; жұмыс біткенде оларды жабыңыз.

## Порт нені дұрыс істеуі керек

- `path.Clean`: Go-ның `lazybuf` құрылымы кері жылжығаннан кейін соңғы сақталған байтты емес, жазу индексіндегі байтты оқиды (9 кейс, Go-ның өз тест кестесінен).
- `strings.ToLower` әр rune-ды жеке-жеке кіші әріпке айналдырады: `ΣΊΣΥΦΟΣ` `σίσυφοσ` болады, ал Rust-тың `to_lowercase` функциясы соңғы сигма ережесін қолданады. Go сондай-ақ `İ` әрпін `i`-ге айналдырады, ал Rust `i̇` береді.
- Go жолдарды байт бойынша кеседі; rune ортасынан кесу JSON-ға әр байтқа бір U+FFFD болып жетеді.

## Жылдамдық

Go шеткі функцияларды бірнеше наносекундта орындайды, ал бір cgo шақыруының өзі шамамен 80 ns тұрады. `path` пакетінде `bench` порттың бір шақыруға 0.04x екенін өлшеді: үлкенірек бірліктерді порттаңыз. Batch ретінде жұмыс Rust-қа барлық ядроларға көшеді: 50,000 жол бойынша `Slugify` Go-да 49 ms алды, ал batch **4x жылдамырақ** жұмыс істеді (бір шақырулық порт: 0.93x). Batch crate-тері mimalloc арқылы жады бөледі: жүйелік аллокатормен Go batch-і бір ағыннан да баяу болды.
