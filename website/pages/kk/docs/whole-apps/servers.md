# Серверлер

Сол командалар HTTP серверлерін дәлелдейді. `--http` команданың сервер іске қосатынын айтады; ол
портын `PORT` айнымалысынан немесе командадағы `{port}` ішінен алады (әрқашан бір портты тыңдайтын сервер үшін `--port`):

```sh
everything-rust app record . --http -- node server.js
everything-rust app replay .
everything-rust app front-door .                                    # axum: әр маршрут прокси арқылы
everything-rust app wire . api --route 'GET /users/{id}' --route '*'
everything-rust app lift .
```

- Сұраныстар қолданба құжаттамасындағы `curl` жолдарынан (`curl -X POST -d ... http://localhost:8080/x`),
  `--inputs` (`{"name", "method", "path", "headers", "body"}`) және тұзақтардан алынады: жол сегменттері мен query
  мәндері CLI аргументтеріндегідей тұзақтарға ауыстырылады, денелер мәтін және JSON тұзақтарына, сондай-ақ
  белгісіз маршрут. Әр іске қосу серверді жаңадан бастап, сұраныстарды атау ретімен жібереді, сондықтан
  сұраныстар арасындағы күй сақталады.
- Күйді файлдарда сақтайтын сервер әр іске қосылғанда жаңа көшірме алады: `--fresh db.json` (файл
  немесе бума, қайталауға болады) `http/files/` ішіне сурет ретінде сақталып, түпнұсқа, front door немесе build
  іске қосылған сайын жаңа жұмыс бумасына көшіріледі; `--arg db.json` әр іске қосу өз командасынан кейін алатын
  аргумент, сондықтан Rust бинарлық файлы түпнұсқа сияқты іске қосылады.
  `--pace 50` әр жауаптан кейін 50 ms күтеді, сервер жауап бергеннен кейін істейтін жұмыс үшін (жаңа ғана жазғанын қайта жүктейтін
  файл бақылаушысы).
- Кейстер `rust/app-cases/http/<case>.toml` (сұраныс, статус және маңызды header-лер)
  және `<case>.body` (жауап денесі, екі іске қосу ерекшеленген жерлерде `[..]`). Date, server және
  әр жауапқа тән басқа header-лер алынып тасталады; өзіңізге маңызды емес кез келген header жолын жойыңыз.
- Front door түпнұсқаны өз портында іске қосатын және ешбір бірлік жауап бермейтін әр маршрутты
  прокси жасайтын axum сервері. `wire --route` axum маршруттарын қабылдайды: `METHOD /path/{param}`, кез келген әдіс үшін `/path`,
  қалғанының бәрі үшін `*`; glue маршрутты, оның параметрлерін және
  сұранысты алады. `lift` проксиді алып тастайды; содан кейін HTTP кейстері CI-да `app replay` арқылы іске қосылады.
## Нақты мысал

[json-server](/docs/real-world/json-server) үшін `--fresh`, `--arg` және `--pace` керек болды: ол әр жазу сайын дерекқорын қайта жазады, ал оның файл бақылаушысы тез арада келетін жазуды кері қайтаруы мүмкін.
