# everything-rust деген не

<p class="lead">Бүкіл қолданбаңызды Rust тілінде бөлік-бөлігімен қайта жазыңыз. everything-rust сіздің Node.js (TypeScript/JavaScript), Python, C, Go, Ruby немесе Java қолданбаңыздың бүгін не істейтінін жазып алады, содан кейін Rust нұсқасының әр бөлігін келесіге өтпес бұрын сол жазбамен салыстырып тексереді, қолданба толығымен таза Rust болғанша.</p>

Ол CLI-ларда, HTTP серверлерде және кітапханаларда жұмыс істейді. Rust кодын сіздің кодинг-агентіңіз (Claude Code, Codex, Cursor, Gemini CLI) немесе өзіңіз жазасыз. PHP және C# [preview](/docs/languages/php) күйінде.

## Ол не істейді және не істемейді

everything-rust кодты аудармайды. Ол агент сенімді түрде болжай алмайтын нәрселерді береді:

- **уақыт қайда кетеді**: `profile` нақты жүктемені іске қосып, ыстық функцияларды рейтингке қояды;
- **алдымен нені және қандай ретпен порттау керек**: `analyze` бірліктерді, толқындарды, тәуекелдерді және crate-терді жоспарлайды;
- **bridge**, қалған код Rust-ты API-ін өзгертпей шақыруы үшін (`bridge`);
- **порт сәйкес келуге тиіс нақты мінез-құлық**: `record` түпнұсқаны шеткі кейстерде іске қосып, оның не қайтаратынын немесе не лақтыратынын сақтайды;
- **оны шығарудың қауіпсіз жолы**: `shadow` екеуін қатар іске қосады;
- **порттың қашан дайын болғанын айтатын gate**: `gate`.

Түпнұсқа ақиқаттың көзі болып қала береді. `diff` әр жазылған кейсті Rust-қа қарсы қайта ойнатады, және барлығы сәйкес келіп, `gate` өтпейінше ештеңе шығарылмайды.

## Төрт қадам

| Қадам | Не болады |
| --- | --- |
| **Жазып алу** | `record` түпнұсқаны генерацияланған шеткі кейстерде, семантикалық тұзақтарда және өз кірістеріңізде іске қосып, оның не қайтаратынын немесе не лақтыратынын сақтайды. |
| **Порттау** | `bridge` Rust crate-ін және wrapper-ді генерациялайды, сондықтан шақырушылар түпнұсқа API-ді сақтайды. Rust кодын сіз немесе агентіңіз жазады. |
| **Тексеру** | `diff` әр жазылған кейсті Rust-қа қарсы қайта ойнатады, және барлығы сәйкес келіп, `gate` өтпейінше ештеңе шығарылмайды. |
| **Lift** | Қайта ойнату fallback-сіз өтіп, әр бірлік gate-тен өткенде, `app lift` оны таза Rust қолданбасына айналдырады. Түпнұсқаға ешқашан қол тигізілмейді. |

## Rust әрқашан жылдамырақ па?

Жоқ, және everything-rust мұны ашық айтады. Әр элемент үшін бір рет шақырылатын кішкентай функция Rust-та жиі баяуырақ болады, өйткені әр шақыру bridge арқылы өтеді; V8, JVM және Go мұндай функцияларды наносекундтарда орындайды. `profile` оның айналасындағы циклды табады, `--batch` бүкіл циклды көшіреді, ал `bench` шығармас бұрын вердикт береді. Өлшенген сандарды, баяулары да бар, [Batch-тар және hot path-тар](/docs/concepts/batches) бетінен қараңыз.

## Ол тек жазба қамтитын нәрсені ғана ұстай алады

Өту Rust жазылған әр кейске сәйкес келеді дегенді білдіреді, одан артық емес. Жасыл gate-ке сенбес бұрын [Ол нені ұстай алмайды](/docs/concepts/limits) бетін оқыңыз.

::: warning Көшірмеде іске қосыңыз
`record` және `app record` түпнұсқа кодыңызды іске қосады: әр функцияны (немесе бүкіл қолданбаны) көптеген генерацияланған кірістермен шақырады, ал `app record` әр кейсті екі рет іске қосады. `diff`, `gate` және `app replay` сол кейстерді портта немесе түпнұсқада қайта іске қосады. Файлдарға жазатын, дерекқормен жұмыс істейтін немесе желіге қатынайтын код мұны әр кейс үшін бір рет істейді. Оларды жобаның көшірмесінде, тесттік дерекқормен және ортада production тіркелгі деректері жоқ күйде іске қосыңыз.
:::
