# Диагностика (doctor)

```sh
everything-rust doctor
everything-rust doctor --json
```

`doctor` проверяет среды выполнения языков, настройку агентов и MCP-сервер и выводит команду, которая исправляет каждую проблему. Если не хватает чего-то обязательного, он завершается с кодом 1.

Запускайте его, когда шаг падает из-за того, что среда выполнения, настройка агента или MCP-сервер отсутствуют или устарели. Навык рабочего процесса велит агентам делать то же самое.

## Что нужно каждому языку

`record`, `diff` и `bench` запускают оригинал в его собственной среде выполнения: Node 22.6+ для TS (он выполняет исходники `.ts` напрямую), Python 3.9+ для Python и C (ctypes), Go 1.21+, Ruby 3+, JDK 17+ (`javac` и `java`). `profile` для Node требует Node 24+, где `--cpu-prof` разрешён в `NODE_OPTIONS`. Для C также нужен компилятор C. Мостам wasm также нужны `rustup target add wasm32-unknown-unknown` и подходящий `wasm-bindgen-cli`; `build` называет точную версию.

## Для контрибьюторов

`cargo run -- doctor` показывает, какие среды выполнения у вас есть, их версии и команду, которая устанавливает или обновляет каждую из них. См. [Участие в проекте](/docs/project/contributing).
