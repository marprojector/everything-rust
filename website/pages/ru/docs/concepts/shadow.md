# Теневой режим (shadow)

```sh
everything-rust shadow <crate>
```

`shadow` генерирует замену с API оригинала: модуль TS или Python, пакет Go, файл Ruby, классы Java или файл C. Загрузите его там, где приложение загружало оригинал. Он запускает обе версии, возвращает результат оригинала и сообщает о расхождениях Rust, пока вы набираетесь уверенности в продакшене.

| `EVERYTHING_RUST_MODE` | Поведение |
| --- | --- |
| `shadow` (по умолчанию) | запускает обе версии, возвращает результат оригинала, сообщает о расхождениях |
| `new` | переключается на Rust |
| `old` | выключает Rust |

Публичный API не меняется. Вызывающий код импортирует те же функции или теневой модуль вместо них.
