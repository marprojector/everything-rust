# Diff и известные расхождения

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # должно быть N/N
everything-rust diff <crate> --json
```

`diff` воспроизводит `cases.jsonl` на собранном Rust-модуле, вызывая его так, как его вызывает код, использующий оригинал, и перечисляет расхождения. Расхождение означает различие в поведении: исправляйте порт, а не запись.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## Известные расхождения {#known-diffs}

Иногда порт должен отличаться: пользователь хочет, чтобы он исправил баг оригинала. Сначала спросите, затем добавьте по одной строке на кейс в `<crate>/known-diffs.jsonl`:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

Скопируйте `fn`, `args` и `actual` из `diff --json`. После этого кейс проходит только с точно таким результатом, а `gate` падает, как только различие исчезает, так что тогда удалите эту строку.

## Устаревшие записи {#stale-recordings}

`record` сохраняет отпечаток файлов исходного модуля в `recorded-from.json`. Когда оригинал позже меняется, `diff` предупреждает, а `gate` падает, пока вы не запишете заново, вместо того чтобы проходить против того, что оригинал делал раньше. Если `gate` сообщает, что запись устарела, запишите заново, прежде чем продолжать портирование.

## Когда порт застрял

`diff` отслеживает прогресс между сборками. Когда он сообщает, что порт застрял (его `trend.stalled`: три изменения `port.rs` подряд не добавили ни одного совпавшего кейса), прекратите правки. Оставшимся расхождениям может требоваться правило, которое знает только пользователь, или эти функции пока стоит оставить в оригинале.

## Допуск для float

Если крейт был записан с `--float-tolerance`, `diff` использует этот допуск; `--float-tolerance` у `diff` переопределяет его на один прогон. См. [Допуск для float](/docs/concepts/float-tolerance).
