# Реальные порты

Что произошло, когда everything-rust встретился с реальным кодом, и что из-за этого изменилось в инструменте. Каждое число ниже получено бенчмарком, который сначала проверяет идентичность результатов, а медленные случаи указаны рядом с быстрыми.

| Порт | Что это | Результат |
| --- | --- | --- |
| [json-server](/docs/real-world/json-server) | целый Node-сервер, портированный от начала до конца с помощью `app record`, `front-door`, `wire` и `lift` | бинарник на чистом Rust, который проходит 514/514 записанных HTTP-кейсов; шесть модулей проходят `gate` |
| [Fuse.js](/docs/real-world/fuse-js) | нечёткий поиск, путь, на который поиск тратит своё время | 3,414/3,414 кейсов совпадают; в 32x быстрее на 50,000 строк (5.3x на одном ядре) |
| [vercel/ms](/docs/real-world/vercel-ms) | крошечный парсер длительностей, от начала до конца | 975/975 кейсов совпадают; 0.56x на вызов, 18x в пакете `parse`, 0.8x в пакете `format` |
| [x18n](/docs/real-world/x18n) | репозиторий для разбора кейса | каждый гейт проходит на `packages/core`, медленнее TS через мост; его поиск 18-22x в пакете |
| [Шесть языков](/docs/real-world/six-languages) | `path` из Go, `shellwords` из Ruby, `colorsys` из Python, поведение JDK и glibc за небольшими фасадами | каждый порт проходит свой гейт, всего 13,010 записанных кейсов |
| [Фикстуры и статические прогоны](/docs/real-world/fixtures) | фикстуры, написанные для нагрузочной проверки инструмента, и библиотеки, которые проанализированы, но не запускались | |

Портировали что-то реальное? Будем рады разбору: см. [Участие в проекте](/docs/project/contributing#share-a-real-port).
