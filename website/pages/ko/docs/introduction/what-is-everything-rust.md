# everything-rust이란

<p class="lead">앱 전체를 한 번에 한 조각씩 Rust로 다시 작성하세요. everything-rust은 Node.js(TypeScript/JavaScript), Python, C, Go, Ruby 또는 Java 앱이 지금 하는 일을 기록한 다음, 다음 단계로 넘어가기 전에 Rust 재작성의 모든 조각을 그 기록과 대조해 검증하며, 앱이 순수 Rust가 될 때까지 이어 갑니다.</p>

CLI, HTTP 서버, 라이브러리에 사용할 수 있습니다. Rust 코드는 코딩 에이전트(Claude Code, Codex, Cursor, Gemini CLI)나 개발자가 작성합니다. PHP와 C#은 [프리뷰](/docs/languages/php) 단계입니다.

## 하는 일과 하지 않는 일

everything-rust은 코드를 번역하지 않습니다. 에이전트가 확실하게 추측할 수 없는 것을 제공합니다:

- **시간이 어디서 쓰이는지**: `profile`이 실제 워크로드를 실행하고 핫 함수의 순위를 매깁니다.
- **무엇을 먼저, 어떤 순서로 포팅할지**: `analyze`가 유닛, 웨이브, 위험 요소, crate를 계획합니다.
- **브리지**: 나머지 코드가 API를 바꾸지 않고 Rust를 호출하게 합니다(`bridge`).
- **포트가 맞춰야 할 정확한 동작**: `record`가 엣지 케이스로 원본을 실행하고 반환값이나 발생한 예외를 저장합니다.
- **안전하게 배포하는 방법**: `shadow`가 둘을 나란히 실행합니다.
- **포팅이 언제 끝났는지 알려 주는 게이트**: `gate`.

원본이 계속 기준(source of truth)으로 남습니다. `diff`가 기록된 모든 케이스를 Rust에 대해 재생하며, 모두 일치하고 `gate`를 통과하기 전까지는 아무것도 배포되지 않습니다.

## 네 단계

| 단계 | 하는 일 |
| --- | --- |
| **기록** | `record`는 생성된 엣지 케이스, 의미상의 함정, 사용자가 준 입력으로 원본을 실행하고 반환값이나 발생한 예외를 저장합니다. |
| **포팅** | `bridge`가 Rust crate와 래퍼를 생성하므로 호출하는 쪽은 기존 API를 그대로 사용합니다. Rust 코드는 개발자나 에이전트가 작성합니다. |
| **검증** | `diff`가 기록된 모든 케이스를 Rust에 대해 재생하며, 모두 일치하고 `gate`를 통과하기 전까지는 아무것도 배포되지 않습니다. |
| **리프트** | 폴백 없이 재생이 통과하고 모든 유닛이 게이트를 통과하면, `app lift`가 앱을 순수 Rust 앱으로 만듭니다. 원본은 전혀 건드리지 않습니다. |

## Rust가 항상 더 빠를까요?

아닙니다. everything-rust도 그렇게 알려 줍니다. 항목마다 한 번씩 호출되는 작은 함수는 Rust에서 더 느린 경우가 많습니다. 호출할 때마다 브리지를 건너야 하기 때문입니다. V8, JVM, Go는 그런 함수를 나노초 단위로 실행합니다. `profile`이 그 함수를 감싸는 루프를 찾고, `--batch`가 루프 전체를 옮기며, `bench`가 배포 전에 판정을 내립니다. 느린 결과를 포함한 측정 수치는 [배치와 핫 패스](/docs/concepts/batches)를 참고하세요.

## 기록이 다루는 범위만 잡아낼 수 있습니다

통과했다는 것은 Rust가 기록된 모든 케이스와 일치한다는 뜻일 뿐, 그 이상은 아닙니다. 게이트 통과를 신뢰하기 전에 [잡아내지 못하는 것](/docs/concepts/limits)을 읽어 보세요.

::: warning 복사본에서 실행하세요
`record`와 `app record`는 원본 코드를 실행하며, 생성된 많은 입력으로 각 함수(또는 앱 전체)를 호출합니다. `app record`는 모든 케이스를 두 번 실행합니다. `diff`, `gate`, `app replay`는 같은 케이스를 포트나 원본에서 다시 실행합니다. 파일을 쓰거나, 데이터베이스와 통신하거나, 네트워크를 호출하는 코드는 케이스마다 그 일을 합니다. 프로젝트 복사본에서, 테스트 데이터베이스를 사용하고, 환경에 프로덕션 자격 증명이 없는 상태로 실행하세요.
:::
