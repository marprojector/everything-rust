# ゲート

```sh
everything-rust gate <crate>
```

完了とは `gate` に合格することです。チェック内容:

- `cargo fmt`、`-D warnings` 付きの clippy、cargo のテスト。
- `unsafe` は `// SAFETY:` コメント付きの場合のみ許可され、`unimplemented!` は一切ないこと。
- 元の実装が意図的に失敗するすべての箇所（`throw`、`raise`、`error` の結果）について、失敗する記録ケースがあること。gate が箇所を示したら `record --inputs` で追加します。
- 元の実装がエラーを返す関数に `unwrap`、`expect`、`panic!` がないこと。`Err` を返してください。元の実装も不可能とみなしている状態には `// INFALLIBLE: <why>` コメントを付けます。
- 移植版の行数が元の実装の 3 倍以内であること（インポートとシグネチャのために 50 行の余裕あり）。
- モジュールがビルドでき、すべてのエクスポートが存在すること。
- [既知の差分](/docs/concepts/diff#known-diffs)を含め、記録されたすべてのケースが一致し、記録が[古くなって](/docs/concepts/diff#stale-recordings)いないこと。
- TS/JS の場合は[カバレッジ](/docs/concepts/coverage)の行: ケースが元の実装をどれだけ実行したか。

失敗したチェックにはそれぞれ `fix` が付いています: まずそれを実行してください。

## 報告して、待つ

ゲートに合格すると、ワークフロースキルに従ってエージェントは次の内容を報告します: 変更したもの（ファイル、関数、ブリッジ、バッチ）、gate の出力、diff の件数、bench の数値、残っている挙動の違いやリスク、計画の残り。そして次のユニットに進む前に承認を待ちます。
