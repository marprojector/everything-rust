# everything-rust とは

<p class="lead">アプリ全体を、一つずつ Rust に書き直しましょう。everything-rust は、既存の Node.js（TypeScript/JavaScript）、Python、C、Go、Ruby、または Java アプリが現在どう振る舞うかを記録し、Rust で書き直した各パーツを次へ進む前にその記録と照合して、最終的にアプリ全体が純粋な Rust になるまで検証を続けます。</p>

CLI、HTTP サーバー、ライブラリに対応しています。Rust を書くのはコーディングエージェント（Claude Code、Codex、Cursor、Gemini CLI）またはあなたです。PHP と C# は[プレビュー版](/docs/languages/php)です。

## できること、できないこと

everything-rust はコードを翻訳しません。エージェントが推測では確実に当てられないものを提供します:

- **どこに時間がかかっているか**: `profile` が実際のワークロードを実行し、ホットな関数を順位付けします。
- **何を最初に、どの順番で移植するか**: `analyze` がユニット、ウェーブ、リスク、クレートを計画します。
- 残りのコードが API を変えずに Rust を呼び出すための**ブリッジ**（`bridge`）。
- **移植版が一致させるべき正確な挙動**: `record` がエッジケースで元の実装を実行し、返したもの、または投げたものを保存します。
- **安全に出荷する方法**: `shadow` が両方を並べて実行します。
- **移植の完了を判定するゲート**: `gate`。

元の実装が常に正解の基準です。`diff` は記録されたすべてのケースを Rust に対してリプレイし、すべて一致して `gate` に合格するまで何も出荷されません。

## 4 つのステップ

| ステップ | 何が起こるか |
| --- | --- |
| **記録** | `record` は生成したエッジケース、セマンティックトラップ、あなた自身の入力で元の実装を実行し、返り値や例外を保存します。 |
| **移植** | `bridge` は Rust クレートとラッパーを生成するので、呼び出し元は元の API をそのまま使えます。Rust を書くのはあなたかエージェントです。 |
| **検証** | `diff` は記録したすべてのケースを Rust に対してリプレイします。すべて一致して `gate` に合格するまで何も出荷されません。 |
| **リフト** | フォールバックなしでリプレイに合格し、すべてのユニットが gate に合格すると、`app lift` がアプリを純粋な Rust アプリにします。元の実装には一切手を加えません。 |

## Rust は常に速いのか？

いいえ。そして everything-rust はそれをはっきり伝えます。要素ごとに 1 回呼ばれる小さな関数は、呼び出しのたびにブリッジを越えるため、Rust の方が遅くなることがよくあります。V8、JVM、Go はそうした関数をナノ秒で実行します。`profile` はそれを囲むループを見つけ、`--batch` はループ全体を移し、`bench` は出荷前に判定を出します。遅い結果も含めた計測値は[バッチとホットパス](/docs/concepts/batches)を参照してください。

## 検出できるのは記録がカバーする範囲だけ

合格とは、Rust が記録されたすべてのケースに一致するということであり、それ以上ではありません。緑のゲートを信頼する前に[検出できないもの](/docs/concepts/limits)を読んでください。

::: warning コピー上で実行する
`record` と `app record` は元のコードを実行し、各関数（またはアプリ全体）を多数の生成入力で呼び出します。`app record` はすべてのケースを 2 回実行します。`diff`、`gate`、`app replay` は同じケースを移植版または元の実装で再度実行します。ファイルを書き込む、データベースにアクセスする、ネットワークを呼び出すコードは、ケースごとにその処理を行います。プロジェクトのコピー上で、テスト用データベースを使い、本番環境の認証情報が環境に含まれない状態で実行してください。
:::
