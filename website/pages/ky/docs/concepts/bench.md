# Бенчмарк

```sh
everything-rust bench <crate>
```

`bench` жазылган кейстерди түп нускада жана курулган Rust модулунда, bridge'ди кошо, убакытка өлчөйт жана саптарды жана кеңеши бар чечимди кайтарат: чыгаруу, жайыраак функцияларды баштапкы тилде калтыруу же чоңураак бирдикти порттоо. 1ден кичине ылдамдатуу порт чакыруучулары аны чакырган жол менен жайыраак иштейт дегенди билдирет. `--min-ms` ар бир функция жана тарап үчүн өлчөнүүчү минималдуу убакытты коёт (демейки 200).

Чечимди аткарыңыз. Чакыруучуларды жайлаткан портту муну айтпай туруп чыгарбаңыз.

## Эмне үчүн порт жайыраак болушу мүмкүн

Ар бир элемент үчүн бир жолу чакырылган порт bridge үчүн ар бир элементке бир жолу төлөйт. Муну эмне чечет:

- **Интерпретацияланган түп нускалар (Python, Ruby)**: Rust'ка чакыруу болжол менен 100-300 ns турат жана Rust коду интерпретатордон алда канча ылдам, ошондуктан кичинекей функциялар да утат.
- **Компиляцияланган түп нускалар (Go, JIT'тен кийинки Java)**: түп нуска leaf функция 4-90 ns алат; бир эле cgo чакыруусу болжол менен 80 ns турат, саптар менен JNI чакыруусу андан да көп. Бул тилдер бир чакыруу көп иш аткарганда гана утушат: функцияны аны чакыргандар менен бирге порттоңуз.
- **C**: чектен өтүү жок; Rust коду C коду менен түз салыштырылат.

Чыныгы коддо бир чакырууга өлчөнгөн ([алты тил](/docs/real-world/six-languages)):

| Тил | Rust түп нускага каршы (`bench`, геометриялык орточо) | Чечим |
| --- | --- | --- |
| Ruby | **4.4x ылдамыраак** (функция боюнча 3.6-7x) | чыгаруу |
| Python | **1.35x ылдамыраак** (көпчүлүк чакырууларда 1.5-1.9x) | чыгаруу |
| C | 0.87x: ctype 1.1-1.4x ылдамыраак, glibc'тин тюнингделген `strtod`, `strspn`, `strcmp` 0.5-0.7x | оптималдаштыруу же жайыраактарын калтыруу |
| Java | 0.18x | чоңураак бирдиктерди порттоо |
| Go | 0.04x | чоңураак бирдиктерди порттоо |

x18n ядросунун API'ни өзгөртпөй көчө ала турган бардык 29 функциясы порттолду: ар бир gate өтөт жана 7,925 жазылган кейс так дал келет, ал эми `bench` порттор JS'тен чакырылганда TS'тен жайыраак экенин көрсөттү, анткени bridge иштин өзүнөн кымбатыраак ([отчет](https://github.com/marprojector/everything-rust/blob/main/demo/x18n-core/README.md)). vercel/ms өзүнүн жазылган кейстеринде бир чакырууга 0.56x менен иштеди ([практикалык мисал](/docs/real-world/vercel-ms)).

## Эмне утат: циклди көчүрүү

`profile` ысык функциянын айланасындагы циклди табат, ал эми `--batch` бүт циклди Rust'ка, бардык ядролорго көчүрөт. [Batch'тар жана hot path'тар](/docs/concepts/batches) барагын караңыз.

::: tip Тынч машинада өлчөңүз
`bench`'ти тынч машинада, эки жолу иштетиңиз жана жарыяланган ар бир сандын жанына жабдыкты жана ядролордун санын жазыңыз.
:::
