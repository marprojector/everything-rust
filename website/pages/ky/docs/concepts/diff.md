# Diff жана белгилүү айырмалар

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # must be N/N
everything-rust diff <crate> --json
```

`diff` `cases.jsonl` файлын курулган Rust модулуна каршы, түп нусканын чакыруучулары аны кантип чакырса ошондой чакырып, кайра ойнотот жана дал келбестиктерди тизмектейт. Дал келбестик жүрүм-турумдагы айырма: портту оңдоңуз, жазууну эч качан оңдобоңуз.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## Белгилүү айырмалар

Кээде порт атайылап башкача болушу керек: колдонуучу анын түп нусканын катасын оңдошун каалайт. Адегенде сураңыз, андан кийин ар бир кейс үчүн `<crate>/known-diffs.jsonl` файлына бир сап кошуңуз:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

`fn`, `args` жана `actual` маанилерин `diff --json` чыгышынан көчүрүңүз. Андан кийин ал кейс так ошол натыйжа менен гана өтөт, ал эми айырма жоголгондо `gate` өтпөй калат, ошондо сапты алып салыңыз.

## Эскирген жазуулар

`record` түп нуска бирдиктин файлдарынын манжа изин `recorded-from.json` ичине сактайт. Кийин түп нуска өзгөргөндө, түп нуска мурун эмне кылганына каршы өтүүнүн ордуна, `diff` эскертет жана сиз кайра жазып алмайынча `gate` өтпөйт. Эгер `gate` жазуу эскирген деп айтса, андан ары порттоодон мурун кайра жазып алыңыз.

## Порт токтоп калганда

`diff` build'дер боюнча прогрессти көзөмөлдөйт. Ал порт токтоп калды деп айтканда (анын `trend.stalled` мааниси: `port.rs`'теги катары менен үч өзгөртүү бир да дал келген кейс кошкон жок), оңдоону токтотуңуз. Калган дал келбестиктерге колдонуучу гана билген эреже керек болушу мүмкүн, же ал функциялар азырынча түп нускада калышы мүмкүн.

## Float тактыгы

Эгер crate `--float-tolerance` менен жазылып алынса, `diff` аны колдонот; `diff`'теги `--float-tolerance` аны бир иштетүү үчүн алмаштырат. [Float тактыгы](/docs/concepts/float-tolerance) барагын караңыз.
