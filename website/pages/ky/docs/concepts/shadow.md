# Shadow

```sh
everything-rust shadow <crate>
```

`shadow` түп нусканын API'си бар drop-in алмаштыргычты генерациялайт: TS же Python модулу, Go пакети, Ruby файлы, Java класстары же C файлы. Аны колдонмо түп нусканы жүктөгөн жерде жүктөңүз. Ал экөөн тең иштетет, түп нусканын натыйжасын кайтарат жана production'до ишенимиңиз бекемделип жатканда Rust'тун дал келбестиктери жөнүндө кабарлайт.

| `EVERYTHING_RUST_MODE` | Жүрүм-турум |
| --- | --- |
| `shadow` (демейки) | экөөн тең иштетет, түп нусканын натыйжасын кайтарат, дал келбестиктер жөнүндө кабарлайт |
| `new` | Rust'ка которулат |
| `old` | Rust'ту өчүрөт |

Public API өзгөрбөйт. Чакыруучулар ошол эле функцияларды же алардын ордуна shadow модулун импорттошот.
