# Gate

```sh
everything-rust gate <crate>
```

Даяр дегени `gate` өтөт дегенди билдирет. Ал төмөнкүлөрдү текшерет:

- `cargo fmt`, `-D warnings` менен clippy жана cargo тесттери;
- `unsafe` `// SAFETY:` комментарийлери менен гана, жана эч нерсе `unimplemented!` эмес;
- түп нуска атайылап ката берген ар бир жер үчүн (`throw`, `raise`, `error` натыйжасы) жазылган ийгиликсиз кейс. Gate аны атаганда `record --inputs` менен кошуңуз;
- түп нускасы ката кайтарган функцияда `unwrap`, `expect` же `panic!` жок. `Err` кайтарыңыз; түп нуска да мүмкүн эмес деп эсептеген абал үчүн `// INFALLIBLE: <why>` комментарийин жазыңыз;
- порт түп нусканын саптарынан эң көп 3x (плюс импорттор жана сигнатуралар үчүн 50 сап);
- модуль курулат жана ар бир экспорт бар;
- ар бир жазылган кейс дал келет, [белгилүү айырмалар](/docs/concepts/diff#known-diffs) да кошо, жана жазуу [эскирген](/docs/concepts/diff#stale-recordings) эмес;
- TS/JS үчүн [камтуу](/docs/concepts/coverage) сабы: кейстер түп нусканын канчасын иштеткени.

Ар бир өтпөй калган текшерүүдө `fix` бар: адегенде ошону иштетиңиз.

## Андан кийин кабарлап, күтүңүз

Gate өткөндө workflow skill агентке эмне өзгөргөнүн (файлдар, функциялар, bridge, batch'тар), gate'тин чыгышын, diff эсептерин жана bench сандарын, калган жүрүм-турум айырмаларын же тобокелдиктерди жана планда эмне калганын кабарлап, кийинки бирдиктен мурун уруксат күтүүнү айтат.
