`profile` `go test` аркылуу иштейт: `everything-rust profile <repo> -- go test -run X -bench . ./pkg`. Batch'тар `NewFnBatch(items)`; иш бүткөндө аларды жабыңыз.

## Порт эмнени туура жасашы керек

- `path.Clean`: Go'нун `lazybuf`'у артка жылгандан кийин акыркы сакталган байтты эмес, жазуу индексиндеги байтты окуйт (9 кейс, Go'нун өзүнүн тест таблицасынан).
- `strings.ToLower` ар бир rune'ду өзүнчө кичирейтет: `ΣΊΣΥΦΟΣ` `σίσυφοσ` болуп калат, ал эми Rust'тун `to_lowercase`'и акыркы сигма эрежесин колдонот. Go ошондой эле `İ`'ни `i`'ге айлантат, ал эми Rust `i̇` берет.
- Go саптарды байттар боюнча кесет; rune'ду ортосунан кескен кесим JSON'го ар бир байтка бир U+FFFD катары жетет.

## Ылдамдык

Go leaf функцияларын бир нече наносекундда иштетет, ал эми бир эле cgo чакыруусу болжол менен 80 ns турат. `path`'та `bench` портту бир чакырууга 0.04x деп өлчөдү: чоңураак бирдиктерди порттоңуз. Batch катары иш бардык ядролордо Rust'ка көчөт: 50,000 саптагы `Slugify` Go'до 49 ms алды, ал эми batch **4x ылдамыраак** иштеди (бир чакырууга порт: 0.93x). Batch crate'тери mimalloc менен эс бөлөт: системалык аллокатор менен Go batch'ы бир агымдан жайыраак болгон.
