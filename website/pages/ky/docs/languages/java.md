# Java

| | |
| --- | --- |
| Бирдик | `public static` методдорунан турган пакет |
| Bridge | типтелген JNI жана генерацияланган бинардык wire, түп нуска методдору бар wrapper класстарында |
| Ким жазып алат жана кайра ойнотот | генерацияланган reflection драйвери |
| Керектүү | JDK 17+ (`javac` жана `java`) |
| Абалы | Facade артындагы JDK 21'де текшерилген: 4,492/4,492 (226сы exception ыргытат), gate өтөт |

Batch'тар `new FnBatch(items)`; иш бүткөндө аларды жабыңыз. `profile` JFR колдонот.

## Порт эмнени туура жасашы керек

- `Integer.parseInt` `Character.digit` аркылуу каалаган Unicode ондук цифрасын (`١٢`, `２`) кабыл алат.
- `Double.toString` (JDK 19+) эң кыска ондук санды басып чыгарат, бирок эч качан эки цифрадан аз эмес: `4.9E-324`, ал эми Rust'тун эң кыска формасы `5e-324`.
- `\s` ASCII гана; Rust'тун `split_whitespace`'и U+00A0'дө да бөлөт.
- Float'тар айланып келүүдөн аман өтүшү керек: `serde_json`'дун демейки float парсери дайыма эле туура тегеректебейт, ошондуктан everything-rust жана ал генерациялаган ар бир crate анын `float_roundtrip` мүмкүнчүлүгүн колдонот.

## Ылдамдык

JIT'тен кийин leaf функциялар бир нече наносекунд алат, ал эми саптар менен JNI чакыруусу андан кымбатыраак. JDK facade'ында `bench` портту бир чакырууга 0.18x деп өлчөдү: чоңураак бирдиктерди порттоңуз. 4 ядродо batch катары 50,000 саптагы `slugify` (Java'да 43 ms) **3x ылдамыраак** иштеди (бир чакырууга порт: 0.68x).
