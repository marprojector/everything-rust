# Doctor

```sh
everything-rust doctor
everything-rust doctor --json
```

`doctor` тилдердин runtime'дарын, агенттин жөндөөлөрүн жана MCP серверди текшерет жана ар бир көйгөйдү оңдогон буйрукту чыгарат. Керектүү бир нерсе жок болсо, ал 1 коду менен аяктайт.

Runtime, агенттин жөндөөлөрү же MCP сервер жок же эскирип калгандыктан кайсы бир кадам ишке ашпай калганда аны иштетиңиз. Workflow skill агенттерге да ушундай кылууну айтат.

## Ар бир тилге эмне керек

`record`, `diff` жана `bench` түп нусканы өзүнүн runtime'ында иштетет: TS үчүн Node 22.6+ (ал `.ts` баштапкы файлдарын түз иштетет), Python жана C үчүн Python 3.9+ (ctypes), Go 1.21+, Ruby 3+, JDK 17+ (`javac` жана `java`). Node'догу `profile` үчүн Node 24+ керек, анткени ал `NODE_OPTIONS` ичинде `--cpu-prof` колдонууга уруксат берет. C үчүн C компилятору да керек. wasm bridge'дерине `rustup target add wasm32-unknown-unknown` жана ага туура келген `wasm-bindgen-cli` да керек; так версиясын `build` айтат.

## Салым кошуучулар үчүн

`cargo run -- doctor` сизде кайсы runtime'дар бар экенин, алардын версияларын жана ар бирин орнотуучу же жаңыртуучу буйрукту көрсөтөт. [Салым кошуу](/docs/project/contributing) барагын караңыз.
