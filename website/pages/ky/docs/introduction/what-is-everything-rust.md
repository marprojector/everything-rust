# everything-rust деген эмне

<p class="lead">Бүт колдонмоңузду Rust тилинде бөлүк-бөлүгү менен кайра жазыңыз. everything-rust сиздин Node.js (TypeScript/JavaScript), Python, C, Go, Ruby же Java колдонмоңуз бүгүн эмне кылып жатканын жазып алат, андан кийин Rust нускасынын ар бир бөлүгүн кийинкисине өтүүдөн мурун ошол жазуу менен салыштырып текшерет, колдонмо толугу менен таза Rust болгонго чейин.</p>

Ал CLI'лар, HTTP серверлер жана китепканалар менен иштейт. Rust кодун сиздин коддоо агентиңиз (Claude Code, Codex, Cursor, Gemini CLI) же өзүңүз жазасыз. PHP жана C# [preview](/docs/languages/php) абалында.

## Ал эмне кылат жана эмне кылбайт

everything-rust кодду которбойт. Ал агент ишенимдүү түрдө болжолдой албаган нерселерди берет:

- **убакыт кайда кетет**: `profile` чыныгы жүктөмдү иштетип, ысык функцияларды тизмектейт;
- **адегенде эмнени жана кандай тартипте порттоо керек**: `analyze` бирдиктерди, толкундарды, тобокелдиктерди жана crate'терди пландайт;
- калган код Rust'ту API'син өзгөртпөй чакырышы үчүн **bridge** (`bridge`);
- **порт дал келиши керек болгон так жүрүм-турум**: `record` түп нусканы чектик кейстерде иштетип, ал эмне кайтарарын же кандай ката ыргытарын сактайт;
- **аны чыгаруунун коопсуз жолу**: `shadow` экөөн тең катар иштетет;
- **порт качан даяр болгонун айткан gate**: `gate`.

Түп нуска чындыктын булагы бойдон калат. `diff` ар бир жазылган кейсти Rust'ка каршы кайра ойнотот, алардын баары дал келмейинче жана `gate` өтмөйүнчө эч нерсе чыгарылбайт.

## Төрт кадам

| Кадам | Эмне болот |
| --- | --- |
| **Жазып алуу** | `record` түп нусканы генерацияланган чектик кейстерде, семантикалык тузактарда жана өзүңүздүн киргизүүлөрүңүздө иштетип, ал эмне кайтарарын же кандай ката ыргытарын сактайт. |
| **Порттоо** | `bridge` Rust crate'ин жана wrapper'ди генерациялайт, ошентип чакыруучулар түп нуска API'син сакташат. Rust кодун сиз же агентиңиз жазат. |
| **Текшерүү** | `diff` ар бир жазылган кейсти Rust'ка каршы кайра ойнотот, алардын баары дал келмейинче жана `gate` өтмөйүнчө эч нерсе чыгарылбайт. |
| **Lift** | Replay fallback'сиз өтүп, ар бир бирдик gate'тен өткөндө, `app lift` аны таза Rust колдонмосуна айлантат. Түп нускага эч качан тийбейт. |

## Rust дайыма ылдамыраакпы?

Жок, жана everything-rust муну ачык айтат. Ар бир элемент үчүн бир жолу чакырылган кичинекей функция Rust'та көп учурда жайыраак иштейт, анткени ар бир чакыруу bridge аркылуу өтөт; V8, JVM жана Go мындай функцияларды наносекунддарда иштетет. `profile` анын айланасындагы циклди табат, `--batch` бүт циклди көчүрөт, ал эми `bench` чыгаруудан мурун өз чечимин берет. Өлчөнгөн сандар үчүн, жай натыйжаларды кошо, [Batch'тар жана hot path'тар](/docs/concepts/batches) барагын караңыз.

## Ал жазуу камтыган нерсени гана кармай алат

Өтүү Rust жазылган ар бир кейске дал келет дегенди гана билдирет, андан ашык эмес. Жашыл gate'ке ишенүүдөн мурун [Ал эмнени кармай албайт](/docs/concepts/limits) барагын окуңуз.

::: warning Көчүрмөдө иштетиңиз
`record` жана `app record` түп нуска кодуңузду иштетет: ар бир функцияны (же бүт колдонмону) көптөгөн генерацияланган киргизүүлөр менен чакырат, ал эми `app record` ар бир кейсти эки жолу иштетет. `diff`, `gate` жана `app replay` ошол эле кейстерди портто же түп нускада кайрадан иштетет. Файл жазган, маалымат базасы менен иштеген же тармакка кайрылган код муну ар бир кейс үчүн бир жолу аткарат. Аларды долбоордун көчүрмөсүндө, тесттик маалымат базасы менен жана чөйрөдө production эсептик маалыматтары жок абалда иштетиңиз.
:::
