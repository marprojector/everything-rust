# Серверлер

Ошол эле буйруктар HTTP серверлерди далилдейт. `--http` буйрук серверди иштетерин билдирет; ал портун
`PORT`'тон же буйруктагы `{port}`'тон алат (дайыма бир эле портто угуучу сервер үчүн `--port`):

```sh
everything-rust app record . --http -- node server.js
everything-rust app replay .
everything-rust app front-door .                                    # axum: every route proxied
everything-rust app wire . api --route 'GET /users/{id}' --route '*'
everything-rust app lift .
```

- Суроо-талаптар колдонмонун документациясындагы `curl` саптарынан (`curl -X POST -d ... http://localhost:8080/x`),
  `--inputs`'тан (`{"name", "method", "path", "headers", "body"}`) жана тузактардан келет: жолдун сегменттери жана query
  маанилери CLI аргументтериндегидей эле тузактарга, денелер текст жана JSON тузактарына алмаштырылат, ошондой эле
  белгисиз маршрут. Ар бир иштетүү серверди жаңыдан баштайт жана суроо-талаптарды аты боюнча тартипте жөнөтөт, ошентип
  суроо-талаптардын ортосундагы абал сакталат.
- Абалды файлдарда сактаган сервер ар бир иштетүүдө жаңы көчүрмө алат: `--fresh db.json` (файл
  же папка, кайталанат) `http/files/` ичине snapshot катары сакталып, түп нуска, front door же build
  иштеген сайын жаңы иштөө папкасына көчүрүлөт; `--arg db.json` ар бир иштетүү өз буйругунан кийин алган
  аргумент, ошентип Rust бинардык файлы түп нуска кантип иштетилсе ошондой иштетилет.
  `--pace 50` ар бир жооптон кийин 50 ms күтөт, сервер жооп бергенден кийин аткарган иш үчүн (жаңы эле жазганын
  кайра жүктөгөн файл watcher'и).
- Кейстер `rust/app-cases/http/<case>.toml` (суроо-талап, статус жана маанилүү header'лер)
  жана `<case>.body` (жооптун денеси, эки иштетүү айырмаланган жерде `[..]` менен). Date, server жана
  ар бир жоопко мүнөздүү башка header'лер камтылбайт; сизге маанилүү эмес каалаган header сабын өчүрүңүз.
- Front door бул axum сервери: ал түп нусканы өзүнүн жеке портунда иштетип, эч бир бирдик жооп бербеген
  ар бир маршрутту проксилейт. `wire --route` axum маршруттарын кабыл алат: `METHOD /path/{param}`, каалаган метод үчүн `/path`,
  калган баары үчүн `*`; glue маршрутту, анын параметрлерин жана суроо-талапты алат.
  `lift` проксини алып салат; андан кийин HTTP кейстери CI'да `app replay` менен иштейт.
## Чыныгы мисал

[json-server](/docs/real-world/json-server) үчүн `--fresh`, `--arg` жана `--pace` керек болду: ал ар бир жазууда маалымат базасын кайра жазат, ал эми анын файл watcher'и тез арада келген жазууну жокко чыгарышы мүмкүн.
