# Front door жана wire

Адегенде кирүү чекитин Rust'ка көчүрүңүз, андан кийин ага буйруктарды бир убакта бир бирдиктен өткөрүп бериңиз:

```sh
everything-rust app front-door .                            # rust/app: every command runs the original
everything-rust app wire . textkit --command upper          # after textkit-rs passes gate
# write the glue in rust/app/src/units/textkit.rs, then:
everything-rust app wire . textkit                          # 100% again, lower fallback rate
```

## Front door

`app front-door` колдонмонун атындагы Rust бинардык файлы болгон `rust/app` папкасын даярдайт: жазылган кейстердеги буйруктар жана желектер үчүн clap парсери, мында ар бир буйрук түп нусканы ошол эле argv, stdin жана чөйрө менен иштетет жана анын чыгышын жана чыгуу кодун өзгөртпөй өткөрөт. Ар бир fallback саналат, ошондуктан жаңы front door'ду кайра ойнотуу 100% fallback менен 100% passed берет (муну көрсөтүү үчүн ал курат жана кайра ойнотот). Ал `rust/app`'ты эч качан кайра жазбайт: ошол учурдан тартып код сиздики.

## Бирдикти туташтыруу

`app wire <repo> <unit> --command <name>`:

1. бирдиктин crate'инде `gate` иштетет (жаңы эле өтсө `--skip-gate`);
2. аны `rust/app`'ка китепкана катары кошот;
3. `src/units/<unit>.rs` файлын бир жолу жазат, аны сиз же агентиңиз толтурасыз: аргументтерди талдоо, `<crate>::port` чакыруу, түп нуска эмне басып чыгарса ошону басып чыгаруу;
4. буйруктарды ага багыттайт, андан кийин курат жана кайра ойнотот.

Glue'ну жазгандан кийин аны кайра иштетиңиз: 100% passed жана төмөнкү fallback rate. `EVERYTHING_RUST_UNIT_<NAME>=original` lift'ке чейин туташтырылган бирдикти түп нускага кайра жөнөтөт.

Эч бир буйрукту атабаган argv үчүн колдонмонун өзүнүн атын буйрук катары туташтырыңыз (`--command mytool`): аргументтер жок, белгисиз буйруктар, колдонуу каталары.

## Эч нерсе түп нускага кайра чакырбайт

Front door түп нусканы өзүнчө процесс катары иштетет (же HTTP'ни ага багыттайт), bridge аркылуу өткөн бирдиктерди түп нуска чакырат, тескерисинче эмес, ал эми callback'тер баштапкы тилде калат.

Серверлер буйруктардын ордуна маршруттарды колдонот: [Серверлер](/docs/whole-apps/servers) барагын караңыз. Китепканалар өздөрүнүн public API'син колдонот: [Китепканалар](/docs/whole-apps/libraries) барагын караңыз.
