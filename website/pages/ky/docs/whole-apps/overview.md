# Бүт колдонмону порттоо

Максат түп нуска сыяктуу иштеген таза Rust колдонмосу, түп нуска эталон катары сакталат. Rust кодун агентиңиз жазат; everything-rust ишти тартипке салат, аны даярдайт жана ар бир кадамды далилдейт. CLI'лар, HTTP серверлер жана китепканалар.

```
analyze --whole-app ──> app record ──> app front-door ──> per unit: the loop, then app wire ──> app lift
 shape, every           what the app    Rust owns the       gate passes, so the unit answers in    pure Rust,
 dependency, the        does from the   entry point; the     Rust: replay 100%, fallback rate down proved by
 decisions to make      outside         original answers                                           replay
```

## 1. Пландоо

```sh
everything-rust analyze . --whole-app
```

`--whole-app` колдонмонун формасын (CLI, сервер же китепкана) жана кирүү чекиттерин, ар бир тышкы көз карандылыкты (импорттолгон же жарыяланган) анын Rust crate'и жана шайкештиги менен, порттоо тартибин бөлүктөр катары (бири-бирин импорттогон бирдиктер чогуу көчөт) жана сунушталган жооп менен номерленген чечимдерди кошот: калтырылуучу бирдиктер, бөгөттөлгөн бирдиктер, crate'и жок же жарым-жартылай болгон көз карандылыктар.

## 2. Бүт колдонмону жазып алып, андан кийин кирүү чекитин көчүрүү

1. [`app record` жана `app replay`](/docs/whole-apps/record-replay) программаны сырттан, кара куту катары далилдейт.
2. [`app front-door`](/docs/whole-apps/front-door) түп нусканын алдына Rust бинардык файлын коёт; ар бир буйрук дагы эле түп нусканы иштетет.
3. Ар бир бирдик [циклден](/docs/concepts/the-loop) өтөт, андан кийин `app wire` анын буйруктарын Rust'ка өткөрүп берет.
4. Replay 0 fallback rate менен өтүп, ар бир бирдик gate'тен өткөндө, [`app lift`](/docs/whole-apps/lift) түп нусканы алып салат.

[Серверлер](/docs/whole-apps/servers) жана [китепканалар](/docs/whole-apps/libraries) ошол эле буйруктарды колдонот.

## Агент аны кантип аткарат

[Whole-app skill](https://github.com/marprojector/everything-rust/blob/main/skills/everything-rust/whole-app.md) агентти бул жол менен алып барат, сиз гана кабыл ала турган чечимдерден баштап:

- **Сурак (grilling)**: агент айлампалар менен суроо берет, ар бир суроо сунушталган жообу менен, порт көз каранды болгон ар бир чечим аныкталмайынча, жана ар бирин `rust/DECISIONS.md` ичине ADR катары жазат, ал эми `rust/GLOSSARY.md` түп нусканын терминдерин Rust аталыштарына шайкештейт.
- **Изилдөө**: фондо иштеген агенттер ар бир көз карандылыктын баштапкы булактарын окуп, тапкан ар бир семантикалык тузагы менен `rust/research/<topic>.md` жазышат.
- **Сессиялар аралык**: `rust/MAP.md` ар бир бирдикти анын абалы менен тизмектейт; сессия баштоодон мурун бир бирдикти ээлейт, ал эми ар бир checkpoint кийинки сессия үчүн `rust/HANDOFF.md` калтырат. Бир толкундагы бирдиктерди subagent'тер параллелдүү порттой алышат.
- **Өтүү (cutover)**: агент колунан келгенин жасап, `rust/cutover.sh` жазат: бул сиз гана аткара турган кадамдар (deploy'лор, DNS, secret'тер) үчүн интерактивдүү скрипт, ар бир кадамда артка кайтуу жолу менен.

Сурак, изилдөө жана бул практикалар [Matt Pocock'тун skill'деринен](https://github.com/mattpocock/skills) ылайыкташтырылган.

## Бул Rust'ту эски дизайнга байлап койбойбу?

Экөө катар иштеп турганда гана. Жазуулар жүрүм-турумду колдонмонун ички түзүлүшүн эмес, чектеринде (CLI'дын чыгышы, сервердин жооптору, модулдун экспорттолгон функциялары) текшерет. Бирдиктер дагы эле bridge аркылуу өтүп жатканда эски структураны кайталаңыз; `app lift` түп нусканы алып салгандан кийин Rust'ту эркин кайра түзүңүз, жана `app replay` жүрүм-турумду дагы эле далилдейт.

## Чыныгы мисал

[json-server](/docs/real-world/json-server) ар бир кадамдан өттү: 514 жазылган HTTP кейси, 99.8% fallback менен front door, адегенде окуулар туташтырылды (22.6% fallback), андан кийин ар бир маршрут (0%), жана 514/514'тен өткөн таза Rust бинардык файлына lift.
