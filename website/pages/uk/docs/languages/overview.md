# Мови

Шість мов проходять увесь цикл: Node.js (TypeScript/JavaScript), Python, C, Go, Ruby і Java. PHP і C# у стадії попереднього перегляду: сьогодні `analyze` і цілі застосунки, далі мости для модулів.

| Мова | Модуль | Міст | Записує і відтворює |
| --- | --- | --- | --- |
| TypeScript/JavaScript | тека або файл | napi-rs або wasm-bindgen зі згенерованим бінарним wire; класи та async теж | Node, що запускає вихідні файли `.ts` |
| Python | пакет або модуль | PyO3 (abi3), пряме перетворення, типізовані винятки | Python, що імпортує оригінал |
| C | файл `.c` | функції `extern "C"` з оригінальними іменами та заголовний файл | оригінал, скомпільований у спільну бібліотеку і викликаний через ctypes, один fork на випадок |
| Go | пакет | типізовані виклики cgo і згенерований бінарний wire, у пакеті з оригінальним API | згенерований драйвер Go, зібраний як окремий модуль |
| Ruby | файл або тека з функціями модулів | розширення magnus під оригінальними модулями | згенерований драйвер Ruby |
| Java | пакет методів `public static` | типізований JNI і згенерований бінарний wire, у класах-обгортках з оригінальними методами | згенерований драйвер на основі рефлексії |
| PHP (попередній перегляд) | тека з функціями та методами `public static` | далі: PHP FFI через C ABI | сьогодні цілі застосунки: `app record`, `app replay` і front door, для CLI та серверів (`php -S`) |
| C# (попередній перегляд) | тека з методами `public static` | далі: P/Invoke через C ABI | сьогодні цілі застосунки: `app record`, `app replay` і front door, для CLI та серверів ASP.NET (`dotnet <app>.dll`) |

Кожна мова, крім C, також отримує пакетні класи (`--batch`): елементи перетинають межу один раз і лишаються в
Rust, а кожен виклик обробляє їх усі на всіх ядрах.

Мова визначається з репозиторію (`go.mod`, `pom.xml`, `.csproj` або `.sln`,
`pyproject.toml`, `Gemfile`, `composer.json`, `package.json`, інакше за найпоширенішими вихідними файлами);
`--lang` перевизначає її. Типи беруться з коду: типи TS, підказки Python, сигнатури C, Go, Java і C#,
теги YARD у Ruby, типи PHP і phpdoc; нетипізовані параметри, що використовуються як числа, виводяться
як числа.

PHP у стадії попереднього перегляду: `analyze` планує застосунок на PHP (пакети Composer і автозавантаження PSR-4, ризики
на кшталт нестрогого порівняння і переповнення цілих чисел у float, пакети Composer, зіставлені з крейтами),
а CLI чи сервер на PHP можна записати, відтворити і поставити за front door на Rust. Портування його
модулів у Rust через FFI у PHP буде наступним кроком ([issue #2](https://github.com/marprojector/everything-rust/issues/2)).

C# у такій самій стадії: `analyze` читає проєкти `.csproj` та їхні пакети NuGet
(зіставлені з крейтами), перетворює директиви `using` на теки і позначає, що C# робить інакше
(`decimal`, `dynamic`, відкладені запити LINQ, `Task`, `lock`, рефлексія). CLI чи сервер ASP.NET на C#
можна записати, відтворити і поставити за front door на Rust; портування модулів через P/Invoke
буде далі.
