`profile` працює через `go test`: `everything-rust profile <repo> -- go test -run X -bench . ./pkg`. Пакети створюються як `NewFnBatch(items)`; закривайте їх після використання.

## Що порт має зробити правильно

- `path.Clean`: `lazybuf` у Go читає байт за індексом запису після того, як той відступає назад, а не останній збережений байт (9 випадків, з власної тестової таблиці Go).
- `strings.ToLower` знижує регістр кожної руни окремо: `ΣΊΣΥΦΟΣ` стає `σίσυφοσ`, тоді як `to_lowercase` у Rust застосовує правило кінцевої сигми. Go також перетворює `İ` на `i`, а Rust дає `i̇`.
- Go ріже рядки за байтами; розріз посеред руни потрапляє в JSON як один U+FFFD на кожен байт.

## Швидкість

Go виконує листкові функції за кілька наносекунд, а один виклик cgo сам по собі коштує близько 80 ns. На `path` `bench` виміряв порт на рівні 0.04x на виклик: портуйте більші модулі. У пакеті робота переходить у Rust на всі ядра: `Slugify` по 50,000 рядках у Go зайняв 49 ms, а пакет працював **у 4x швидше** (порт з викликом на кожен елемент: 0.93x). Пакетні крейти виділяють пам'ять через mimalloc: із системним алокатором пакет Go був повільнішим за один потік.
