# Doctor

```sh
everything-rust doctor
everything-rust doctor --json
```

`doctor` перевіряє середовища виконання мов, налаштування агента і сервер MCP та виводить команду, яка виправляє кожну проблему. Він завершується з кодом 1, коли бракує чогось обов'язкового.

Запускайте його, коли крок падає через те, що середовища виконання, налаштування агента чи сервера MCP немає або вони застарілі. Навичка робочого процесу каже агентам робити так само.

## Що потрібно кожній мові

`record`, `diff` і `bench` запускають оригінал у його власному середовищі: Node 22.6+ для TS (він запускає вихідні файли `.ts` напряму), Python 3.9+ для Python і C (ctypes), Go 1.21+, Ruby 3+, JDK 17+ (`javac` і `java`). `profile` на Node потребує Node 24+, який дозволяє `--cpu-prof` у `NODE_OPTIONS`. Для C також потрібен компілятор C. Для wasm-мостів також потрібні `rustup target add wasm32-unknown-unknown` і відповідний `wasm-bindgen-cli`; `build` називає точну версію.

## Для контриб'юторів

`cargo run -- doctor` показує, які середовища виконання у вас є, їхні версії і команду, що встановлює або оновлює кожне з них. Див. [Як долучитися](/docs/project/contributing).
