# Реальні портування

Що сталося, коли everything-rust зустрівся з реальним кодом, і що через це змінилося в інструменті. Кожне число нижче взято з бенчмарку, який спершу перевіряє, що результати ідентичні, а повільні випадки наведено поруч зі швидкими.

| Порт | Що це | Результат |
| --- | --- | --- |
| [json-server](/docs/real-world/json-server) | цілий сервер на Node, портований від початку до кінця через `app record`, `front-door`, `wire` і `lift` | чистий бінарник Rust, що проходить 514/514 записаних HTTP-випадків; шість модулів проходять `gate` |
| [Fuse.js](/docs/real-world/fuse-js) | нечіткий пошук, шлях, на який пошук витрачає свій час | 3,414/3,414 випадків збігаються; у 32x швидше на 50,000 рядках (5.3x на одному ядрі) |
| [vercel/ms](/docs/real-world/vercel-ms) | крихітний парсер тривалостей, від початку до кінця | 975/975 випадків збігаються; 0.56x на виклик, 18x як пакет `parse`, 0.8x як пакет `format` |
| [x18n](/docs/real-world/x18n) | репозиторій для прикладу з практики | кожен gate проходить на `packages/core`, через міст повільніше за TS; його пошук 18-22x як пакет |
| [Шість мов](/docs/real-world/six-languages) | `path` з Go, `shellwords` з Ruby, `colorsys` з Python, поведінка JDK і glibc за невеликими фасадами | кожен порт проходить свій gate, загалом 13,010 записаних випадків |
| [Фікстури та статичні прогони](/docs/real-world/fixtures) | фікстури, написані для навантажувального тестування інструмента, і бібліотеки, проаналізовані, але не запущені | |

Портували щось реальне? Опис вітається: див. [Як долучитися](/docs/project/contributing#share-a-real-port).
