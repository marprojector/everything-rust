# Shadow

```sh
everything-rust shadow <crate>
```

`shadow` генерує заміну з API оригіналу: модуль TS чи Python, пакет Go, файл Ruby, класи Java або файл C. Завантажте її там, де застосунок завантажував оригінал. Вона запускає обидва варіанти, повертає результат оригіналу і повідомляє про розбіжності Rust, поки ви набираєтеся впевненості в продакшні.

| `EVERYTHING_RUST_MODE` | Поведінка |
| --- | --- |
| `shadow` (за замовчуванням) | запускає обидва, повертає результат оригіналу, повідомляє про розбіжності |
| `new` | перемикає на Rust |
| `old` | вимикає Rust |

Публічний API не змінюється. Код, що викликає, імпортує ті самі функції або shadow-модуль на їхньому місці.
