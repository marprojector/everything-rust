# Diff і відомі розбіжності

```sh
everything-rust build <crate>
everything-rust diff <crate>                     # має бути N/N
everything-rust diff <crate> --json
```

`diff` відтворює `cases.jsonl` на зібраному модулі Rust, викликаючи його так, як його викликає код оригіналу, і перелічує розбіжності. Розбіжність є відмінністю в поведінці: виправляйте порт, ніколи не запис.

```
198/200 cases match
- fuzzyScore("b😀", "a😀b😀c"): expected {"ok":1997}, got {"ok":1998}
```

## Відомі розбіжності

Іноді порт має відрізнятися навмисно: користувач хоче, щоб він виправив баг оригіналу. Спершу запитайте, потім додайте по одному рядку на кожен випадок у `<crate>/known-diffs.jsonl`:

**known-diffs.jsonl**
```json
{"fn": "...", "args": [...], "actual": ..., "reason": "..."}
```

Скопіюйте `fn`, `args` і `actual` з `diff --json`. Тоді цей випадок проходить лише з точно таким результатом, а `gate` падає, щойно відмінність зникає, тож тоді видаліть рядок.

## Застарілі записи

`record` зберігає відбиток файлів оригінального модуля в `recorded-from.json`. Коли оригінал згодом змінюється, `diff` попереджає, а `gate` падає, доки ви не запишете знову, замість того щоб проходити проти того, що оригінал робив раніше. Якщо `gate` каже, що запис застарів, запишіть знову, перш ніж портувати далі.

## Коли порт застряг

`diff` відстежує прогрес між збірками. Коли він каже, що порт застряг (його `trend.stalled`: три зміни `port.rs` поспіль не додали жодного випадку, що збігається), припиніть редагувати. Решта розбіжностей може потребувати правила, яке знає лише користувач, або ці функції можуть поки лишитися в оригіналі.

## Допуск для float

Якщо крейт записано з `--float-tolerance`, `diff` використовує цей допуск; `--float-tolerance` для `diff` перевизначає його на один прогін. Див. [Допуск для float](/docs/concepts/float-tolerance).
