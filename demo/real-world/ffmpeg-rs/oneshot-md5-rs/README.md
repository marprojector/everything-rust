Rust port of `oneshot_md5.c`, bridged with the C ABI. Generated by everything-rust.

## Loop

```sh
everything-rust record .   # record what the C code does
everything-rust build .    # build the C library
everything-rust diff .     # run the recorded cases against Rust
everything-rust shadow .   # run both in the app, log mismatches
everything-rust gate .     # fmt, clippy, tests, unsafe, API, diff
```
